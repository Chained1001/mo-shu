# 技法总结生成 SOP（technique-summary-sop.md）

> **何时加载**：moshu-analyze Stage 6 执行时。`拆文报告.md` 是阻断级前置依赖；`章节/*_摘要.md`、`章节/第1-3章_深度拆解.md` 是质量输入，缺失时严格按下方「失败模式与降级」逐项处理。
>
> **输出**：`拆文库/{书名}/技法总结.md`（模板见 [output-templates.md](output-templates.md)「Stage 6 技法总结」）。
>
> **定位**：拆解结论的应用视图（怎么学这本书）。**写作风格（句长/标点/对话/锚点）不在此产出**——那是独立技能 `moshu-style`（`文风库/文风.md`）的职责，拆书与文风解耦。

## 4 步流程

### Step 1: 读拆文报告核心字段

读 `拆文库/{书名}/拆文报告.md`，提取：

- **「写法技巧」段** → 填「可借鉴技巧」的「写法技巧 Top 5」
- **「可借鉴套路」段** → 填「可借鉴套路 Top 3」
- **「全书情绪节奏总览 / 伏笔与冲突网络」段** → 填「分层学习路线」的进阶层与适配层，只抽象节奏和手法，不搬运具体桥段
- **基本信息**（书名、题材、总章数）→ 填写技法总结标题与「生成记录」
- 拆文报告不存在 → **停止 Stage 6**，提示拆文未完成，先跑完 Stage 5

### Step 2: 章节基调序列（情绪交替）

用 Grep 读所有 `章节/*_摘要.md`：

```bash
grep -hE '基调：(紧张|轻松|悲伤|热血|爽|甜|温馨|恐怖|压抑|其他)' 章节/*_摘要.md
```

**关键格式注意**：`章节/*_摘要.md` 的实际格式是 `主题标签X | 基调：Y` 单独成行、跟在每个情节点后（一章 10-40 行）。`基调` 用**全角冒号**，`主题标签` 后**不带冒号**，两者都**不在行首**。grep 模式不能用 `^基调:` 这种锚定。

**章基调聚合规则**（每章一个章基调，写入「情绪交替模式」）：对该章所有情节点的「基调」字段做众数统计；并列时取章节内**最早出现**的基调。输出 `第N章: {章基调}` 连成序列。

**章内情节点基调序列**（「章内基调切换」分析）：不做聚合，按摘要中情节点出现顺序保留；切换频率 = 相邻情节点基调不同的次数 / 总情节点数。

### Step 3: 分层学习路线 + 不可模仿

- **基础层**：事件推进节奏、情绪链结构、冲突-释放结构中**结构/情绪层面**最易迁移的 3-5 条（换素材后使用）——表达层（词汇/句式/对话标签/描写重心）由 `moshu-style` 的「分层模仿建议·基础层」负责，此处不重复产出
- **进阶层**：节奏推进、伏笔埋回、视角切换、场景衔接中最值得复用的 3-5 条（替换人物/场景/道具后再使用）
- **适配层**：哪些技法适合本项目，哪些会导致人设/题材错位；明确不要搬运专名、标志性台词、独特桥段和事件顺序
- **不可模仿**：对标书的明显缺陷或不适合当前项目的技法（从拆文报告「不建议模仿」提取；可选，可空）

### Step 4: 落盘

按 [output-templates.md](output-templates.md)「Stage 6 技法总结」模板填写 `拆文库/{书名}/技法总结.md`：

- **生成记录**：参考资料（拆文报告 + 章节摘要）、情绪交替统计范围（全部/部分章节）、`技法可用：是/否`
- **仅情绪交替模式必标 confidence**（`high`：基调序列从 ≥10 章摘要统计 / `med`：3-9 章 / `low`：<3 章或样本不足）；其余段可选标：`high`（数据直接来自拆文产物，如可借鉴技巧直接引用拆文报告）/ `med`（样本归纳且样本充足）/ `low`（样本不足）
- 字数预算：硬上限 ~1000 字（技法总结是应用建议，不是完整报告——完整数据在拆文报告）

## 失败模式与降级

| 场景 | 降级策略 |
|---|---|
| `拆文报告.md` 不存在 | **停止 Stage 6**，提示拆文未完成，先跑完 Stage 5 |
| `章节/*_摘要.md` 数量 <3 | 情绪交替段标 confidence: low 并注明样本不足；可借鉴技巧照常 |
| `章节/第1-3章_深度拆解.md` 缺失 | 对话技法类建议从拆文报告兜底；confidence: low |
| 原文缺失 | 不影响（技法总结不采样原文） |

## 与 moshu-chapter-extractor 的关系

**不修改 moshu-chapter-extractor**。技法总结直接从既有字段（基调/主题标签/可借鉴要素）整理生成即可。

## 与写作端的关系

- `技法总结.md` 是**作者阅读参考**（怎么学这本书）+ 写作侧兜底（匹配章回退改指拆文报告写法技巧，不读技法总结）
- 写作每章的**风格基准**来自 `文风库/文风.md`（moshu-style）——两者互补：文风管"写得像"，技法总结管"学什么"
- moshu-import 同步外部对标资产时，技法总结.md 与拆文报告同等待遇同步到 `{项目}/对标/{对标书名}/`
