# dashboard-guide.md：Dashboard 工作台细节（moshu skill）

> SKILL.md 的 Dashboard 启动步骤路由到本文件。项目识别规则、可编辑扩展名与冲突保护细节。

## 项目识别规则

工作台会识别标准 `拆文库/{书名}/`，兼容存量 `拆文库-{书名}/`。写作项目识别：

- 长篇目录结构：目录内含 `正文/`、`大纲/`、`设定/` 或 `追踪/` 任一普通子目录。

符号链接不作为项目标记，只有单个 `正文.md` 的普通资料目录也不会被误认。

## 可编辑文件与冲突保护

浏览器可编辑 `.md`、`.txt`、`.json`、`.yaml`、`.yml`、`.toml`。保存或确认删除前做内容版本校验（sha256）——检测到外部修改时提示重新载入，防止误操作外部更新。

## 安全边界（重申）

Dashboard 默认只监听 `127.0.0.1`；不主动增加 `--allow-network`，不把工作区暴露到局域网或公网。小说内容不会上传。
