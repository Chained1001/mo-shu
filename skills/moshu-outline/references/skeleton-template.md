# 长篇大纲骨架模板（skeleton-template）

> **使用声明**：本文件是大纲/大纲.md 的产出模板——Stage 2 骨架构建时按需加载。
> **层级边界**：本文件管「做成什么样」（规模与形状）；outline-methods 管「怎么设计」（过程方法论）——两层不重叠。
> **边界声明**：场景表/人物详档/伏笔登记表不进大纲（归卷纲/Stage 3/volume）。
> **结构（十节）**<!-- B102 ㉖ -->：0 主题尺子句｜1 每卷骨架表｜2 卷间因果闭环表｜3 承诺兑现时点｜4 终局底牌｜5 升级台阶+常驻压力+刻度｜6 对手梯队与势力场｜7 暗线设计｜8 支线登记｜9 核心角色五件套——表不转述表（钥匙/卷名/字数各单现一处）。

## 第 0 节 主题尺子句

> 本书的守护纪律（一句话，来自题材定位核心梗）——例：每场大战由一具尸体引发，每次胜利替一个死者讨回债。
> 用途：后续所有场景/事件设计的取舍尺子——不符合尺子句的戏，先问「为什么破例」。
>
> **主题尺子句推导方法（B105）**：见 outline-causality §4 主题推导（五问+九行模板+主题呈现+象征贯穿）。
>
> **4.1 产物落位（B103）**：本节同时承载 4.1 故事核心设计的「一句话梗概+核心卖点」——梗概（主角+目标+阻碍+反转，雪花法第 1 步选定/混搭后写入）+ 核心卖点（金手指+主角+模式的一句话合成，凭啥追）——落本节开头两行，check_outline 第 0 节检查兜底存在性。

|---|---|---|---|---|---|---|---|---|---|
| 1｜{卷名} | {本卷主线一句话} | {具名对手——不是「反派」，是名字+立场} | {输了会怎样} | {中点是假胜还是假败} | {高潮由什么驱动——事件/人物/揭示} | {谁在本卷入场、谁有高光戏} | {本卷末留下的具体未答问题} | {主角能力/地位/认知的跃迁} | {字数} |

- **合计尾注**<!-- B102 ㉖ -->：表下一行「合计：共 {N} 卷｜总字数约 {X} 万字｜总章数 ≈ 总字数 ÷ 每章字数（可推导，不单列）」——机检字数加总对照此行（±5%）；卷级鸟瞰即本表本身，不再另设总览表（表不转述表）。
- **每卷一段话落位**<!-- B102 ㉙ -->：每卷骨架行下附**每卷一段话**（三幕+两次灾难性事件——Stage 3 人物构建产出落此，显式落盘；不由下游代写，下游发现缺失应呈报上游漏产）。

- **对手须具名**：每个卷级对手写名字（哪怕绰号），禁「幕后黑手」「某势力」占位——具名后才有动机可查（配第 9 节五件套）。
- **卷末钥匙**：本卷留给下一卷的具体问题（前台问题的延续口），不是情绪总结。
- **群像列**：本卷谁入场（新核心成员）/谁高光（有重头戏的既有人物）——防「换场全靠新人物类别勾」的标签消费。
- **篇幅配比参考（C20⑤）**：起≈20%/承≈40%/转≈20%/合≈20%（**外部经验值，非书证——仅节奏自检参考，不作硬约束**）。

|---|---|---|---|---|
| 1 | {主角本卷的目标问题} | （开书设定债——核心梗的起点） | {钥匙 1} | {下一卷承接点} |
| 2 | | {上一卷钥匙/遗留问题/因果债} | | {本卷开头的承接点} |

- **双环一表查**<!-- B102 ㉖ 合并 -->：横向闭环=每行「卷末钥匙」接下行「前台问题」；纵向闭环=「因为上卷」导出本行「前台问题/起于」——两环同表逐行核，断链当场补（因果设计方法论见 [outline-causality.md](outline-causality.md)）。
- 末卷钥匙 = 终局底牌的先导；**钥匙单现**——本表是唯一登记处，骨架表「卷末钥匙」列与各处只引用不转述。

## 第 3 节 承诺兑现时点表

| 读者承诺 | 兑现章数（预估区间） | 兑现方式 |
|---|---|---|
| {成品标尺承诺——卖点/爽点/情绪} | {第 N-M 章} | {怎么兑现} |

- **模式转换点**（如探案→战斗的题材切换）单列一行——转换的章数区间与触发条件。
- **卖点亮相点**（金手指首显威）单列——首显威的章数与方式（对照成品标尺的承诺强度）。

- **终极露面点**：终极阻碍首次对读者露面的章数（哪怕只是名字/影响——登记介入点，见第 6 节）。

## 第 4 节 终局底牌

- **终局底牌**：全书终极真相/主角终极资源（开书写死，后文只揭露不更改）。

**终局设计四件（B105 补——来源：大师课 Ch6 :2960-3116）**：
- **最终抉择（道德二难）**——问句：终局时主角必须二选一且两难吗？操作：执意达成目标须付道德代价 **vs** 做对的选择须放弃渴望之物——两条路都真的痛，读者无法轻松站队。反例：一条路明显正确=假抉择。
- **十结局头脑风暴**——操作：定稿前强写 10 个替代结局→取前 4 酝酿→选一个**添加转折元素不替换**→回头埋线索。反例：写完一个结局就定=没比较过更优解。
- **收梗三法**——操作：大梗加场景收（专章收束）/小梗配角一句交代/最大梗短尾声（终章后余韵段）——对应第 7 节「必收性」补上「怎么收」。反例：所有梗同一方式收=机械。
- **「真好」收尾戏**——操作：主线冲突后补一场主角个人生活戏（和解/拥抱/新日常）——网文第六幕余波的关系版。反例：收在战斗胜利=读者对主角的生活没有落幕感。
## 第 5 节 升级台阶 + 常驻压力 + 刻度连续性

- **升级台阶**：能力/地位的阶段递进表（每阶段的关键跃迁，与第 1 节跃迁列对应）。
- **常驻压力**：贯穿全书的压力源（对手存在感/世界规则/债务/时限），不随卷结束消失。
- **刻度连续性**：每轨（职级/境界/势力/名声）在卷间换轨时**显式重定义新刻度**——如职级轨→势力轨时声明「此后以势力规模计」，防刻度漂移。

## 第 6 节 对手梯队与势力场

| 层级 | 对手（具名） | 立场/目标 | 背后手笔 | 与主角关系 |
|---|---|---|---|---|
| 终极 | {名字} | {终极目标} | —（终极本身） | {关系定位} |
| 卷级 | {名字} | {本卷目标} | {此案/此局幕后的指向} | {关系定位} |
| 单卷案件 | {名字} | {单卷目标} | {如系某人指使——指向谁} | {关系定位} |

- **背后手笔列**：单卷案件反派的「案」指向哪个更高层对手（案级案子的幕后是谁）——把卷间对手链显式登记，防「打完小怪忘了谁在操纵」。
- **终极介入点登记**：终极阻碍在卷 2-3 以局外人一句话/一个动作影响主角（读者回看才知）——登记章数与形式，后文兑现时对表。
- **反派差异化对照问**<!-- B102 ㉗·社区经验非书证 -->：每个新卷级对手过一问「**与上卷对手的差别是什么**」——驱动力/关系位/威胁方式至少一异，治「村级小反派反复」同质化伤。

## 第 7 节 暗线设计（层次表）

- **暗线层次表**：每暗线登记 层次（读者先知/主角先知分流）｜埋设章｜揭示章｜**必收性**｜承载人物。
  - 读者先知=读者知道主角不知道（悬念）；主角先知=主角知道读者不知道（期待）——两类分流登记，防混。
  - **必收性列**<!-- B102 ㉗·社区经验非书证 -->：主线必收（不收=坑）／支线可选（收了加分）／彩蛋可弃——悬置预警按级差异化。
  - **活跃伏笔上限**<!-- B102 ㉗·mo-shu 自定可覆盖 -->：一卷埋而未收 ≤6 条警戒——悬置预警补活跃数维度。
  - **埋设间距纪律**<!-- B102 ㉗·社区经验非书证（C20⑤ 口径） -->：大伏笔揭示前须有铺垫跨度（行业经验「反转前 30-50 章」）——揭示章与埋设章间距过远时中段补强化点。
## 第 8 节 支线登记

- **支线登记**：支线名｜归属（角色/势力/设定）｜交汇章｜收束卷｜**刀片/离场（选填）**——支线占比与主线的交汇点提前标；刀片列=该支线/角色是否在何时牺牲或永久离场（情绪核弹排期）。
- **挂靠理由四分法（C20⑥ 三分法→B105 加第四理由）**：提供主线线索/塑造人物/铺垫后续设定/**承载内在议题（B105，大师课 Ch8 :3729-3748）**——一条副线专管主角需要学的事（婚姻/亲子/信任），正负结局都能传达主题。四者皆无=纯水支线不进表；支线登记表加「内在议题」选填列——全表无一条内在议题副线=大纲只有外部引擎。
- **刀片计划（B91）**：刀片与配角高光互为正负两极——只登记高光=武器库只有一半；刀片时刻须过情绪引擎低压区核对（连刀不宜超过读者容忍线）。

## 第 9 节 核心角色五件套

| 角色 | 目标 | 动机（为什么是他） | 价值观冲突 | 顿悟 |
|---|---|---|---|---|
| 主角 | {目标} | {个人化动机——不是「大家都恨纳粹」，是「为什么是他」} | {两组价值观的拉扯} | {弧线终点的认知转变} |
| 对手（卷级） | | | | |
| 终极阻碍 | | | | |
| 关键配角 | | | | |

- **动机必须个人化**：写「所有人都恨的事」不够——要落到「这件事为什么在他身上刺得最深」（出身/创伤/亏欠/执念）。填不出个人化动机=人物还没想清（设计方法论见 [outline-causality.md](outline-causality.md)「动机链/道德前提」，B86）。
- **目标=欲望（表面要什么），顿悟=发现需求（内心缺什么）——弧光的引擎是从追求欲望到发现需求（B91，Truby）**。
- 对手/终极阻碍同填五件套（不单列反派栏）——对手也是人，有目标、动机、价值观冲突与（可能的）顿悟。
- 顿悟列 = 第 4 节终局底牌（道德前提）的角色版兑现轨迹（正文「从信 X 到信 Y」的锚点，见卷纲信念轨迹字段）。
