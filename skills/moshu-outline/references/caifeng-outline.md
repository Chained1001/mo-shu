## 检索策略（只取公开元数据）

0. **前置查库（B71）**：query 组装后、出网前先对 [genre-catalog.md](genre-catalog.md) 路由与题材卡索引别名表匹配——命中共性内容则收窄检索为特性层；未命中才全量检索（库管共性/采风管特性）。
1. **优先级**：百科/角色词条/机制解析文章 > 平台目录标题/简介/标签。
2. **取什么**：书名/媒介/人物名/机制名/结构形态（目录标题可证的结构层证据）；**全书正文不取、不复述**（正文红线）。
3. **源不限媒介**：网文/动漫/影视/游戏均可——机制采风尤其鼓励跨媒介。
4. 多源检索（≥2 个独立来源）再落盘；单一来源时**披露占比**。
5. **参考档案 context（B88）**：spawn 时传对应参考档案路径——researcher 只查本次增量维度。
6. **人物原型采集（C21①，乌贼实证，可选——无对标默认纳入、有对标跳过）**：query="{题材/时代} 历史人物 小传 轶事"。
7. **时代质感采集（C21②，乌贼实证，可选同上）**：query="{题材/时代} 经济 社会 风俗 概况"。

### 检索效率四件套 + 效率纪律 + 环境节 + CDP 预检（B90/B93 原文保留）

- **效率四件套**：检索计划先行（2-4 角度）/两段式（广度→top3-5 深抓）/源去重/引用强制（无 URL 丢弃）。
- **回合预算**：检索 ≤20 回合；先写产物骨架再增量补；超限降级收尾（元数据头标「降级」）。
- **环境节**：临时文件进 `设定/.caifeng-tmp/`（禁项目根散落/禁 /tmp）；PYTHONIOENCODING=utf-8；搜狐 GBK 解码。
- **CDP 预检**：spawn 前主会话跑 CDP 探测（moshu-cdp 侧，端口 9222，--detect-only）——ready 则注明可用 agent-browser；needs-setup 征询作者；拒绝走 curl 栈。

### 来源质量优先级 + 国内可达源优先级表 v2（B93 实测）

**专业分析/创作方法论 > 权威百科/官方资料 > 平台页面/榜单 > 个人评论/读后感**。

发现层（按序 fallback，不并行）：① 搜狗 web（主力，CAPTCHA 壳即切）② 搜狗微信 ③ 360 搜索。
内容层（直接抓取）：豆瓣书评/小组、萌娘百科（RESTful 页面路径）、晋江（GBK）、搜狐号/网易号。百度百科开放 API 已失效（移降级名单）。
禁用名单：google/wikipedia/duckduckgo（国内不可达）、Bing cn（分词失效）、起点/知乎专栏/贴吧/番茄/龙空/飞卢/纵横（反爬）。

### spawn prompt 必含条款（B93，两侧同文逐条搬入）

1. **源优先级表 v2**（全文引用发现层+内容层+禁用名单）
2. **发现层按序 fallback**：搜狗 web 试 1 次→CAPTCHA 即切搜狗微信→再切 360（不并行不重试）
3. **搜狗 web 可能限流**——CAPTCHA/验证码壳=立即切下一层
4. **Bing 禁用**（cn.bing 中文书名分词失效）
5. **内容层直接抓取**（已知 URL 直接 curl）
6. **反爬名单**：禁用名单站点白探即弃
7. **CDP 状态**（主会话预检结果传入）
8. **效率纪律**（≤20 回合/先骨架/超限降级）
9. **临时目录约定+Windows 三坑**

## 三域深采检查单（#089/#091）

- **剧情域**：故事脉络/关键剧情节点/桥段手法/节奏形态——落参考档案「脉络/节点/支线段」
- **设定域**：世界观/力量体系/规则与质感——时代素材（如"唐朝"）落 `设定/资料/{专题}.md` 素材层
- **人设域**：人物表/动机-缺陷-反差/关系网形态——落参考档案「人物表段」

**对象与差量**：主参考+辅参考逐部过检查单；**有对标者**：对标拆文已覆盖主体（#079），采风只做差量。**边界**：深采=元数据层全覆盖（正文红线不读）；拆书=全文逐章。

## 参考作品档案（一书一档，B88 schema 九段）

**触发**：立意参考确认后为每部确认参考（主 1+辅 ≤3）建**轻档**（速写三行：底色占比｜开局 vs 主体｜主角弧；专名清单随轻档即建；元数据头标「降级」）；首次采风后增强为**实证档**。落点 `设定/参考/{书名}.md`。

**schema（实证档九段）**：①故事脉络 ②关键剧情节点 ③主线支线 ④主要设定 ⑤主要人物表（功能位）⑥底色配方与模式占比 ⑦缺点清单 ⑧专名清单 ⑨来源与截至日期。

**边界**：有该书拆文产物时档案做索引引用不重做（指向拆文库路径）；档案=基础认知层，拆文=结构分析层。

## 转译纪律（加粗执行，公共纪律）

1. **机制可学**——专有名词零复用（来源名词清单落盘，check_outline candidate 比对兜底）。
2. **具象必改**——名字/背景/关系网全换；角色采风产物因"神似"无法机检，**使用前必须作者过目停靠**。
3. **跨媒介必过本土化转译步**——输出前过「转译深度三问」：动力源改了吗？获取方式改了吗？社会结构适配了吗？三问全过才算译好——只改名=缝合。
4. **单一来源占比披露**。
5. **正文红线**——只取公开元数据，全书正文不取不复述。
6. **防抄红线（结构相似度自检）**：融合后若成品≈来源换皮（同开局+同金手指类型+同升级性质）→ 红线触发——打散重组。

## CF 票据制（公共纪律）

`设定/采风/采风-CF{NNN}-{类型}-{主题}.md`（旧书根散落回退）——CF 编号在需求产生时登记创作进度「采风需求」行（CF-{NNN}｜类型｜需求描述｜状态四列）；spawn prompt 携带；重采=新 CF（标「取代 CF-XXX」）。编号递增：`ls 设定/采风/采风-CF* 设定/采风-CF* 2>/dev/null` 取 max+1。

**票据 schema**：核心发现（第 0 节 ≤5 条）/元数据头（类型/触发需求/本书语境/日期/执行者/版本状态）/来源清单（分组+URL+占比）/要素表（要素|内容|来源|建议消费去向）/专有名词清单/转译三问初答/缺点与规避清单/融合与消费记录。

**资料层五维（#101——设定域时代素材采集清单）**：①制度[官制/法律/军事/经济→势力场原料]②社会风土[阶层/职业/习俗/节庆→日常底色]③宗教信仰[信仰/神话/禁忌→暗线主题原料]④山川地理[地形/气候/物产/交通→换图征程原料]⑤器物衣冠[建筑/服饰/饮食/技术→场景颗粒原料]。纪律：条目式（每维 5-15 条）/来源红线/转译注记栏。
