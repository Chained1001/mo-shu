## 1. 人物宝典元素清单（雪花法 Ch12 框架）

每个元素一行+触发问句（设计时逐元素过；落盘字段见 character-basics 卡模板）：

| 元素 | 触发问句 | 来源 |
|---|---|---|
| 基本信息 | 姓名/年龄/身份——名字有含义吗（读者会记错吗）？ | 雪花法 Ch12 |
| 外貌 | 一个可记忆特征是什么？（不是清单，是读者记住的那一个） | 雪花法 Ch12 |
| 性格标签 | 三个标签——哪个是表层、哪个是深层？ | 雪花法 Ch12 |
| 背景故事 | 哪件事塑造了他现在的性格？（创伤/亏欠/执念） | 雪花法 Ch12 |
| 动机 | 为什么是他？（见 outline-causality 动机个人化——「所有人都恨纳粹」不够） | 雪花法 Ch6/实测 #021 |
| 目标 | 表层诉求是什么？（动机≠目标，见 outline-causality） | 大师课 :6451 |
| 障碍 | 什么挡着他？（内部+外部各一） | 雪花法 Ch12 |
| 价值观冲突 | 两组价值观拉扯，哪组是剧情主战场？ | 雪花法 Ch12 |
| 弧线六阶段 | 现在在哪个阶段？升级台阶对表了吗？（见第 5 节） | 雪花法 Ch12 |
| 对话 DNA | 口癖/句长/语气词——遮住名字能认出吗？（见 character-design-methods） | 实测 #021 |
| 关系网 | 与核心团/反派/朝堂谁有绑定？（见第 2 节 roster） | 雪花法 Ch12 |
| 弱点 | 一个会被反派利用的弱点是什么？ | 雪花法 Ch12 |
| 出场设计 | 在哪卷哪段入场？高光在哪？（见第 2 节编排表） | 实测 #021 |

**价值观具体化测试（B105 补——雪花法 Ch7 :1323-1381）**——「价值观冲突」字段防抽象词：
- 写 2-3 条「没有什么比 X 更重要」（例：比复仇更重要=她女儿的平安）→ 每条问「一个普通人会不会持相反值？」（会=不够个人化，太普世没张力）。
- **两难测试**：设计至少一次「保 X 必失 Y」的取舍场景（X=他声称最重要的，Y=他实际放不下的）。
- 五件套价值观列禁填抽象词（「正义」「自由」），须填「X vs Y 曾在哪一难中被排序」——例「他曾为救女儿放弃复仇——直到女儿也站在仇人那边」。

## 2. 配角群规模规划（roster 分层）

- **问句**：全书人物量级规划了吗？——每个角色有明确「层位」吗？
- **操作**：按体量分档参考值（300 万字长篇对照）：
  - **核心团 5-8**：主角+核心伙伴（每卷都有戏）
  - **跨卷反派 5-8**：须具名（skeleton-template 第 6 节对手梯队——背后手笔链）
  - **朝堂势力人物 8-15**：政治/势力面人物（分阵营登记）
  - **单元轮换配角 20-40**：单卷/单单元出场，用完即退
- **出场编排表**：谁在哪卷哪段入场——对照 skeleton-template 第 1 节骨架表群像列（谁入场/谁高光）+ 第 3 节承诺兑现时点（群像入场点）。**牺牲/离场时刻登记（刀片计划，B91）——与支线登记刀片列同源**（情绪核弹排期，过情绪引擎低压区核对）。
- **本卷变化列（B105 补——救猫咪 Ch6 :1993-2023）**：编排表加「本卷变化」列——核心团每成员本卷有可见变化（态度/关系/能力任一）；填「无变化」的核心成员=群像工具化警报。**唯一不许变的是反派**——拒绝转变正是反派被淘汰的主题依据；反派的「不变」登记为「哪些诱惑被他拒绝」（他不是没机会改，是主动拒绝——这比「设定上不变」有力）。
- **反例**：全书 200 个「重要角色」——没有层位=每个都浅（精力分散）；或核心团 2 人、路人 100——核心关系单薄。
- **来源**：雪花法 Ch12（人物宝典+规模规划）+ 实测 #021（五问诊断——人物散落）。

## 3. 魅力原型学（咒术/血界类型库扩挖）

| 原型 | 定义 | 功能位 | 适用场景 |
|---|---|---|---|
| 帅型强者 | 实力顶尖+从容（五条悟式） | 天花板参照/碾压爽点来源 | 主角成长参照系 |
| 搞笑抽象型 | 行为抽象+可靠（扎普式） | 高压缓冲/群像润滑 | 团队副手/气氛担当 |
| underdog 观测者 | 底层视角+敏锐观察（雷欧式） | 代入通道/信息差载体 | 主角前期视角/旁观者线 |
| 成人导师 | 成熟克制+有自己战场（七海式） | 三观锚/主角短板补位 | 主角成长引路人 |
| 职场妈妈 | 家庭+事业双线（KK 式） | 世俗锚/人情味来源 | 都市/现实题材关系线 |
| 腹黑军师 | 算计深+目的隐秘 | 谋略戏/反转制造 | 权谋/智斗线 |
| 老手尊严型 | 老练+守尊严底线 | 传承/宿命对照 | 前代强者/宿敌镜像 |

- **问句**：每个核心配角的「原型」是什么？原型功能位被谁承担了？——功能位缺人=群像有洞。
- **反例**：全员「帅型强者」——功能位重复=群像无差异（没人搞笑/没人当导师）。
- **来源**：咒术回战/血界战线类型库扩挖（实测 #021 诊断——魅力原型空白）+ 雪花法 Ch12（角色差异化）。

## 4. 演员规定情境法

- **问句**：这个情绪是从「规定情境」长出来的，还是我直接命令角色「他愤怒了」？
- **操作**：情绪由规定情境导出——处境（他在哪/面对什么）/时限（多久内要做决定）/谁知道什么（信息差）/关系压力（谁在看着他）——四要素摆出来，情绪自然出现（与 emotional-methods「规定情境代入」同源，此处升格为人物构建节）。**任务动词化**：把角色目标动词化命名（「报仇」→「让他当众失去一切」）——动词化的目标才能演。
- **反例**：细纲写「他很愤怒」——没有规定情境，正文只能贴情绪标签（见 anti-ai 模式）。
- **来源**：演员自我修养（规定情境法/任务动词化）+ emotional-methods 既有雏形升格 + 实测 #021。

**任务动词化完整引用（B105 补——演员自我修养 Ch7 :1821-1905）**：
- **名词陷阱**：名词命名任务（「母爱」「强势」）→ 演的是状态（做作）；动词命名（「我希望让他当众失去一切」）→ 才有行为。反例：任务写「强势」=摆架势；写「逼她交出遗物」=可执行。
- **双人对练**：场景双方动词任务写成一对互相挫败的「我希望」——A 希望让 B 当众难堪、B 希望保住体面→碰撞即场景引擎（一进一出自检的微观版）。
- **任务三型**：外在身体（拿/走/藏）/简单心理（试探/安抚）/心理任务（原谅/背叛）——太宏大的先落到具体肢体动作链（「原谅」→「把旧信还给她」）。

## 5. 升级绑弧光强化

- **问句**：主角的弧线六阶段与升级台阶逐阶段对表了吗？
- **操作**：弧线六阶段每阶段对照升级台阶的具体操作——阶段 N 的能力/地位跃迁（skeleton-template 第 2 节跃迁列）= 弧线阶段 N 的认知/关系变化；**能力升级和信念转变同步发生**（不是各走各的）。
- **反例**：能力一路升（50 档）但信念不变（弧线不动）——升级与弧光脱钩=爽点无灵魂。
- **来源**：雪花法 Ch12（弧线六阶段）+ character-basics 既有「升级绑弧光」整合 + 实测 #021。
