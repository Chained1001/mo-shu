# 基本设定表模板（core-setting-template.md）

> 定位注记（B54；B103 重写 #102 终版）：本文件是 Stage 1 第 5 步定稿过日落盘 `设定/基本设定.md` 的模板（旧书名题材定位.md——读回退兼容；旧书 `设定/创作进度.md` 同）。**使命（★#102，B105 #113 调整）=商品标签＋作者种子可暂存**：书城商品信息——标签＋作者种子可暂存（AI 不编故事）。AI 编的故事不落本表（作者种子可暂存第五段，4.1 消费）；故事的一切（梗概/主角/世界观/冲突/金手指）由 AI 设计的部分全是草稿产物（4.1 起）。本表只承载格式。
>
> **两层宪法对称**：基本设定=开书契约（why/what，COMMIT 后锁死走修订流）；大纲=结构宪法（how，定稿后全书只读）。例：终局口径[基本设定·意志] vs 终局底牌[大纲·设计]。

```markdown
## 基本设定表

### ① 基础参数
- 书名：{暂定名}（2.5 书名候选 naming-cards 拟，作者挑）
- 题材/类型：{主类型 + 副类型}
- 目标平台：{起点/番茄/晋江/其他}
- 预计字数：{X} 万字（默认 200 万）
- 预计章数/卷数：{X} 章 / {N} 卷（4.2 细化定稿）
- 每章字数：{默认 3000-4000，细纲字数目标的全局默认}（ℹ️ 影响细纲字数验收基准）
- 关系线：{单女主/多女主/无CP/纯爱/未定[AI 按题材建议]}（ℹ️ 影响感情线设计深度）
- 终局口径：{圆满/圆满带憾/悲剧/开放式/还没想好[AI 拟]}（ℹ️ 与 4.1 终局底牌一致性锚）

### ② 基调风格
- 情绪基调：{爽文/虐心/甜宠/悬疑/燃——可多选，AI 融合}
- 文风：{成熟商业文风/轻松/厚重…——一句话描述}
- 读者画像：{年龄段/口味/平台分布（AI 从题材+平台推断，作者可改）}
- 题材雷区：{读者最反感——扫榜直填或 AI 按题材拟+过目，不问作者}（ℹ️ 服务避雷，check_outline 词表扫描+评审检查面）
- 作者雷区：{个人不想写——问一次可跳}（ℹ️ 与题材雷区并存不合并；机检/评审两者都扫，作者雷区命中更严重）

### ③ 参考偏好
- 主参考：{书名}（定主基调，唯一）——{主要借鉴它什么}
- 辅参考：{书名 ≤3}——{各借鉴什么}
- 无参考时标「无——按题材/基调大范围采风」

### ④ 成品标尺（B94 合并段——三组目标态）

> 撰写口吻以「完全读懂成品的评论家」视角推演目标态——具体可测（拒绝「好看/流畅」级空词），每条能对照产物打分。

- **节奏目标**：期待密度{每 N 章一个期待点}｜释放频率{每 N 章一次爽点释放}｜爆发密度{区间}｜爽点循环{模式}｜追读锚点{一句话}
- **情绪基准**：核心情绪{类型}｜首卷感受{一句}｜交替模式{高低落点交替}｜低压容忍{连续 N 章不爽可接受线}
- **结构要点**：结构自评 1-10{+一句依据}｜中点安排{模式}｜对手升级节奏{每卷一档}｜伏笔密度{参考}

**锚定指针模式**（有对标时——#079 锚定指针不复制数值）：标尺三组登记「锚定：对标《X》剧情/节奏.md+情绪模块.md」——数值权威留拆文库（单一真源），拆文更新标尺自动跟随。解除锚定=该字段降级为 AI 推演+素材收集校准路线。

**版本与校准**：v1=Stage 1 落盘（明标「初版·按信号推演，待 Stage 2 素材收集校准」）；v2=4.2 素材收集校准后写回（同节版本升级+元数据标注 v2·素材校准——#093 落点：不独立成文件、不进大纲）。跳过素材收集→标尺停留推演版标注保留。

**消费方**：evaluator benchmark_path（4.4 验收/5.2 质量审/卷 Phase 2）/write A 段无对标 fallback/骨架表「读者承诺」列/5.6 开卷就绪包 Q1。

### ⑤ 创作种子（可选，可空）
- 只收作者念头/补问中的故事直觉原话——AI 不填一字（#113）
- 空=4.1 不消费（从标签+参考档案独立生成）；有=4.1 优先用（作者种子＞AI 自由发挥）
- 格式：`- {作者原话}——{AI 一句标注：人物直觉/世界画面/冲突点子/金手指念头}`
```
