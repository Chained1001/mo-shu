## 开场白（进入时呈现，B89）

**FULL 模式每次进入呈现**：技能目的一句（「本技能完成开书故事层：题材定位→世界观→人物→全书大纲」）+ 步骤总览表：

| 步骤 | 作用 | 产出 | 作者参与点 |
|---|---|---|---|
| Stage 1 信息采集 | 定调/定形/理想书评/采风 | 核心设定三文件+理想书评 | 四轮问答 |
| Stage 2 骨架构建 | 全书结构与规模 | 大纲/大纲.md | 机检后 |
| Stage 3 人物构建 | 角色与世界观 | 角色页+势力场 | 人物设计评审（可选） |
| 大纲终审（B89） | 独立语义评审 | 终审报告 | 随开书确认 |

预计交互点数 ~8-12。**续跑/恢复降级**：一句话定位（「Stage N 进行中，当前焦点…」）+当前进度，不重复全表。

## 交互模态规则（对话形态的选用纪律）

1. **封闭选择**（候选可枚举且 ≤4 项）→ AskUserQuestion（弹窗），不开放式提问。
2. **开放采集**（无候选、自由表达，如方向/感受）→ 对话式，不硬塞弹窗。
3. **过程性动作**（即将执行的操作）→ 声明即将做 + 可显式跳过（如采风默认执行）。
4. **同性质封闭选择合批一屏**（≤4 问/屏），不逐问弹窗——轮 2 超 4 问拆两屏。
5. **弹窗选项必须带"（推荐）"标注与一句理由**，供作者快速决策。

## Stage 1·信息采集（四轮式开场——作者意图输入口，保留全部交互）

> **方法论书指引**：**《小说的骨架》第 2 章**——理想评论家口吻成品书评作目标态锚；操作已萃取进 [idea-seed.md](idea-seed.md)「理想书评」节。

**故事面**（所有书都做）——四轮开场（定调→定形→理想书评→定流程），按回答落地：

1. **先查选题决策**：项目根存在 `选题决策.md`（moshu-scan Stage 5 产出）则读取——取最前推荐选题向用户确认；`扫榜日期` 久则提示"数据可能过期"；「能爆的原因」标 `待拆文验证` 时提示可选先 `/moshu-analyze` 或直接开书（不拦）。缺失时自动找（**项目根起向下** 3 层按名搜；**不向上、不吃兄弟项目**）——见轮 1。
2. **模糊灵感**（画面/脑洞，说不清题材卖点）：先做**灵感种子收敛**（[idea-seed.md](idea-seed.md)，落 `灵感种子.md`），Logline 作一致性尺度。
3. **定形（轮 2）**：AskUserQuestion 批问 体量三数＋目标平台＋终局口径＋情绪基调＋更新频率＋禁区雷点（可选跳过）；不确定按 200 万字/5 卷。答案落盘核心设定表（读者偏好段）。
4. **理想书评（轮 3）**：按 [ideal-review-template.md](ideal-review-template.md) 写——三维度目标（①结构 1-10｜②节奏：期待密度/释放频率｜③情绪：核心情绪+首卷感受），Phase B evaluator 锚点。落盘 `设定/理想书评.md`。
5. **核心设定落盘（轮 4 后）**：按 [core-setting-template.md](core-setting-template.md) 产出，**成稿先展示作者过目**，确认后创建 `设定/题材定位.md`（核心梗三分法+对标分析，含终局底牌与升级台阶）、`设定/关系.md`（关系映射）、`设定/题材正文提示卡.md`（边界/逻辑/期待/爽点）——产出方法见方法论索引。
6. **方法论声明（轮 4 收尾）**：创作进度创建后补全——仅档位一行（轮 4 答案）；三域深度**不再逐项问**，默认档位表作参考，作者口头可调（"卷纲再细一点"即改）。

> **默认档位表**：

| 域 | 默认 | 可选档 | 不可裁剪项 |
|---|---|---|---|
| 大纲 | 全局骨架 | 前半细化 / 仅阶段一 | 终局与升级台阶（全书） |
| 卷纲 | 首卷细 | 前两卷细 | 首卷（开书必须） |
| 设定 | 核心+终局相关 | 全量前置 | 主角/金手指/核心冲突 |

> **执行归属（B84）**：三域深度为全书构建声明（记入创作进度）：大纲/设定由 outline 执行；卷纲由 volume 执行——此处声明、彼处消费。

**对标面**（有主对标时做）——**对标发现**（先于反应式加载，主动扫拆文库推荐，不被动等用户开口）：

1. `ls 拆文库/`（数据源）与项目 `对标/`（引用视图）列已有书目；按项目目录名、`.active-book` 与 `设定/题材定位.md` 识别当前作品，**排除同名或指向当前正文的 `拆文库/{当前书}/`**。moshu-import 重建工程生成的本书拆文不是对标候选，不得复制回 `对标/`。排除后都为空 → 跳第 4 条。
2. 逐本读题材（读 `拆文库/{书}/` 的 `概要.md` 头部或 `拆文报告.md`「基本信息」的「题材」），与本书题材/方向比对，标 同题材 / 弱相关 / 不相关。
3. 有同题材或弱相关候选 → AskUserQuestion 推荐（列候选书 +「都不用」+「另拆一本」），选定主对标 1 本。写入 `设定/题材定位.md`「对标登记」`主对标书`，按「首次引用对标书」规则把选中书从 `拆文库/{书}/` 复制到 `对标/{书}/`（不含文风.md——文风独立）。登记后若文风库尚无该书文风，询问是否现在 /moshu-style 学习（可跳过，写第一章缺失再提醒）。
4. 无候选 → 无对标继续（骨架按八节点自排，见 Stage 2）；想对标可先 `/moshu-analyze` 拆一本。

**对标上下文加载**（用户提到对标书或工作目录已有 `对标/` 时）：先按上 1 条排除自对标；检查 `剧情/情绪模块.md` 与 `剧情/节奏.md`——任一缺失即停止，设 `missing_primary_contract: true` + `repair_action`（重跑 `/moshu-analyze` 或 `/moshu-import`），不得以拆文报告/章节摘要代替；两产物都在时先读情绪模块（读者需求/情绪引擎/可复现模块）再读节奏.md（信息推进/情绪触动点/爆发节奏）。子目录按需召回（消费方 write）。

> 开篇"第一个冲突/机遇"定义可参考**激发事件四问**（moshu-volume 侧 [opening-design.md](opening-design.md) :87——什么是/什么不是/在何处/四特质），Stage 2 定全书四阶段时用。

### 四轮式开场（Stage 1 交互）

```
轮 1（定调 + 参考偏好 + 采风 · 开放对话）：
> **灵感池分流（B91）**：作者提到攒了灵感/火种清单 → 先走 [idea-seed.md](idea-seed.md) 灵感池模式（筛活火种→进种子收敛）再进方向提问。
"你想写什么类型的故事？你希望这本书给读者什么感觉？"
→ 有方向 → 追加参考偏好快问：「有没有喜欢的作品？不说对标——就是风格/基调/主角类型你觉得不错的，0-3 部」
  （采集：作品名 + 各自偏好维度，如"诡秘的悬疑氛围"；落盘核心设定表「参考偏好」段。参考≠对标语义见文头注记）
  （题材初判走 [genre-catalog.md](genre-catalog.md) 路由，框架名写入题材定位.md「题材框架」行[B71]）
→ 没方向 → "要不要先扫一下最近的榜单？或者说说你想让读者有什么感觉？"
→ 提到参考书 → 弹窗（AskUserQuestion）：「参考书怎么处理？」
  ○ 正式对标——需先拆书（/moshu-analyze），参与每卷节奏校准
  ○ 仅参考——取参数做原创；借鉴剧情可以、缝合可以，但每个设计须自证增量（改了什么/加了什么/重组了什么）（推荐）
  ○ 都不用——删掉参考
  （对参考书的三个吸引点提问在轮 3 理想书评采集）
→ **参考作品速写确认（B84）**：AI 对每部参考作品给三行速写（底色内核+模式占比｜开局手法 vs 全文主体｜主角弧阶段转变），AskUserQuestion 弹窗请作者确认/纠正。确认后才组采风 query——防误权重污染 query 框架。
→ **参考作品档案建档（B88）**：速写确认后为每部确认参考建轻档 `设定/参考/{书名}.md`（速写三行+模型知识扩展，元数据头标降级）；首次采风产物回来后增强为实证档（schema 见 caifeng-methods「参考作品档案」节）。
→ **采风默认执行**（query 构造按参考偏好分流）：
  - 参考偏好非空：query = "{参考作品A}的{维度}手法 + {参考作品B}的{维度}——提炼可复用模式"（定向检索）
  - 参考偏好为空：query = "{题材} 当前热门作品的结构模式"（泛化检索）
  采风默认执行（无网时降级声明照旧）：
  1. 向用户声明："你提到了《X》《Y》——我先联网采风这两部作品的结构要素（约 5 分钟），采完给你看要点表，确认后拿它做设计参照。不想等就说'跳过采风'。"
  2. 用户说跳过 → 记录降级声明进创作进度附注，继续
  3. 用户不反对 → spawn moshu-researcher（结构采风，CF 票据登记）
  4. 采风产物回来 → 展示要点表 → 用户过目 → 按融合流程使用
  5. 采风产物回来后 → **融合五步在本 Stage 内执行完毕**（对照核心设定表→借用功能位→**归因重构**→本土转译→方法论验证），产物直接喂 Stage 2——不留到后续才消化。**归因重构**——对每个拟借要素过三问：作者为什么这么写（立意指认，不许五字带过）／落读者心理（锚 write 侧 reader-psychology 分类）／重新出发（从心理需求生成 ≥2 条不同路数的写法，参考实现只是其一）。
  5b. **深度融合（B81）**：融合涉及 ≥3 个设定文件联动 → spawn researcher（caifeng-fusion，传采风产物+本书设定+设计需求）；轻量融合主会话 inline。
  6. **操作细则见采风手册**：检索策略/源七类/融合五步与 fallback 内联见 moshu-volume 侧 caifeng-methods.md。

轮 2（定形·AskUserQuestion 批，>4 问拆两屏连续问）：
问 A（体量三数）："这本书大概什么体量？"（总字数/总章数/分几卷一起问）
  → 不确定 → "先按 200 万字/5 卷，写完第一卷可调"
问 B（平台）："目标平台？"（起点/番茄/晋江/其他，各选项带一句适配注解）
问 C（终局口径）："你要在动笔前设计好结局吗？"
  选项：完结（终局底牌+高潮定死，全书朝终点铺）｜开放连载（升级台阶驱动、单元剧循环）
问 D【B53 新增】（情绪基调）："你想给读者什么感觉？"
  选项：爽文（打脸/升级/收获）/ 虐心（代价/牺牲/成长）/ 甜宠（治愈/日常/恋爱）/
        悬疑（解谜/反转/紧张）/ 燃（热血/友情/突破）——可多选，AI 融合
问 E【B53 新增】（更新频率）："预计更新节奏？"
  选项：日更 4000+ / 两日一更 6000+ / 周更 10000+ —— 影响章长/节奏/爆发密度
问 F【B53 新增】（禁区雷点，可选跳过）："有没有绝对不要的元素？"
  示例：不要后宫/虐主/系统流——负面约束比正面偏好更防翻车
所有答案落盘核心设定表「读者偏好」段。

轮 3（理想书评·创作确认）：
"方向和体量已定，给这本书定理想书评——想象一个完全读懂这本书的评论家，
为它写一篇溢美的书评。"
采集子问题（固化）：①希望给读者什么感觉？②参考书最吸引你的三个点（如有）？
> **预填路径（B84）**：作者说「说不太准/你按已有信息拟一版我来改」→ 跳过子问题采集，按已收集信号（轮 1 参考偏好+轮 2 定形+采风要素）生成理想书评草稿，进「草稿→作者改定」。两问保留为可选深化。
> **参考素材归因（B88）**：参考素材入稿前过归因三问；出口自证增量——答不出「我们改了什么」=照搬，回炉。
→ [作者描述]
→ AI 生成理想书评草稿 → 作者改定 → 落盘设定/
→ "好，这是你的理想书评——后面每一步都拿它当尺子。"

轮 4（定流程·AskUserQuestion 一问）：
"构建精细度选哪档？"
  🏃 快速（试水/脑洞，先跑起来）
  🚶 标准（推荐——大部分网文，不确定选这个）
  🧗 完整（多线/强反转/群像）
→ 不确定 → 先标准档，写完第一卷可升
→ 答完 → 创建最小创作进度（方法论声明仅档位一行、焦点＝Stage 1 落盘中、答案记入已收敛区）
→ 核心设定表成稿展示作者过目 → 确认后落盘 设定/ 三文件 → 补全方法论声明（三域深度默认档位表，口头可调）
→ **参考素材归因（B88）**：参考素材入稿前过归因三问；出口自证增量——答不出「我们改了什么」=照搬，回炉

轮 4 后·虚拟对标合成（无对标时执行，有对标时跳过；细则见 moshu-volume 侧 caifeng-methods.md「第五步」）：
  前提：采风产物已回并过融合流程；`设定/题材定位.md` 已登记主对标 → 跳过本步
  主线程 AI 从多源采风产物提炼三类设计目标（① 节奏目标：爆发密度/爽点循环/追读锚点 ② 情绪基准：核心情绪/交替模式/低压容忍/禁区 ③ 结构要点：中点/对手升级/伏笔密度——细则见 caifeng-methods「第五步」）。有参考偏好时优先从参考作品采风产物提炼（定向），辅以同题材泛化补充。落盘 `设定/虚拟对标.md`（固定三节）；CF 票据标「已消费·合成虚拟对标」
```

## Stage 3·人物构建（自动）

> 方法论照常加载：**人物构建开始前必读 [character-construction.md](character-construction.md)**（B86）+ [character-design-methods.md](character-design-methods.md)（苏式问句/升级绑弧光/人物主题卡）；卡字段见 [character-basics.md](character-basics.md)。**虚拟对标情绪基准参照**（无对标时）。角色采风按需（产物命名与融合规程见 moshu-volume 侧 caifeng-methods.md）。角色卡含「对话 DNA」五要素（口头禅功能位/句长习惯/语气词与标点/回避话题/情绪外显）——有主对标时从拆文库角色卡带入作派（学结构不抄血肉），无对标留占位；write 语声锚消费（B59）。

**产出**：每卷一段话（三幕+灾难）、每角色一页（背景+弧线六阶段+大纲微调）、势力场总览回填、世界观完善、情绪引擎设计。不确定标 ⚠️ 入创作进度（移交 volume Phase B）。

**人物设计评审（B77 可选触发）**：本步产出后可 spawn evaluator（eval_type=structure，对象=人物设计；target_paths=新角色档案+关系.md，related_paths=大纲/大纲.md 骨架段），报告呈报作者；不可用 fallback 自评（对照三维度问句，标 Fallback）。只呈报不拦截。

**大纲终审（B89，开书确认前必做）**：Stage 3 完成后 spawn evaluator（eval_type=structure；target_paths=大纲/大纲.md+设定六文件+三份采风；benchmark=理想书评；virtual_benchmark=虚拟对标）——spawn context 显式含**长弧四检查面**：①卷间跃迁契机（每卷换台/升迁须有不可替代理由）②跨卷反转链（各卷假胜/假败后反转已登记）③终局代价具体化（终局两条路可感知对比）④末卷收束节奏（群像告别点名式风险）。**终审四件**：产物包交叉一致性（大纲×设定×采风数字/时点）、遗留分类审计（规则见 moshu-volume 侧 volume-workflow「遗留分类规则」）、数据缺口闭环（research_needed 须采风或作者明示豁免）、机检 blocking 复跑确认。报告呈报作者随开书确认（只呈报不拦截）；不可用 fallback 自评标 Fallback。
