# caifeng-methods.md：采风操作方法（研究环）

> 本文件是 moshu-research 的操作说明书：检索策略 + 三类要素表模板 + 转译纪律 + 降级与来源规范。产物一律项目级（`设定/采风-*.md`），禁中央库。

## 检索策略（只取公开元数据）

1. **优先级**：百科/角色词条/机制解析文章 > 平台目录标题/简介/标签。
2. **取什么**：书名/媒介/人物名/机制名/结构形态（目录标题可证的结构层证据）；**全书正文不取、不复述**（正文红线）。
3. **源不限媒介**：网文/动漫/影视/游戏均可——设定机制采风尤其鼓励跨媒介（别处把同一机制解决得更漂亮）。
4. 多源检索（≥2 个独立来源）再落盘；单一来源时**披露占比**（"单一来源：X"）。

## 三类要素表模板

### 结构采风（→ 设定/采风-结构-{主题}.md）

| 要素 | 从哪取 | 学什么 |
|---|---|---|
| 每卷弧线模式 | 目录标题/简介 | 卷与卷的推进形态（升压/换场/内卷） |
| 对手设计 | 角色词条/简介 | 对手与主角的纠缠关系（私人化/组织化） |
| 节奏形态 | 目录标题密度 | 快慢交替/卷内起伏 |

### 角色采风（→ 设定/采风-角色-{主题}.md）

| 要素 | 学什么 |
|---|---|
| 动机-缺陷-反差 | 人物立体的结构，不学名字背景 |
| 行为模式/口头禅功能位 | "这个位置放什么功能"，不抄具体台词 |
| 关系网形态 | 角色间张力来自哪类关系 |

### 设定机制采风（→ 设定/采风-机制-{主题}.md）

| 要素 | 学什么 |
|---|---|
| 代价/边界 | 机制的限制设计（不是无代价） |
| 成长路径 | 力量提升的结构（阶段/门槛） |
| 对抗关系 | 机制如何制造冲突（攻防/博弈） |

## 转译纪律（加粗执行）

1. **机制可学**——机制/结构/规则可跨作品学习，但专有名词零复用（来源名词清单落盘，check_outline candidate 比对兜底）。
2. **具象必改**——名字/背景/关系网全换；角色采风产物因"神似"无法机检，**使用前必须作者过目停靠**（记录尾注显式提醒）。
3. **跨媒介必过本土化转译步**——输出前显式过「转译深度三问」：
   - 动力源改了吗？（如负面情绪→修炼积累）
   - 获取方式改了吗？
   - 社会结构适配了吗？（如异能者组织→修行宗门/衙门体系）
   **三问全过才算译好——只改名=缝合不算转译**。
4. **单一来源占比披露**——多源稀释自证（来源记录里写清各来源贡献占比）。
5. **正文红线**——只取公开元数据（简介/标签/百科/目录标题/角色词条/机制解析文章），全书正文不取不复述。

## 采风融合四步（采风产物 → 本书资产的有机融合）

> 融合发生在调用方步骤（build 步 1 骨架/步 2 人物/设定面），本节是操作规程——**采风给灵感，方法论把关，防抄红线兜底**。三类对象通用，角色版最典型。

1. **结构对照**：采风要素表逐项对照本书现有设定——采风当**检查清单**用（照出缺哪个功能位：动机链没递升？反差立不住？口头禅功能位缺失？），不是照抄对象。
2. **功能位借用**：缺什么补什么，借的是**功能**（"宣言用于被羞辱节点""导师兼金手指载体"），不是内容——宣言/桥段必须从本书角色的性格和世界长出来。
3. **本土转译**：动力的社会植根必须换——用本书世界真实存在的压迫（贱籍制度/师门除名/官场贬谪）重新长出动机起点，过「转译深度三问」。
4. **方法论验证**：融合结果过对应方法论工具（角色：九维/三层标签反差/探索三件套/升级绑弧光；结构：势力场设计/中点假胜败；机制：代价边界检查）——**采风不豁免质量关**。

**结构相似度自检（防抄红线落点）**：融合后若成品≈来源的换皮（同开局+同金手指类型+同升级性质），红线触发——打散重组（保留结构功能，换内容组合）；采风记录的占比披露供作者过目核对。

**示意（角色版）**：采风对象"动机逐级递升链（私辱→证明→救亲→对抗终极）"照出本书主角"动机从头到尾同一层"→借用"递升"功能→起点从本书社会结构长出（如贱籍不得科考之辱）→过九维与升级绑弧光验证。
