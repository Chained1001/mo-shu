# moshu-research：研究环（采风技能）

你是**研究环**：为 moshu-build 构建环的各步骤提供**动态参照**（结构/角色/设定机制/情节/情绪五类），产出**项目级**记录（`设定/采风-CF*.md`，CF 需求票据制），不改任何构建产物（设定/大纲/卷纲归 build）。**技能做壳，agent 做芯**——检索+蒸馏由 moshu-researcher agent 执行（B21），融合四步留主线；agent 不可用时主线程内联降级。采风失败不阻断——降级声明后继续。

## 五类采风对象

| 对象 | 触发时机 | 检索输入 | 学（结构层） | 改（具象层） |
|---|---|---|---|---|
| **结构采风** | build 步 0 轮 1 后（可选） | 题材关键词/榜单 | 每卷弧线模式/对手设计/节奏形态 | 情节血肉全原创 |
| **角色采风** | build 步 2 人物步（按需） | 角色需求描述（"油滑怕死有底线"） | 人设结构：动机-缺陷-反差-行为模式-口头禅功能位 | 名字/背景/关系网全换 |
| **设定机制采风** | build 步 1-2 设定面（按需） | 机制需求（力量体系/对抗规则），源不限媒介 | 规则设计：代价/边界/成长路径/对抗关系 | 命名与包装本土化转译（机制换语汇） |
| **情节采风** | build 步 3 单元步（按需） | 桥段需求（如"主角突破反俗套"） | 桥段/名场面/情节装置的结构手法 | 血肉与人物全原创 |
| **情绪采风** | build 步 1-2 情绪面（按需） | 情绪目标（如"让读者哭的情节组合"） | 情绪节拍/催泪燃点设计的组合手法 | 场景与人物全原创 |

## 入口流程（交互门 → spawn → 融合 → 过目）

1. **确认对象类型与需求**：AskUserQuestion 五选一（结构/角色/设定机制/情节/情绪），或从调用点语境直接判定；登记采风需求 CF 编号（台账「采风需求」行：CF-{NNN}｜需求描述｜状态：进行中）。
2. **spawn moshu-researcher**：检查 `.claude/agents/moshu-researcher.md` 存在且非子代理上下文——存在则 `Agent(subagent_type: "moshu-researcher", prompt: ...)`，prompt 必含：
   - `type`：`caifeng-structure | caifeng-character | caifeng-mechanism | caifeng-plot | caifeng-emotion`；
   - `query`：检索需求（题材关键词/角色需求描述/机制需求/桥段需求/情绪目标）；
   - `context`：**本书语境一段摘要**——题材+主角+当前步骤+要喂给哪个字段（采风产物「元数据头.触发需求」据此落盘）；
   - `project_dir`：书项目根；
   - `cdp_port`：可选。
3. **读回采风产物**：读 `设定/采风-CF{NNN}-{类型}-{主题}.md`（六节结构，见 caifeng-methods「采风产物六节模板」）；核对元数据头（触发需求/本书语境/状态）。
4. **主线执行融合四步**（agent 不做融合）：按 [caifeng-methods.md](references/caifeng-methods.md)「融合四步」——选要素 → 转译 → 喂字段 → 功能位清单回写（写前取材 pull / 写后校验 check 双模式均合法）。
5. **角色类作者过目停靠**：角色采风产物因"神似"无法机检，**使用前必须作者过目停靠**（记录尾注显式提醒）。
6. **主线回写**：融合结论/消费去向/作者过目结果回写采风文件「融合与消费记录」节，元数据状态改**已消费**；台账 CF 行改「已消费」。同需求重采＝新 CF（台账标「取代 CF-XXX·原因」）。

## spawn 契约（调用协议）

- **产出**：agent 写 `{project_dir}/设定/采风-{结构|角色|机制|情节|情绪}-{主题}.md`（区别于事实查证的 `参考资料/`），六节骨架精简版在模板内自含。
- **返回 JSON**：`status: success|partial|failed`、`research_file`（指向采风产物）、`type`（caifeng-*）、`summary`、`sources_count`、`confidence`、`gaps`。
- **正文红线**：采风任务下 agent 不得取小说正文（区别于事实查证的"可取正文"）；每要素标注来源 URL，无来源丢弃。

## fallback（agent 不可用时的内联降级）

agent 不可用（未部署/子代理上下文/spawn 失败/联网缺失）→ 主线程按 [caifeng-methods.md](references/caifeng-methods.md) 内联执行原检索流程（标注 `Fallback: researcher unavailable -> inline`），降级声明照旧（台账附注「本次构建未经采风，基于模型知识+方法论」）——**一行不废，降级后继续**。

## 与相邻技能的三层定位

- **moshu-scan**（市场层）：扫榜单找题材方向——问"现在什么火"。
- **moshu-analyze**（深度层）：拆一本书的节奏/情绪/模块——问"这本书怎么写的"。
- **moshu-research**（广度层）：跨书跨媒介采风找参照——问"别处怎么解决的/有没有更好的机制"。

## 产物清单

- 融合锚定：采风类型×验证方法论×大纲落点三方锚定（见 caifeng-methods「融合锚定表」）
