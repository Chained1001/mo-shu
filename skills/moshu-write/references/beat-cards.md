# 节拍卡集合（Beat Cards）

细纲设计时的可引用节拍模板。**从 mo-shu 既有方法论固化，不引入新理论**——每张卡对应已有抽象模式的具体化。细纲「本章结构公式」行可用节拍 ID 引用（如 `BC-004 爽点换挡 + BC-001 蓄力爆发`），设计者按需选择、组合、变体。

> 用法：节拍卡是**材料不是答案**——卡内步骤可拆散重排、可自定义变体；卡之间可嵌套（如 BC-010 五折线的某段内部套 BC-001）。同批细纲内同名节拍卡软降权（防循环重复，见 outline-methods.md 约束规则）。

---

### BC-001 压抑蓄力爆发

- 适用：高压/推进章、爽点前置章、打脸前蓄势
- 结构：①压抑铺垫（憋屈/劣势/被轻视）→ ②蓄力（准备/忍耐/伏笔收紧）→ ③爆发（爽点释放，铺垫值全额兑现）
- 铺放比：≥4:1（铺垫字数 ≥ 释放 4 倍）；短章可降至 3:1
- 注意：铺垫必须可指认（读者知道在憋什么）；释放后必须给在场反应层（见 plot-core-methods）

### BC-002 微反转补刀

- 适用：普通推进章内的微型爽点（每 3 章一次冲突解决）
- 结构：①设预期（角色/读者以为 A）→ ②轻反转（实际 B，意外+合理）→ ③补刀（对反派的额外一击或态度转变）
- 注意：微反转不改变大格局（大转折归 BC-009/卷级节点）；相邻章微反转类型不可相同

### BC-003 情绪高压三段式

- 适用：冲突密集章、对抗高潮章
- 结构：①升温（对话/行动升级，逐句紧咬）→ ②峰值（最尖锐的一次交锋/揭示）→ ③回落锚点（一句台词/动作收束，留余温）
- 注意：三段必须情绪递进，不能原地重复；回落不泄气（锚点制造新期待）

### BC-004 爽点换挡防疲劳

- 适用：批量写作时控制爽点密度（高压/推进章每 3000-5000 字一个爽点；低压/关系/修炼/信息整理章不强求）
- 结构：高压章（爽→爽→钩）↔ 低压章（关系/铺垫/喘息，弱钩或阶段目标）交替排布；相邻章不情绪趋同
- 注意：低压章仍要给读者一个往下看的理由（微好奇/暧昧期待/阶段目标）；换挡节奏参照 outline-structure-theory.md「章节定位与张弛」

### BC-005 卷终余波结算

- 适用：卷末章、大高潮后 1-3 章
- 结构：①主要矛盾解决 → ②战利品通过**情节**展现（非罗列）→ ③角色结局/关系落定 → ④下卷铺垫钩子
- 注意：战利品要有可见的"使用场景"（当众/对比/影响扩散）；下卷钩子不点破（留白有余味）

### BC-006 狗血冲突螺旋升级

- 适用：冲突链设计（多章级），升级层级：口头 → 经济/资源 → 暴力 → 关系崩塌
- 结构：每轮冲突在上一轮基础上加码（新信息/新筹码/新人物卷入）；至少一轮"虚晃一枪"（先放松再升级）
- 注意：升级必须有因果（不是为冲突而冲突）；每轮后主角付出可见代价（体力/资源/关系/信任/身份/时间）

### BC-007 黄金三章情绪契约

- 适用：开书前 3 章（opening-design.md 配合）
- 结构：第 1 章立"绝境+主线"（读者知道主角要什么）→ 第 2 章喂情报+立世界观（不打断节奏）→ 第 3 章第一次爽点释放+推向正面冲突
- 注意：三章分别承担"绝境-情报-反击"；每章末尾收在下一步行动而非解答（见 genre-writing-formulas 各题材公式的章结构）

### BC-008 章章爽压钩均衡

- 适用：全部章节（细纲设计每章必过）
- 结构：每章 = 至少一个可指认的爽点/进展（按章节定位）+ 一个往下看的理由（章尾钩子/阶段目标）
- 注意：钩子与下一章开头承接（钩子承诺的兑现点要在下章细纲可见）；低压章允许弱钩子但不允许无理由

### BC-009 高潮构建公式

- 适用：大高潮章（plot-core-methods.md「高潮构建公式」）
- 结构：蓄能（1-2 章铺垫，拉满期待）→ 假胜（先给希望）→ 崩解（希望被击碎/反转）→ 交叉死磕（主角成长兑现）→ 悬置收尾（不留水）
- 注意：主角必须展现成长（用行动而非旁白）；高潮后接 BC-005 余波结算

### BC-010 情绪五折线

- 适用：10 万字尺度规划、卡文时推方向（outline-methods.md「情绪拉扯五折线结构」）
- 结构：上行（有利条件）→ 拐点下行（不利转折，非主角之错）→ 上行（行动/转机）→ 拐点下行（虚晃一枪）→ 爽点爆发
- 注意：可嵌套套娃（每段内部再用五折线）；下行原因绝不归主角失误（"功都是主角的，锅都是别人的"）

### BC-011 爽文五阶段循环

- 适用：单元剧/剧情单元设计（outline-methods.md「爽文五阶段小循环」）
- 结构：稳定态（潜在危机）→ 危机触发（抓眼球）→ 破局行动（金手指挫败阴谋，可大量铺垫）→ 收益结算（明确有价值回报）→ 新平衡+预埋（连下一个循环）
- 注意：每单元金手指必须展示**不同用法**（相邻单元禁同逻辑）；单元间建立因果

### BC-012 期待感管理

- 适用：长线钩子设计（emotional-arc-design.md「期待感管理六法则」）
- 结构：埋期待（承诺/悬念/升级暗示）→ 保持（间隔性提及，不冷落）→ 兑现（在读者遗忘前偿还）→ 新期待（兑现后立刻立新的）
- 注意：期待债不拖欠过久（见 reader-contract-and-progression.md）；兑现时机=读者最想要时，不是作者方便时

## 节拍卡与既有机制衔接

| 机制 | 衔接 |
|---|---|
| 细纲「本章结构公式」 | 用节拍 ID 引用（如 `BC-004 + BC-001`），公式行保留节点功能说明 |
| 大纲方法论总路由 | 节拍设计 → 本文件（beat-cards.md） |
| 爽点节奏公式 | BC-001/002/004 是公式的节拍化落地 |
| 大纲安全七检 ⑤（高低层次） | BC-004 换挡是五检的执行工具 |
| 卷复盘 | BC-005 余波结算是卷末章的标准结构 |
