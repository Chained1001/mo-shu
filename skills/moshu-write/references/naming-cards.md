# 命名卡集合（Naming Cards）

起名时的可引用模板。**冷路径**——开书定书名/卷名、细纲定章节名、人物卡定角色名时按需取用，不随 SKILL.md 加载。

> 来源：V7 命名卡精选（14 张中取 5 张高频刚需）。共同原则：**名字是功能不是装饰**——先锁定名字要承担的读者承诺/悬念/路标/身份功能，再生成候选；拿不准就按卡内问题自查。

---

### NC-001 书名卖点承诺

- 适用：开书定书名
- 一句话：书名必须让读者能判断题材卖点；标题过于花哨而看不出承诺 = 失败
- 规划：
  1. 先写本书**真正不可替代的读者承诺**（题材 + 核心冲突或收益，一句）
  2. 再生成能在短句中显出题材/冲突/收益的候选；锁定标题承诺与作品契约的对应关系
- 自查：读者只看书名，能说出"这是什么题材、能爽在哪"吗？不能 → 重选

### NC-002 章节名事件与悬念

- 适用：细纲/写章定章节名
- 一句话：章名在「已发生事件」与「未闭问题」之间取舍；过度剧透或空泛都失败
- 规划：
  1. 确定本章**最值得点击的**已发生事件或未闭问题
  2. 选择表达方式：结果先行 / 疑问 / 短句；锁定章名希望读者期待哪一个兑现
- 自查：章名是"本章最大看点"还是"一句空泛形容"？后者 → 换

### NC-003 卷名阶段路标

- 适用：开书/开新卷定卷名
- 一句话：卷名要能区分长篇阶段；只剩华丽意象 = 没完成任务
- 规划：
  1. 提取本卷主轴：阶段任务 / 主要地图变化 / 核心对手 / 规则升级（取一个）
  2. 与前卷卷名形成可辨识差异；锁定卷名对应哪项进展
- 自查：两卷卷名互换后读者能察觉吗？不能 → 太泛

### NC-004 角色名身份语系

- 适用：人物卡定角色名
- 一句话：名字脱离时代/阶层/阵营/语系 = 人物区分度失败；名字要能承载身份
- 规划：
  1. 锁定角色所处时代、地域、群体、家庭关系与公开身份
  2. 从**相同语系内**生成多个可读候选；记录正名、称呼层级、别名与改名
- 自查：两个同阵营角色的名字像同一语系吗？主角的别名有来历吗？

### NC-005 代号绰号传播

- 适用：设定绰号/代号/称号（外号、江湖名号、系统称号）
- 一句话：代号必须听得出处与传播范围；称呼来自可验证的行为和使用者
- 规划：
  1. 写清代号由谁起、因何传播、谁有资格使用、与正名的关系
  2. 检查不同群体是否用不同称呼；锁定代号揭示或遮掩什么身份
- 自查：角色听到"那个外号"时能说出是谁起的吗？绰号对应的事件读者见过吗？
