## 1. 过滤词直呈（Ch.2 :1500-1552）

- **触发问句**：这段有限知视角的感知/回忆，我写的是「她注意到 X」还是直接写 X？——「她注意到」「看见」「回想起」「意识到」「这才发现」出现时，读到的不是 X 本身，是「她在注意 X」的转述层。
- **操作**：删过滤词，直接呈现所见物/所忆物。X 有多具体就写多具体，镜头对准 X，不写取景动作。
- **反例**：她注意到门开着，看见桌上放着那封信，回想起三年前的事 → 门开着。桌上那封信。三年前，她把信放在这里。
- **注意**：角色**自觉**的反省时刻（「她意识到自己怕了」是角色的自我认知转折点）可保留——过滤词删除只针对无意识的感知流，不针对有意识的自我发现。

## 2. 系动词激活（Ch.2 :1558-1648）

- **触发**：「X 很 Y」式状态句（她很紧张）、「显得/看起来/感到」系词句、被动语态批量出现。
- **操作**：把状态换**主动动词+可感知动作**——让人笑跳哭抱，让头发飘动、手攥白、脚步加快。主动动词迫使你为这个情绪找到具体形象；找不到形象=这句情绪本来就空。
- **反例**：她很紧张 → 她攥住扶手指关节发白（主动动词+身体细节替代情绪词，与 writing-craft「身体细节替代情绪词」同源）。
- **注意**：被动语态三合法情形别误删——动作主体未知（「他被杀了」不需要说谁杀的）、主体不重要（「门被推开」）、表无助感（「她被人群裹着走」）。静止态度场景保留系动词是刻意的节奏选择，不是错误。

## 3. 比喻禁忌（Ch.8 :6253-6465）

- **触发问句**：这个比喻是五类禁忌之一吗？——五类各一句判据：
  - **陈词滥调**：比喻烂熟（心如刀割/时间如流水）→ 删，或逼自己找一个新角度。
  - **牵强**：本体与喻体差距过大、读者要停下来想两者关系 → 删（关系不瞬间成立=不是比喻是谜语）。
  - **混合**：两个喻体混在同一句（「她的愤怒像刀子般燃烧」刀与火两套）→ 拆开，只留一个。
  - **过度解释**：比喻后又解释比喻（「像猫一样，意思是她骄傲」）→ 删解释，相信读者。
  - **专名无注**：用读者不认识的人物/作品/典故当喻体 → 加注或换成通用意象。
- **总原则**：少即是多，拿不准就不用——无比喻的文段只是平，坏比喻是伤。
- **反例**：她的眼睛像黑夜中的宝石，闪闪发光，仿佛藏着星辰大海 → 删两喻留一，或全删写具体眼神动作。

## 4. POV 距离推拉（Ch.8 :5749-5776）

- **触发问句**：这个场景此刻需要读者离角色多近？——决定叙述的镜头距离，远近不是风格是操控。
- **拉远**（读者评判视角）：抽象名词+简述+典型化+客观语气——「她是个爱冒险的人」让读者站在外面打量。
- **拉近**（角色沉浸视角）：具体细节+场景化+内心思想——「她翻过栏杆，掌心擦出火辣」把读者塞进角色皮肤里。
- **操作**：要读者评判角色时拉远（出场介绍/转折定性），要读者共情角色时拉近（危机/抉择/受伤）。一章内远近切换必须跟着意图走，不是随心情。
- **注意**：最远的叙述也不能撤出限知（见 writing-craft「深度限知」）——拉远是抽象化，不是上帝视角。

## 5. 叙事时间五技（Ch.8 :3952-4275）

- **简述（Summary）**：黏合剂——覆盖长时间/不重要过程（「三个月里他试了十七种办法」），一笔带过不展开。
- **详述（Scene）**：砖石——关键时刻展开成场景（对话+动作+感官），读者在场。
- **白空间（White space）**：空行本身是叙述手段——用段落空行切换时空/视角/基调，不写过渡句（「与此同时」「让我们回到」是禁语）。
- **倒叙三规则**：①**实物锚进出**——从当前场景的物件/动作滑入回忆，再靠同一锚滑回（触到旧信→三年前→信烧尽→回到现在）；②**禁直白过渡句**——不写「他回想起从前」；③**不嵌套**——回忆里不再套回忆，一层封顶。
- **慢动作（Slow motion）**：危机时刻高度聚焦随机小细节（打斗中对手袖口的线头）拉长时间，禁感叹式内心喊话（「天啊」「完了」）——聚焦物让读者自己感觉时间的慢。
- **触发问句**：这段时间流逝读者需要快进还是身临其境？——长时间用简述，关键时刻用详述，切换时空用白空间，重要往事用倒叙（带锚），高潮用慢动作。
