# revision-workflow.md：设定/大纲/卷纲修订工作流（构建环）

> 修订对象：`设定/`（世界观/人物/势力/题材定位）、`大纲/大纲.md`、`大纲/卷纲_第X卷.md`——构建环的"计划层"资产。
> 边界：**细纲修订归 write**（B1b outline-workflow 的失效检查与重建）；**正文与追踪不在此修订**（已写事实按 P4 走"顺势圆"提示，不自动改动）。
> 原则：修订是显式工作流，不是顺手改——先影响分析，作者裁决，留痕落盘，级联标记。

## 五步流程

### ① 影响分析（impact_scan）

作者发起修订（改设定/大纲/卷纲）时，先对每个修订对象跑确定性影响分析：

```bash
{PYTHON} {build skill 根}/scripts/impact_scan.py --project {项目根} --keyword {关键词/实体名} [--keyword {更多}...]
```

- 输出三清单（单行 JSON）：**未写细纲**（`大纲/细纲_第*章.md` 中章号 > last_committed_chapter 的命中行）、**已写正文**（`正文/第*章*.md` 中章号 ≤ last_committed_chapter 的命中行）、**追踪条目**（state 的 characters/foreshadow/timeline/information_gaps 四域命中）。
- 分界：`last_committed_chapter`（追踪 state）——≤它=已写事实，>它=计划（D2 口径）。
- 退出码：0=分析完成（无命中=空数组，仍 0——分析工具非判定器）；2=追踪未初始化或参数/读文件错误（报文明示）。

### ② 作者裁决

把三清单呈现给作者（AskUserQuestion，不做拦截）：**改 / 不改 / 缩小范围**。
- 缩小范围 → 按作者给出的子集重跑 ① 或直接进入 ③；
- 红线三条（主角核心人设、力量体系、核心主线）改动时，在 ② 前**追加一次显式确认**（D4：提示级不拦截——作者明确"继续"才进 ③）。

### ③ 留痕落盘

1. 按作者裁决修改修订对象（`设定/` 或 `大纲/` 文件）；
2. 在 `大纲/变更日志.md` **追加一行**（append-only，不覆盖不改历史）：

```
- YYYY-MM-DD | {对象：设定/题材定位.md 等} | {变更一句话} | {影响范围摘要：未写细纲 N 份/已写正文 N 章（顺势圆提示）/追踪条目 N 条}
```

> 变更日志是修订的留痕真源；全文 diff 靠 git 历史，日志只记一行摘要（D6）。

### ④ 级联标记

对影响分析清单中**未写细纲**（章号 > last_committed_chapter）且命中的每个细纲文件，在文件头追加：

```
<!-- stale: 设定修订 YYYY-MM-DD {对象} -->
```

- **正文与追踪不标不改**（已写事实按 P4：不自动改动，若确需处理走 write 侧"顺势圆"提示）；
- 已写细纲（章号 ≤ L）不标——它们在写作循环内已消费，如受影响由 write 的细纲失效检查处理；
- 标记是派生信息，write 侧在细纲补建/复核步骤消费（B1b 接线），build 不负责清理。

### ⑤ 结束与回流提示

修订完成后报告：变更日志行已追加、stale 标记数量与文件清单、未写细纲的后续处理权在 write（下次写该章时消费 stale 标记）。若修订同时是回流入口转来的提案，在回执里标注来源。

## 回流入口（开工/修订前读取）

构建环开工或修订前，先读两处现存流出，转为修订提案（走上面五步）：

1. **审查工单**：`review_tickets.py list --project {项目根} --status open`——dimension 为设定类（structure/character/consistency/factual/world 相关）的 open 条目转为修订候选；处置走工单 resolve（fixed/dismissed + 一句证据）。
2. **追踪连贯性风险与信息差冲突**：读 `追踪/上下文.md` 的 `## 连贯性风险` 与 `追踪/信息差.md` 的冲突条目——影响设定/大纲的转为本轮修订提案（不直接改追踪，事实层归 write）。

> 回流不新开管线：以上两处是既有产出（批 6 工单 / 批 3a 信息差），build 只消费并转提案（P6）。

## 明确不做

- 不回滚（一期无版本树；git revert 是仓库级能力，本书项目无书仓管辖权）；
- 不改正文/追踪（已写事实的处置在 write 环）；
- 不自动级联（stale 标记只写未写细纲；处理权在作者/write）。
