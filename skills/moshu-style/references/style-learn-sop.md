# 文风学习 SOP（style-learn-sop.md）

> **何时加载**：moshu-style Stage 4 执行时。本文件是从任意量原文提取写作风格（表达层）的详细操作步骤——**不依赖拆书任何产物**（黄金三章深度拆解/章节摘要/拆文报告均不需要），对话技法从样本原文直接归纳。
>
> **输出**：`文风库/文风.md`（模板见 SKILL.md「产出规范」）。

## 前置

- 样本已准备（Stage 3）：`文风库/_source.md` 或内存中的样本
- **采样原则（档位制——样本覆盖面直接决定文风质量与写作效果）**：
  - **标准档 5-6 章（推荐，正式学习文风用）**：完整章节全文，综合覆盖——**通用四类描写类型**（对话推进 / 动作打斗 / 景物开篇 / 情感心理，每类至少 1 章）+ **位置分散**（开头/中间/后期各 2 章）。5-6 章的样本量（2-3 万字）能让锚点覆盖四类叙事功能且每种描写类型都有真实素材，文风文件对写作的指导覆盖面最广。**采样维度只用通用描写类型**——题材场景（推理/战斗/日常等）不属于文风采样需求（那是拆书技法总结的职责），不进采样维度
  - **最小档 2-3 章（快速评估用）**：判断"这本书值不值得学/拆"、或时间受限时使用——四类描写类型保底 + 按书挑 1-2 类；**覆盖缺口必须在生成记录诚实标注**（如"动作类样本不足，未覆盖"），不编造
  - **无完整章节（粘贴片段）**→ 全部使用；样本 <800 字 → 全程 confidence: low，并提示用户补充
- **选章通用规则**：
  - 完整章节优先（前 N 字采样有"开篇偏差"——开篇 1000 字多为环境/设定密集区，对话样本稀少、形态单一，实测《大奉打更人》第 1 章前 1000 字几乎零对话）
  - 位置分散（覆盖全书文风演变，后期章节句长/成熟度可能不同）
  - **选章后快速验证**：读所选章节开头 2-3 段确认实际类型——标题判断不可靠（实测第 183 章标题"血光"但内容是传书群聊+日常，非打斗章），不符则换章
  - 逐章标注主导描写类型，写入生成记录——**文风应能回答"作者怎么写对话/景物/动作/心理"四问**

## 提取边界（通用性铁律）

**只提取表达层通用元素——任何题材的书都有的"怎么写"维度；题材层内容识别后一律排除。**

- **提取**：句长/标点/段落节奏、对话的表达手法（标签习惯/潜台词模式/语气区分）、风格词与口头禅、锚点手法
- **排除**：情节类型（推理/战斗/日常）、设定词汇（功法/宗门/望气）、人物与称呼、世界观——这些属于拆书（技法总结）范畴，识别后不写入文风产物
- 技法命名用**通用手法词**（信息分层递进/语气反差/动作先行），不用题材词（推理对话/战斗描写）；原文示例只是手法载体，标注的是手法不是内容
- 书特有内容（口头禅实例、对话变体形式）标注「书特有」，不宣称通用；换书时模板与维度可复用，书特有内容不迁移

## Stage 4-A：句长/段落/标点/对话比/虚词（确定性画像）

由**主线程**执行。调用标准画像脚本 `scripts/style_profile.py`（零依赖纯 stdlib+正则，替代手搓 one-liner）。先探测可用解释器再跑——**勿直接用 `python3`**，Windows 上它会触发 Microsoft Store 占位程序、exit 49 失败。样本路径**必须用项目内相对路径**（Windows 原生 python 会把 `/tmp/x.txt` 解析成 `C:\tmp\x.txt`，与 Git Bash 写入位置不一致）：

```bash
SAMPLE="文风库/_source.md"   # 或实际样本路径
for PYBIN in python3 python py; do "$PYBIN" -c "" 2>/dev/null && break; done
"$PYBIN" {SKILL_DIR}/scripts/style_profile.py --input "$SAMPLE" --json > 文风库/画像.json
```

JSON 落盘 `文风库/画像.json`（键名稳定，供模板摘要与仿写校验 `--compare` 复用）。把数值填进模板「整体语感（画像表）」——`confidence: high`（确定性测量，不是抽样估计）。**字段名必须照模板逐字写**：「平均句长」是下游确定性解析锚点（`check-prose-candidates.js` 按字面匹配），改成「平均 N 字」这类变体就会解析失败且不报降级。

**指标口径**（与脚本 docstring 同源）：
- **句长分布**：按 `。！？…` 分句（去空白字符数），P25/中位/P75/均值/标准差——30-50 是长句常规区，≥50 是超长句（疑似堆叠/流水账信号，写作时注意拆）
- **段落节奏**：段落按行切分（非空行 = 一段）——网文 txt 常见"一行一段"（行首缩进、无空行分隔），空行分隔格式同样兼容；段均句数配合人工归纳（单段单动作 vs 多动作堆叠、断行习惯）
- **标点密度谱**：逗/句/叹/问/省略/破折，每百字出现次数（省略号/破折号按串计一次）——配合人工归纳（高频用法+示例）填「标点习惯」；**破折/省略占比高 → 文风标注「注意克制」**（banned-words 硬安全线禁破折号/省略号，写作时仍按 Gate 归一，统计只作理解）
- **对话叙述比**：引号（「」“”『』）内去空白字数占比——对话/叙述比重底座
- **句首二字 bigram Top5** 与 **虚词密度**（内置虚词表命中/每万字，mo-shu 自定口径）：作「词汇指纹」的统计底座

**Bash/Python 不可用时的降级**：跳过确定性统计；整体语感段写「解释器不可用，跳过确定性统计」；`confidence: low`。

## Stage 4-B：词汇指纹（AI 从样本归纳）

**中文分词无轻量确定性方案，词频归纳由 AI 完成**（与"三层分工"一致：脚本做可数的统计，AI 做语义归纳）。通读样本，归纳：

- **高频名词 Top 10**：标注 `主题词` 或 `风格词`——**区分原则：词频本身不是风格**。主题词随题材变（玄幻的"灵力/宗门/境界"、都市的"公司/合同"），不构成风格；风格词跨题材稳定（"光景/由头/眉眼"这类作者的常用称呼与具象词），才是声音标记
- **高频动词 Top 8**：同上区分（主题动作 vs 风格化动作——"祭出/催动"是主题，"转身/抬眼/顿了顿"是风格）
- **高频副词 Top 8**：**过度使用的副词 = 需要克制的噪声**——若样本中 "竟/忽然/仿佛/蓦然/不禁/猛地" 等出现 2 个以上且频率明显偏高 → 标注 `过度副词警告：{词列表}`（写作时克制，与去 AI 味联动；这些词同时是 banned-words/anti-ai-writing 的高频 AI 标记词——作者习惯性滥用会放大 AI 腔）
- **固定搭配/口头禅 3-5 条**：作者反复使用的短语（"说到底""话锋一转"）——写作时倾向使用（风格词），但不强制

输出到模板「词汇指纹」节；`confidence: med`（样本归纳，非统计）。

## Stage 4-C：对话技法（从样本直接归纳）

- **潜台词模式**：扫描样本中的对话段落，识别 2-3 种典型手法——问非所答、语气反差、信息隐瞒、话里有话、信息分层递进等；每种附 1 段原文示例（300 字内）。**提取的是对话的表达手法，不是对话的情节内容**（"审讯/谈判/推理"是题材，不入技法名）
- **对话标签习惯**：样本中说话动词的多样性（说/道/问/喊 vs 重复单一）、动作替代说话标签的频率、对话与动作的穿插比例
- **角色语气区分**：样本含多个说话者时，归纳主角和 1-2 个核心配角的句式差异（口头禅/句长/用词），引用原文样本句
- 样本无对话（纯独白/纯设定）→ 对话技法段写「样本无对话，跳过」或省略，不编造

## Stage 4-D：原文锚点片段（四场景分型）

- 从样本中选 4-6 段，**按写作场景覆盖**（few-shot 场景库——四类各 1-2 段）：
  1. **战斗**——动作/打斗/交锋怎么写
  2. **对话**——对话推进/潜台词/标签习惯
  3. **情绪**——心理/情感/氛围渲染
  4. **过渡**——场景切换/时间跳跃/转场衔接
- 样本无该场景 → 如实标「缺——样本未覆盖」，不编造（如纯对话文没有战斗段）
- 每段 300-500 字；标注**场景 + 基调**（如"场景：战斗；基调：紧张"）；基调按样本内容判断（紧张/悲伤/轻松/热血等）
- **锚点必须逐字连续切片，禁止改写/缩写/跳段/拼接**：moshu-narrative-writer 拿锚点当 few-shot 直接学，标注的行号要能回查来源。落盘前逐段抽 1-2 句 `grep -F` 回 `文风库/_source.md`（粘贴来源）或原文文件，grep 不到即说明被改写或拼接——重切为忠实连续片段。确需跳过中间过渡段时，分别标各自真实行号（如「行264-267 + 行269-270」）并在引用块内用「（……中略……）」显式断开
- 少于 1 段 → `文风可用：否：锚点不足`（few-shot 核心缺失）
- **场景标注消费方式**：写作时 narrative-writer 按场景名取用锚点（写打斗段先看「战斗」锚点）——标注在锚点旁，不改写书侧召回逻辑（本批 D4 不动 write 侧）

## Stage 4-E：仿写校验（方案 C，学后验证）

**仿写**：AI 按画像 + 锚点写 **200 字仿写**（选一样本覆盖的场景；用锚点的手法——句长节奏/标点习惯/对话标签，不用锚点的字句；写的是「这本书会怎么写」的样张，不是摘抄）。

**度量**：调脚本生成仿写画像 → `--compare` 原作画像 vs 仿写画像：

```bash
"$PYBIN" {SKILL_DIR}/scripts/style_profile.py --input 文风库/_仿写.md --json > 文风库/画像_仿写.json
"$PYBIN" {SKILL_DIR}/scripts/style_profile.py --compare 文风库/画像.json 文风库/画像_仿写.json
```

**判级**（AI 按阈值，mo-shu 自定口径）：**句长中位相对差 >30% 或 任一标点密度差 >50% → `confidence` 降 low**；否则保持原判级。两画像 JSON 与相对差表附入 `文风.md`「仿写校验」节（落盘时一并写入）。

**阈值依据**：arXiv 2509.14543「分布锚比指令可靠」——句长/标点的分布级偏差比逐句对比更稳定，作为学后校验的度量锚。

## Stage 4-F：落盘

按「产出规范模板」节填写 `文风库/文风.md`：

- **生成记录**：来源（本地文件路径/粘贴）、抽样位置、**抽样章节及主导描写类型**（如"第1章=景物+心理开篇 / 第100章=对话 / 第500章=动作+对话"）、生成时间、`文风可用：是/否`
- **覆盖前确认**：`文风库/文风.md` 已存在 → AskUserQuestion「替换现有文风？」
- 每段标 confidence（high=确定性统计 / med=样本归纳充足 / low=样本不足或降级或仿写校验降级）

**confidence 语义**：

| 值 | 触发条件 | 下游处理 |
|---|---|---|
| `high` | 确定性统计（句长/标点）；样本归纳且证据极强（多章交叉一致）也可 high | moshu-narrative-writer 优先采纳 |
| `med` | 样本归纳且样本充足 | 参考，与默认 Gate 协商 |
| `low` | 样本不足/片段 <800 字/仿写校验未过阈值 | 让位回默认 Gate |

**可用性语义**：

- `文风可用：是` → 写作每章召回可用
- `文风可用：否：{原因}` → moshu-explorer 读取时返回 `gaps.profile_degenerate: true`；写作按默认 Gates

**生成自检（落盘前 3 条）**：

- [ ] 画像表为确定性统计（脚本产物；解释器不可用则标 low，不假装 high）
- [ ] 锚点 ≥1 段且可回查（`grep -F` 验证逐字连续）
- [ ] 词汇指纹区分了主题词/风格词；过度副词已标注（无词频数据则整节标 low 或省略，不编造）

## 失败模式与降级

| 场景 | 降级策略 |
|---|---|
| 源文件不存在/不可读 | 提示重新提供路径；粘贴场景不存在此问题 |
| 非 UTF-8 且转码失败 | 报错说明编码，提示转码后重试 |
| 样本 <800 字 | 全程 confidence: low；提示用户补充 |
| Python 解释器不可用 | 跳过句长统计，confidence: low |
| 样本无对话 | 对话技法段省略，不编造 |
| 锚点不足 1 段 | `文风可用：否：锚点不足` |

## 与拆书的关系

- 本 SOP 是**纯表达层**方法论——不依赖拆书任何 Stage 产物
- 拆书 Stage 2-7「技法总结」产拆解结论（情绪交替/可借鉴技巧/分层学习路线/不可模仿）——与本文件互补不重叠
- 需要完整对标时：`/moshu-analyze` 全量拆解（情绪模块/节奏/技法总结）

## 与写书的关系

- `文风库/文风.md` = moshu-write 写前准备 (d) 文风召回唯一来源（每章必做）
- 缺失/不合规时写书侧交互提醒（「用 /moshu-style 生成 / 跳过用默认 Gate / 自写约束引导」）
- 写作时 narrative-writer 消费：句长带（自检）/ 锚点（few-shot）/ 对话技法（潜台词优先）
