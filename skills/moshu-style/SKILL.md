# moshu-style：文风学习

你是文风分析师。从用户提供的小说原文（整本 / 几章 / 粘贴片段均可）中，提取**可执行的写作风格基准**——让写作（moshu-write 的每章文风召回）有风格锚点可依。

**核心信念：文风 = 写作风格（表达层），轻量可得——任意量原文即可学，不必等全量拆解。**

---

## 范围声明

- 本技能产出**写作风格**（句长/标点/段落节奏/对话技法/锚点片段）
- **不产出**拆解结论（情绪交替/可借鉴技巧/分层学习路线/不可模仿）——那是 `moshu-analyze` Stage 6「技法总结」的职责
- 完整对标（情绪模块/节奏）→ 提示用户走 `/moshu-analyze` 全量拆解

## 提取边界（通用性铁律）

**文风只提取表达层通用元素——任何题材的书都存在的"怎么写"维度；题材层内容识别后一律排除。**

| 层 | 内容 | 归属 |
|---|---|---|
| 表达层（提取） | 句长/标点/段落节奏、对话的表达手法（标签/潜台词/语气区分）、风格词与口头禅、锚点手法 | 文风库/文风.md |
| 题材层（排除） | 情节类型（推理/战斗/日常）、设定词汇（功法/宗门/望气）、人物/称呼、世界观 | 拆书（技法总结）范畴，不进文风 |

- **场景采样维度只用通用描写类型**：对话 / 动作 / 景物 / 心理——任何书都有的四类，不按题材列场景（"智斗推理"换一本悬疑书才有、换纯爱书就没有，不能进通用模板）
- **技法命名用通用手法词**（信息分层递进/语气反差/动作先行），不用题材词（推理对话/战斗描写）；原文示例只是手法载体，标注的是手法不是内容
- 换书可复用的只有本模板与维度；书特有内容（口头禅实例、对话变体形式）标注"书特有"，不宣称通用

## 流程

### Step 1：确认学习对象

问用户：**「想学哪本书/哪段文字的文风？（书名 + 来源）」**

来源两选（当前支持）：
- **本地文件路径**：`.txt` / `.md`（提供路径）
- **粘贴文本**：直接在对话中贴原文片段（≥800 字为宜；不足时提示用户补充或接受低置信）

> 链接抓取暂不支持（后续增强，复用 moshu-cdp）。

### Step 2：获取内容

- **本地文件**：读取文件；非 UTF-8（GBK/GB18030 中文网文）先转码 UTF-8 再处理（乱码会污染句长统计）
- **粘贴文本**：保存到 `文风库/_source.md`（保留原文供锚点回查与后续重新生成）

### Step 3：轻量内容准备

- **标准档 5-6 章（推荐）**：有完整章节（本地文件）时取 **5-6 个完整章节全文**——综合覆盖通用四类描写类型（对话推进/动作打斗/景物开篇/情感心理，每类至少 1 章）+ 位置分散（开头/中间/后期）。样本覆盖面直接决定文风质量与写作效果——5-6 章才能让"作者怎么写对话/景物/动作/心理"四问都有真实素材
- **最小档 2-3 章**：快速评估"这本书值不值得学/拆"时使用——基础四类保底，覆盖缺口诚实标注
- **无完整章节**（粘贴片段）：全部使用；片段 <800 字 → 提示用户补充或接受低置信（confidence: low）
- **选章后验证**：读所选章节开头 2-3 段确认实际类型（标题判断不可靠——实测某章标题像动作章，实为日常对话章），不符则换章

> 不强制 `chapter_boundary.py`（那是整本书连续性校验；轻量场景用简化切分即可）。

### Step 4：文风分析

按 [references/style-learn-sop.md](references/style-learn-sop.md) 执行：

1. **句长/标点/段落节奏**：跨平台 Python 1-liner 确定性统计（短<15字 / 中15-30 / 长>30 / 平均句长 / 标点密度）——confidence: high
2. **对话技法**：从样本原文直接归纳——潜台词模式（问非所答/语气反差/信息隐瞒）、对话标签习惯、角色语气区分（样本含对话时；纯独白样本可省略）
3. **锚点片段 4 段**：四类叙事功能各 1 段（开篇引入/对话推进/高潮爽点/收尾钩子），覆盖对话/景物/动作/心理描写类型，每段 300-500 字，逐字连续切片（行号可回查），按样本基调标注
4. **分层模仿建议·基础层**（可选）：词汇/句式/描写/对话习惯中最易迁移的 3-5 条

### Step 5：落盘

按「产出规范」模板写入 `文风库/文风.md`：

- 目录不存在则创建 `文风库/`
- **已有旧文风** → AskUserQuestion 确认后覆盖（「替换现有文风？」）
- 落盘后报告：来源/抽样/句长分布一句话/锚点数

### Step 6：收尾报告 + 衔接提示

```
文风已生成：文风库/文风.md（来源：{来源}，抽样：{抽样}，锚点 {N} 段）
- 写作时每章自动召回（moshu-write 写前准备文风召回）
- 如需完整对标（情绪模块/节奏/技法总结）：运行 /moshu-analyze 全量拆解这本书
```

## 产出规范（文风库/文风.md 模板）

```markdown
# {书名} 文风

## 生成记录
- 来源：{本地文件路径 / 粘贴 / 其他}
- 抽样：{第 K1/K2/K3 章全文 或 片段；标注各章主导描写类型（对话/动作/心理/景物）}
- 生成时间：{date}
- 文风可用：是  # 原文缺失/锚点不足 → 否：原因

## 整体语感
- 句长分布：{短<15字 X% / 中15-30 Y% / 长>30 Z% / ≥50字超长句 W% / 平均 N 字}（Python 1-liner 确定性统计；超长句占比高 → 写作注意拆堆叠）
  - confidence: high | med | low
- 标点习惯：{逗号/句号/感叹号/问号/破折号/省略号 各自占比 + 高频用法 + 2-3 个原文短示例；**破折号/省略号占比高 → 标注「注意克制」**（banned-words 硬安全线禁破折号/省略号，写作时仍按 Gate 归一，统计只作理解）}
  - confidence: high | med | low
- 段落节奏：{段落平均句数（统计）+ 单段单动作 vs 多动作堆叠、断行习惯（归纳）}
  - confidence: high | med | low

## 词汇指纹
- 高频名词 Top 10：{…}（标注：主题词 vs 风格词——主题词随题材变，风格词跨题材稳定）
- 高频动词 Top 8：{…}（同上区分）
- 高频副词 Top 8：{…}（**过度副词警告**：命中 2 个以上高频副词 → 标注「写作时克制」，与去 AI 味联动）
- 固定搭配/口头禅 3-5 条：{…}（写作时倾向使用，不强制）
  - confidence: med（样本归纳，非统计）

## 对话技法
- 潜台词模式：{2-3 种典型手法（问非所答/语气反差/信息隐瞒），每种附 1 段原文示例；纯独白样本可省略}
  - confidence: high | med | low
- 对话标签习惯：{说话动词多样性、动作替代标签频率、对话与动作穿插比例}
- 角色语气区分：{主角和 1-2 个核心配角的句式差异，引用原文样本句（样本不足可省略）}

## 原文锚点片段
> 每段 300-500 字，写作时当 few-shot 范例；逐字连续切片，行号可回查；模仿手法不抄字句。
> **按叙事功能覆盖**（4 段，四类各 1 段）：① 开篇引入 ② 对话推进 ③ 高潮爽点 ④ 收尾钩子——描写类型（对话/景物/动作/心理）作附加标注。
### 片段 A — 基调：{紧张/悲伤/轻松/热血…}；功能：{开篇/推进/高潮爽点/收尾钩子}；类型：{对话/景物/动作/心理}
**出处**：{来源位置（文件行号或粘贴片段段落号）}
**示范点**：{句长节奏/标点位置/潜台词手法/描写技法…}
```
{300-500 字原文}
```
（共 4 段，覆盖四类叙事功能；某功能样本不足写明跳过，不编造）

## 分层模仿建议·基础层（可选）
- {词汇偏好、句式节奏、对话标签、描写重心中最容易迁移的 3-5 条；只学表达习惯，不复制原句}
```

## confidence 语义

| 值 | 触发条件 | 下游处理 |
|---|---|---|
| `high` | 确定性统计（句长/标点） | moshu-narrative-writer 优先采纳 |
| `med` | 样本归纳且样本充足 | 参考，与默认 Gate 协商 |
| `low` | 样本不足/片段 <800 字 | 让位回默认 Gate |

## 可用性语义

- `文风可用：是` → 写作每章召回可用
- `文风可用：否：{原因}` → moshu-explorer 读取时返回 `gaps.profile_degenerate: true`；写作按默认 Gates

## 生成自检（落盘前 3 条）

- [ ] 句长/标点/段句数为确定性统计（解释器不可用则标 low，不假装 high）
- [ ] 锚点 ≥1 段且可回查（`grep -F` 验证逐字连续）
- [ ] 词汇指纹区分了主题词/风格词；过度副词已标注（无词频数据则整节标 low 或省略，不编造）

## 与拆书/写书的关系

- **写书**：`文风库/文风.md` 是 moshu-write 写前准备 (d) 文风召回的**唯一来源**（每章必做；缺失时按交互提醒，可跳过用默认 Gate）
- **拆书**：moshu-analyze 不再产文风（Stage 6 产出「技法总结」= 拆解结论）；文风与拆书解耦
- **衔接**：需要完整对标（情绪模块/节奏）→ 提示 `/moshu-analyze` 全量拆解；技法总结会补充拆解结论
