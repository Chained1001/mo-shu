# 写作技法卡（Craft Cards）

### 技法卡：多人锚点沉默

- 触发：三人以上连续对话，群戏糊成一片、读者靠说话人标签认人
- 写法：给每个在场者一个**锚点**（一个动作/一个物件/一个习惯反应），轮到他说话前先落锚点动作；沉默者的反应（抬头/停杯/攥紧）也是对话的一部分
- 注意：锚点每人最多一个，重复使用要有变化；失败模式=锚点变成复读机、沉默者被忘在场景外

### 技法卡：高压嬉笑托底

- 触发：高压/生死/对峙场景全员绷紧，对话只剩信息与威胁、失去人味
- 写法：高压中保留一两个**功能性的调侃/口癖/错位反应**（不是插科打诨）——用轻松语气托住紧张，反而放大压迫（对比效应）
- 注意：调侃必须符合角色声线（搞笑担当让位原则）；失败模式=高压场景被玩笑泄气、或角色不分场合逗趣

### 技法卡：爽点后停顿

- 触发：爽点/打脸/反转释放后立刻接下一事件，读者没有消化拍
- 写法：爽点释放后给**一拍停顿**——一个在场反应（安静、对视、某人的小动作）或一句短收束，让读者"落下来"再继续；停顿是爽感的延长线
- 注意：停顿一拍就够（过度就是拖戏）；失败模式=每次爽点都套同款停顿（变套路）、或停顿反而泄了情绪

### 技法卡：证据投放顺序

- 触发：推理/解谜/真相线，读者跟不上或提前猜穿
- 写法：证据按**可参与性**顺序投放——先给读者和主角同起点的信息，再给主角多一步（信息差），关键证据在读者"快猜到"时投放（延迟揭示）；每份证据要改变一次行动或判断
- 注意：证据链可在后文回看成立；失败模式=证据全靠主角口述（读者无法参与）、或关键证据藏到揭晓才给（读者放弃推理）

### 技法卡：不可靠叙述

- 触发：第一人称/限知视角下的误导设计（与"有限认知"区分：有限是诚实缺信息，不可靠是**刻意扭曲**）
- 写法：叙述者的认知偏差要有来源（立场/创伤/利益/被欺骗），扭曲的部分要在后文**可回看纠正**（读者重读时能发现伏笔）
- 注意：扭曲必须有动机且不破坏基本信任（读者要能跟着走）；失败模式=为反转而反转、扭曲无来源、纠正后前文完全失效

### 技法卡：名场面变奏

- 触发：同类桥段第二次出现（升级战/再遇/求婚/打脸重复），照搬会机械
- 写法：保留**功能位**（情绪链/读者期待点），换场景/对手/代价/规则——同功能不同配方；递增或回响（第二次比第一次大/或呼应第一次的细节）
- 注意：变奏要有明确升级或回响意图；失败模式=换皮不变魂（套词复读）、或为变而变丢功能位

### 技法卡：过滤词直呈

- 触发：写「她注意到/看见/回想起/意识到/这才发现 X」——读者读到的不是 X 是转述层
- 写法：删过滤词直接呈现所见/所忆——「她注意到门开着」→「门开着」；镜头对准 X 本身，不写取景动作
- 注意：角色**自觉**的反省时刻（「她意识到自己怕了」是自我认知转折）保留——只删无意识感知流

### 技法卡：系动词激活

- 触发：「X 很 Y」状态句（她很紧张）、「显得/看起来/感到」、被动语态批量出现
- 写法：状态换主动动词+可感知动作——攥住扶手指关节白/头发飘动/脚步加快；主动动词逼你为情绪找形象
- 注意：被动三合法情形（主体未知/不重要/表无助感）别误删；静止态度场景保留系动词是刻意节奏

### 技法卡：概括化时刻（该详述还是简述）

- 触发：每一段时间流逝都等长着墨——过渡写太细或关键写太略
- 写法：长时间/不重要过程用**简述**一笔带过（「三个月试了十七种办法」）；关键时刻用**详述**展开成场景（对话+动作+感官）——问「读者需要快进还是身临其境？」
- 注意：一章内两种交替是节奏；失败模式=全程详述（拖）或全程简述（没戏）

### 技法卡：白空间剪切

- 触发：时空/视角/基调切换时写了过渡句（「与此同时」「让我们回到」）
- 写法：用段落空行完成切换，不写过渡语——白空间本身是叙述手段
- 注意：白空间切换后需有语境标记让读者快速定位（谁/在哪/何时）；失败模式=切得读者找不到北

### 技法卡：慢动作

- 触发：危机/高潮时刻节奏没压住，三句带过最紧张的一瞬
- 写法：危机时高度聚焦随机小细节（打斗中对手袖口线头/一滴汗滑落），用具体物的放大拉长时间
- 注意：禁感叹式内心喊话（「天啊」「完了」）——聚焦物让读者自己感觉时间的慢；失败模式=慢动作滥用变拖戏

### 技法卡：说「不」对话

- 触发：对话全是顺应/同意，冲突靠内心戏不靠台词——嘴上说「好」心里骂
- 写法：关键时刻让角色台词说「不」——拒绝/否认/打断，把冲突放到台面上；「不」比解释更有戏
- 注意：说「不」要符合声线与关系（敢说 vs 不敢说都是人物信息）；失败模式=人人硬刚（没层次）

### 技法卡：距离推拉

- 触发：写完整段不知道镜头该多近——情绪点没着落或读者进不去
- 写法：拉远=抽象名词+简述+典型+客观（读者评判视角：出场介绍/转折定性）；拉近=具体细节+场景+思想（角色沉浸：危机/抉择/受伤）——问「此刻要读者离角色多近？」
- 注意：拉远不撤出限知（是抽象化不是上帝视角）；远近切换跟着意图走，不随心情

### 技法卡：水晶鞋合脚

- 触发：心理转折写成了内心宣告（「她终于明白自己错了」）——转折无外化行动
- 写法：心理转折必须由**可感知行动**引发与呈现——她明白自己错了，靠她退还信物/起身道歉/放下仇恨的某个动作落地（水晶鞋原则：内在变化穿上可见的鞋才合脚）
- 注意：行动要具体可验（读者能看见）；失败模式=转折挂在情绪词上（读者信不过）
