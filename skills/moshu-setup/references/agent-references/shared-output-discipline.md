# shared-output-discipline：结构化产出纪律（共享 base 段）

本文件是 agent 模板产出结构化数据（JSON 载荷/机器消费结果）时的统一纪律。
模板只允许**锚点引用**本文件（逻辑路径 `moshu-setup/references/agent-references/shared-output-discipline.md`），禁止把正文复制进模板（单副本原则）。

## 一、输出纯 JSON

- 直接输出单个 JSON 对象，**不带 Markdown 代码围栏**（不用 ```json … ```），不带 prose 解释文字。
- 无法满足时返回 `{"error": "<原因>"}`，不输出半成品。

## 二、JSON 字符串安全化（ASCII 直引号）

- 字符串内一律使用 ASCII 直引号 `"`；内容中的英文双引号写成 `\"`。
- 换行写成 `\n`，制表符写成 `\t`；原文片段含引号无法转义时，可把英文双引号替换为中文弯引号后再输出。
- 禁止尾随逗号（`},` / `],`）；键名用 ASCII 直引号包裹。

## 三、先落临时文件，再 `--input` 提交

- 结构化载荷（追踪事务/审查工单/机检输入等）一律先写临时文件，再以 `--input <文件>` 提交给确定性脚本。
- 不进对话复述、不进 argv 内联。

## 四、输出前自检三问

1. 必需字段齐全？
2. 枚举值合法（落在约定枚举内）？
3. 空集合也显式写 `[]` / `{}`，不省略？
