# 场景卡集合（Scene Cards）

高频场景的可引用写作模板。**冷路径**——细纲设计场景或写正文遇到对应场景类型时按需取用。

> 来源：V7 场景卡精选（35 张中取 6 张最高频）。共同原则：**先定赌注再写场面**——场景的价值在关系重排与局势变化，不在排场与动作本身；每张卡含「与近邻区分」防串场。

---

### SC-001 团战

- 适用：多人同时在场的战斗（守点/突入/混战/翻盘）
- 一句话：谁在哪、负责什么、局势怎么变——配合可读，不靠功法名撑场面
- 规划：
  1. 先定赌注与阵型：守点/突入/混战/翻盘——双方分工与胜负判准写进细纲
  2. 立起空间与分工：前排/远程/控场/支援/主攻/诱敌——读者知道谁在哪负责什么
  3. 排局势转折点：哪次配合失手、哪次补位改变战局；避免所有角色抢同一个高光
- 落笔：先写空间与分工，再跟改变局势的关键动作；只跟关键动作，不逐一平均描写每个人；小队静默突入用手势与位置变化承载专业感
- 自查：所有人同时冲上、读者看不清谁有用 → 混乱；逐一平均描写 → 流水；凭旁白宣布胜负 → 逻辑虚化
- 与近邻区分：打斗是单对单底牌博弈；比武大会是赛制梯度；本条是多人分工配合

### SC-002 谈判对峙

- 适用：以筹码交换为骨架的博弈戏（摊牌/交涉/对峙）
- 一句话：亮牌顺序与底线试探决定胜负——每次让步都有标价
- 规划：
  1. 先定赌注：谈崩失去什么、谈成付出什么——双方底线与最想要的东西不能重合
  2. 排亮牌顺序：谁先开价、谁握隐藏筹码、第几回合才亮——错开抖落，一次一张
  3. 若力量失衡，戏点在弱势方用信息或时机扳平，不硬碰
- 落笔：分回合写（开价→还价→探底线→僵持→破裂或成交），每回合双方各进一步或退一步；每次让步写清换回什么（无对价的松口即降智）；主角真实底线留在视角内；可用逼仄环境加压
- 自查：一次性宣读全部条件 → 无回合；让步无对价 → 降智取胜；谈完处境没变 → 缺余波（成交埋隐患/破裂留引线）
- 与近邻区分：吵架冲突是逼近伤口的情绪对抗、不以成交为目标；本条以筹码交换定胜负

### SC-003 真相揭露

- 适用：铺垫回收型揭晓（揭穿/身份败露/真相大白）
- 一句话：以铺垫回收清单为骨架——揭露是转折点不是收尾，后果当章落地
- 规划：
  1. 清点要回收的铺垫：这场揭露兑现哪几条前文伏笔——无对应铺垫的真相不在此揭
  2. 设计现场压力：在对峙/逼问/危机边缘揭晓，让真相带着代价出场，不搞安全复盘
  3. 想清即时后果：谁的处境翻转、哪段关系破裂/重建——不可逆变化当章就要发生
- 落笔：分层抖落（疑点→松动→反转→坐实），每回收一条对上一条前文伏笔；揭底嵌在现场行动里，禁止脱离情境的大段独白解说；被揭方视角写真实震惊与应对，揭露方视角的证据须是前文已铺的
- 自查：真相无前文铺垫 → 凭空；安全场合平铺直叙 → 无压力；揭露后局面无变化 → 缺不可逆后果
- 与近邻区分：当众翻盘可只逆转当场局面不回收长线铺垫；本条以铺垫回收+不可逆后果为核

### SC-004 重逢

- 适用：今昔对照的关系再会（久别/故地/旧识）
- 一句话：表面克制与细节失控撑起旧账张力——别一见面就把旧账说尽
- 规划：
  1. 先定这场重逢改变什么：确认关系回不去/试探立场/揭开旧账——双方带什么旧账入场写进细纲
  2. 立今昔对照：同一个人、同一地点、同一个习惯，新旧落差照出两人和局势变了什么
  3. 定克制外壳：公开场合/职业身份/第三人在场——用体面压住暗流
- 落笔：表面克制、细节失控（语气平稳，却让捏皱的登机牌、停顿的称呼暴露情绪）；情绪信息一点点渗，谁先提那件不能提的事是本场张力节点；假和解守住中间地带（礼貌与旧情都保留，每句问候像在试刀）
- 自查：只剩空泛怀旧无具体新旧变化 → 空转；一见面倾倒旧账 → 信息倾泻；假和解直接翻篇或翻脸 → 张力流失
- 与近邻区分：关系跃迁当场跨档；离别守夜是时间流逝下的未尽之言；本条是今昔对照，关系可不动档

### SC-005 宴会

- 适用：宴席庆典里的社交冲突（赴宴/席间暗战/当众发难）
- 一句话：宴会的价值在人物关系重排，不在吃喝排场——每个发难者给一个可见动机
- 规划：
  1. 先定真正目的：暴露谁的立场/结成或破裂哪段关系/当众定下哪个名分
  2. 座次与身份立成压制格局：谁高谁低、谁能开口谁只能陪坐——主角初入席位的处境即起始压力
  3. 信息位错开：刁难方真实意图、主角反击筹码、席上某人隐藏立场——不在开席就摊牌
- 落笔：写节点不写流水（入席→敬酒/刁难关键回合→当众交锋→散席余波）；每个发难者动机可见；节庆转惊变先把热闹写满，再用一个小失拍撕开场面；主角底牌留在视角内，当众揭穿时机才是揭示位；散席留至少一条离席线索
- 自查：发难无动机 → 工具化；打脸筹码早抖 → 失重；散场即了 → 注水
- 与近邻区分：群像日常无座次压制；多人会议博弈以正式决议为目标；公开评议是结果公布反应场

### SC-006 审讯

- 适用：沉默施压逼破绽的对抗（问讯/诱供/逼供）
- 一句话：真正的压力来自空白——知道何时不问，让对方自己补漏
- 规划：
  1. 先定要撬出什么：口供/破绽/关系裂口——审问方已知什么、想让对方补出什么写进细纲
  2. 设计施压手段：沉默/重复确认/故意摆错的时间线/错位信息——不靠拍桌大吼
  3. 排心理崩口：嫌疑人在空白逼迫下自己露出破绽，破绽点提前想清
- 落笔：用沉默与节奏施压（水杯/钟表/灯光/停顿比吼叫更压人）；把前后颠倒的证据推过去，安静等对方喉结滚动——破绽由对方自曝；审问方每一步都有目的，读者看得出这是设计；审问方底牌留在视角内
- 自查：互喊互骂无设计 → 空转；只靠拍桌 → 手段单一；审问方直接说破而非逼出 → 张力落空
- 与近邻区分：搜证是空间线索探索；庭辩是规则场上的证据攻防；本条是封闭对峙用沉默与节奏逼自曝
