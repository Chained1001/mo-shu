# 模型产出质量评测（evals）

目标：让"模型产出的正文质量"可评估、可回归。当检测器或写作方法论改动时，跑本目录评测确认质量没有悄悄变差。

## 评测什么

| 评测 | 资产 | 判定 |
|---|---|---|
| 正文 AI 味（确定性） | `samples/prose-ai-flavored.md` vs `samples/prose-clean.md` | 缺陷样本的 blocking/advisory 命中数必须显著高于干净样本 |
| 检测器回归 | `../scripts/test-ai-patterns.sh` 等（既有单元级） | CI 强制 |

本目录是**端到端基准**（整篇正文 × 全部确定性检测器），与脚本单元测试互补：单元测试验证单规则，端到端验证整篇文本的综合得分。

## 怎么跑

```bash
bash scripts/eval-prose-quality.sh
```

输出每个样本的检测器命中报告（blocking/advisory/字数），并以退出码断言回归基准（缺陷样本命中 > 干净样本）。

## 怎么加样本

1. `samples/` 下放一对"缺陷/干净"同主题文本（建议 ≥1200 字，检测器密度阈值才能触发）
2. 在 `scripts/eval-prose-quality.sh` 的断言区登记这对样本与期望关系
3. 跑 `bash scripts/eval-prose-quality.sh` 确认基准成立（缺陷 > 干净）

## 边界（诚实声明）

- 本评测只覆盖**确定性可检测**的维度（AI 味句式/退化/细纲照搬/标点）。情绪交付、节奏、爽点等主观维度需要 LLM-judge 或人工评分，不在本目录范围内。
- 样本数量少时是"基准"不是"统计显著"：它的价值是回归哨兵（改动导致分数翻转 = 立刻发现），不是绝对质量度量。
