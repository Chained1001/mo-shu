# 审核记录（规格-V2）

- 用途：规划模型对每批施工的审核往来，**单文件、按批追加节**。协议见 [README.md](README.md) §6。
- 规则：审核结论由规划模型/作者侧写入；施工模型**只能写对应批次的"整改回执"小节**；append-only。

## 条目模板（每批一审一节）

```markdown
## 批N 审核（日期：YYYY-MM-DD）
- 结论：通过 ｜ 有条件通过（条件：…）｜ 打回（问题数：N）
- 五查结果：规格符合性 ✅/❌ ｜ 验收复跑 ✅/❌ ｜ 禁止事项 ✅/❌ ｜ 范围外改动 ✅/❌ ｜ 日志完整性 ✅/❌
- 问题清单：（每条：编号 / 证据路径 / 应改什么 / 依据=规格哪条）
### 批N 整改回执（施工模型填写）
- （逐条：问题编号 → 已如何处理 → 复跑的验收命令与结果）
```
