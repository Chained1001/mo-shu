### 1.2 分步注解

#### 入口
- **技术细节**：读 `创作进度.md`（项目根⑳——书级元数据归根）；开场白四步总览（续跑降级一句话定位）；每步开始「📋 本步加载」回执。
- **产物**：读，不写（表单答完才建最小版）。
- **意义与目的**：构建态单真源——任何会话进入先对齐"这本书到哪了"。
- **心流设计**：作家翻开自己的创作笔记本，先看上次写到哪、有什么待办——不带上下文不重新自我介绍。

#### Stage 1 立意表单（五步）
- **技术细节**：分型路由四型（方向/画面脑洞/冲动/空）；字段四档表（必问=平台｜问一次=终局口径/情绪基调/口味｜可跳过默认兜底=体量/每章字数/关系线/雷区｜永不问=核心玩法/金手指/主角/世界观/梗概/标尺——AI拟+过目）；对标发现归并（步3 只暂存，登记延迟到步5 落盘——B101 时序修正）；交互纪律 6 条（封闭≤4弹窗/开放对话/过程可跳/合批≤4/选项带推荐+理由/每问 ℹ️ 三件套）；⑭ 确认三选（✅确认/✏️修改/⏸️停靠）替换所有"过目点"的单按钮。
- **产物**：`基本设定.md`㉓（原题材定位改名——七段+成品标尺节 v1）、`角色/关系.md`（⑲ 归并角色域）、`灵感种子.md`（条件，步 1 收敛时已落盘）、最小 `创作进度.md`（项目根⑳）。题材正文提示卡**退役**——内容教训归 write 侧教训档案（⑱㉔，形态 B102 定）。
- **意义与目的**：落盘物即接口——每个问句能指认它填的基本设定字段、每个字段有来源；把"为什么写、给谁看、爽什么"定成可校准的尺子，标尺 v1 是全书设计的参照原点。
- **心流设计**：作家不是先填表——是先有"我想写个XX"的痒处。**念头框接住冲动原样**（厚念头=已在脑内发酵过，最省交互）；**缺啥问啥=作家的创作自问**（写多长/发哪/给谁——问的是备忘不是表格）；**口味种子=品味的来源**（作家的品味=他最近被打动的东西，宽媒介=承认品味跨媒介）；**档位=投入决策**（试水还是全力）；**基本设定v1=笔记本第一页**（"这本书是关于什么"——作家的私人宣言，标尺初版=他预想的读者体验）；**AI 拟+过目=代笔与审阅分工**（AI 起草作家不擅长起草的，作家只做品味确认）。

#### Stage 2 备料步（L1 采风）
- **技术细节**：四路 query 无条件构造（口味锚点[有参考定向/无参考泛化]/同题材结构/人物原型/时代质感）；spawn 必含条款逐条搬入（源表 v2/fallback/Bing 禁用/CDP 状态）+主会话 CDP 预检；CF 票据登记创作进度；融合五步（≥3 文件联动→spawn caifeng-fusion 深度融合）；标尺 v1→v2 必经步；**L1 产物模板**（#071）：底色配方+模式占比必填，桥段/节拍不设（那是 L2 的）；**对表字段新增**㉘（采风要点→本书对应物→核对结果[做到/部分/没做到]→触发修改——草稿期先空，打磨环逐条填）。
- **产物**：`设定/采风-CF001-结构-备料四路.md`（L1 版）；`基本设定.md` 标尺升 v2（元数据标"v2·采风校准"）；参考档案轻档→实证档。
- **意义与目的**：拿真实市场证据校准尺子——生成向消费（把外部经验融进设定），使后续所有设计有据可依而非凭空推演。
- **心流设计**：**同行研究**——作家写玄幻前翻十本畅销玄幻的目录、书评、百科：不是抄，是摸形态（这类书长什么样、读者吃哪口、升级怎么放缓）。四路=作家调研的四个自然问题：读者吃哪口（口味锚点）/这类书怎么搭（结构）/谁的故事可借（原型）/世界的质感原料（质感）。**标尺校准=看完修正预期**——"哦，这题材读者要的是这个节奏"——校准的是心里的尺，所以变化必须逐格给作者看（不许静默改尺子=作家的尺子自己掌握）。

#### Stage 2 骨架构建
- **技术细节**：方法论装配（outline-causality 必读：前提句北极星+动机链+道德前提；雪花法/五步法/死亡三类型/中点假胜败/势力场/舞台规则）；skeleton 十二节+㉗四增量（骨架表必收性列/暗线活跃伏笔上限/埋设间距/反派差异化对照问）；自动 check_outline（blocking only——blocking 修/候选呈报不拦截）；骨架轻过目十秒级。
- **产物**：`大纲/大纲.md` v0.1。
- **意义与目的**：全书骨架立因果闭环——横向驱动链（钥匙→问题）+纵向前因注（卷尾→卷头）双环皆通才算立住；标尺的承诺在这里被排上时点（承诺兑现时点表）。
- **心流设计**：**一口气搭骨架**——作家的兴奋期：六卷走向/每卷赌注/对手/钥匙全铺开，写作状态不回头挑刺（草稿模式禁自我评判=保护兴奋期心流）；**骨架轻过目=站起来看墙**——把骨架贴墙上退两步扫一眼："走向对吗"——十秒级，不深究（细节留给打磨环）；**机检=格子的语法检查**——表有没有断链、字段有没有缺，机器管确定性，作家管好不好。

#### Stage 3 人物构建
- **技术细节**：character-construction 必读+苏式问句/升级绑弧光/人物主题卡；对话 DNA 五要素（有对标从拆文库带作派/无对标推演）；原型/质感采风产物参照消费；情绪引擎瘦身㉑（可复现模块为主干）；每卷一段话㉙补产（三幕+两次灾难）；停靠点#063 人物清单确认；可选人物评审（spawn evaluator·structure，三件套声明，只呈报）。
- **产物**：`基本设定/角色/*.md`、`基本设定/势力/`、`基本设定/世界观/`、`基本设定/情绪引擎.md`；编辑 `大纲/大纲.md`（每卷一段话）。

### 2.2 分步注解

#### 入口+认领台账 ★新（㉚）
- **技术细节**：前置检查+读创作进度（断点恢复）；**移交台账消费**：Phase B 初始清单=自产⚠️+台账项，逐条认领——卷级处理入清单，大纲层回改大纲+变更日志（认领或回退，不许静默吞掉）。
- **产物**：编辑：`创作进度.md`（台账认领状态）。

- **心流设计**：**上游遗留的交接单**——作家从大纲期带过来的待办，开工先过一遍：这卷顺手解决的解决，是大纲毛病的退回去改大纲（不在卷纲里将就——将就会留隐患到正文）。

#### Phase A 单元构建
- **技术细节**：峰值三问（B88，峰值可标来源火种）；结构预览停点（11 行总表，对话式确认不强制弹窗）；单元卡全字段（承接钩·开启钩=单元间接力，B85；敌手动机注跨卷级强制）；L2 采风按需（#071 工艺学要素：单元结构/节拍密度/伏笔手法/支线交织/配角编排/开场钩子——产物模板桥段表+情绪节拍必填）；浮现记录随手记。
- **产物**：`大纲/卷纲_第X卷.md`（11 张单元卡+卷契约节）；`设定/采风-CF*.md`（L2 版，条件）。
- **意义与目的**：整卷拆成可执行单元——每单元承诺/风险/章功能/钩子链；快写模式（不停靠）保护整卷视野：先把整卷铺完再挑毛病（B53：三停靠折叠成一个打磨环）。
- **心流设计**：**峰值三问=名场面的自觉预设**（网文作家设计卷时问"哪里值得读者截图发群"——商业自觉前置，不是写完碰运气）；**结构预览=单元清单先行**（先列 11 行看排布——此时改结构最便宜，还没写卡）；**逐单元细化=剧情梗概卡堆**（作家给每单元写一张卡，堆着看）；**快写不停靠=兴奋期一气呵成**（逐停靠打断心流，B53 的教训）。

#### Phase A 整合检验
- **技术细节**：伏笔四态/反转覆盖/跨卷呼应/线索矩阵八线/动机链核验/删主角删题材核心测试/时点兑现纯对表/期待释放排布（>5 章干带当场重排）/事件关系边三型（check_outline 查悬空引用）/防撞对照三维（登记免责/单源两维高重合→候选呈报/可选 evaluator 复核）。

- **心流设计**：**串起来检查**——连载作家的纪律手册自查：埋的要收（伏笔四态）、欠的要还（时点兑现）、线要交圈（线索矩阵）、期待别断供（释放排布）；**当场重排=发现即修**（干带不等评审——作家排章节表时发现五章没爽点会当场挪，不会"先记下来以后改"）。

- **技术细节**：对标回流五步（有对标时）；全量 check_outline blocking 清零；弹窗三选（✅/📋/⏸️——构建态记"Phase A 完成待续"）。

#### Phase B 打磨环

- **产物**：打磨记录（append-only 入创作进度）；编辑：`卷纲_第X卷.md` 及受影响文件。

#### 定稿序列（终审→三查→tracking init→标记→收尾）
- **技术细节**：终审（非抽样全场景表+设定漂移复检+追踪核验；不清零不放行）；三查（设定回写 diff 新实体+新名过 naming-cards/大纲影响回改+变更日志/冻结声明走修订流）；tracking init（第 0 章基线，next_chapter_commitments 从单元卡映射不自造）；定稿标记（write 放行依据）；遗留分类（可留三类登记去向/必清两类清零）；收尾话术㉕。

- **意义与目的**：COMMIT——卷纲定版，事实层从此归 write（build 只读追踪）；三查防设定漂移与账实分离；追踪 init 是 write 逐章事务的地基。
- **心流设计**：**收尾纪律**——连载作家的账本自觉：新人物登记（设定回写）、大纲改动留痕（变更日志）、"从此定死了哦"的仪式感（冻结声明——开写后不静默改设定，这是长篇不崩的根）；**记忆外置=连载状态板**（埋了什么伏笔/人物到哪了——人类作家靠重读笔记，AI 靠点名注入追踪文件：功能模仿非形式模仿）。
