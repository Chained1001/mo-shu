# 10-实测观察清单（实测门手册 · shadow mode 执行依据）

> **定位**：实测=打磨而非验收（作者 2026-08-28 裁定）。本文件收拢开源强化程序全程散落的观察点，是 test2-5 实测的执行手册与数据登记簿。
> **shadow mode 定义**：新机制的候选/评审输出在观察期内**只记录质量、不收紧**——先积累"误报率/采纳率/命中率"数据，收紧决策=作者裁决走小批。
> **记录方法**：每观察点按 `实测书/章区间/现象/数据/结论` 登记，append-only 追加到 §五。

## 二、横切观察点

- **token 实耗曲线**：每章 A/B/C/D 分段 + agent spawn 计量——校准「3-5 倍」估算；A 段 13 项逐项命中率（瘦身的直接依据）。
- **千章边界**：999/1000 跨界的脚本行为（fixture 已进 B68 验收，实测再验真数据）。
- **自读方法论**：卷复盘时「以读者身份重读」实际发生否、需不需要 checklist（回路三件套最后一根虚柱）。
- **六查执行**：规格侧错误的拦截率（第六查首战数据）。
- **评审者质量回路**：evaluator 各型建议采纳率分桶登记（㉕㉗为单型观察，此处横向汇总——哪一型持续产生噪音/持续被采纳），每卷复盘时汇总一次。
- **人物设计评审触发率**（实测 #020 首数据 0/1）：B77 可选触发是否被默认跳过——若持续 0 触发，「可选」实为「不做」，须改触发条件或并进 Phase B。
- **起名卡跨技能消费**（实测 #020）：naming-cards 在 volume 侧，outline Stage 3 用名字时未取用（自行提案）——B76.6 交叉副本机制是否覆盖 naming-cards 待核。
- **冷启动串联**：B76 拆分后首次开书——「开书」意图是否自动串 outline→volume→write，还是要求用户逐个调技能（步数/卡点登记）。
- **细纲-正文技能边界三信号**（审计-三期收官 F2 挂载；任一显形再议拆分，数据先行）：①细纲批会话被正文材料污染——token 曲线看建批期 chapter-core/writing-craft 是否也被加载（若是，轻修=会话内分段加载纪律，不动技能边界）②细纲需要独立重上下文深审——structure 的 related_paths 跨稿核对实测不够用 ③作者自然形成「先批量建纲、隔天再写」两段节奏——真实工作流先分 session，边界自然显形。
- **流程偏差率**（设计弱势 #1：散文编排无结构防御）：每批写作对照流程文件记录偏离——跳段/乱序/漏 A 段步骤/擅自改顺序的频次；偏高则需在关键 Phase 加确定性闸门（设计评审 2026-08-30）。
- **打磨环止损**（设计弱势 #3：循环无界）：卷级打磨实测轮次与 token 分布——若动辄 >5 轮或单轮 re-spawn 重读全稿成本过高，需加预算/轮次上限（设计评审 2026-08-30）。

1. 观察期=每机制前 2-3 个使用周期（如 B59 看 2-3 个批次、B65 看 2 次对照）；
2. 期内候选/评审只记录不改参数（阈值/上限原样跑）；
3. 数据登记 §五（append-only），每条含：观察点编号/书/章区间/现象/数据/结论；
4. 期后按数据提收紧建议（走小批+作者裁决），不凭单次印象改。

### 实测 #019 步骤告知规范（作者提出，2026-08-31）

- **优化**：每一次向用户询问信息、或流程行进到某个步骤停下来时，须**先告知**：①这一步在做什么（当前处于流程哪个环节）②为什么要问这个/停在这里（收集的信息或确认将喂给什么下游产物）③答/不答的影响（跳过会怎样）。示例：角色盘提问应带「这是 Stage 3 人物构建第一步——阵容定了之后每人生成一页（背景/弧线/对话DNA），直接喂卷纲的出场设计」。

- **作者核心质问**：「我之所以让有方法论，就是目的是能自我思考加采风能构建出好故事，而不是方法论加采风结果还是很垃圾」——举例（地图/三密度）只是引子，要求全面反思。

- **完备性模型草案（维度总清单）**：结构（卷弧线/节点/案链）｜人物深度（弧线/DNA/动机五件套）+人物规模（核心团数/具名反派数/配角分层 roster/出场编排）｜世界（力量体系+地理[舞台数与流转+每舞台场所清单]+社会[势力数与每势力具名人物数]）｜节奏（爆发密度+反派更替频率/场景多样性）｜时序（承诺兑现点）｜因果（动机链/道德前提）｜守护（尺子句/禁漂移）——每维度带最小规模参考值（量化来自对标拆文统计）。
- **作者新功能方向：参照大纲**——虚拟对标从「抽象目标三节」升级加第四节「参照骨架」：从采风合成**具体的**结构骨架（卷数/舞台流转/反派梯队数量与更替/人物群规模/案链密度——数字+结构不是原则），Stage 2 **对着做差**构建。三收益：①采风消费从「吸收原则」变「对照实体」②规模基准自然浮现（参照骨架天然显示大奉式结构≈N 反派/M 场所）③预填确认应用到构建层（参照→己纲→差异即讨论点）。转译纪律适用（借骨架不借内容）。
- **配套：采风量化基准萃取**——要素表加「量化基准」行（参考作品卷数/具名人物数/反派数/场所数/换图频率/案链密度）。
- **处置**：C16 候选（参照大纲+完备性模型+量化采风一体包）；与 C14④/P11 合并整体回顾。
- **结论**：终极缺口不是某份方法论，是把散装方法论装配的总装图+量化锚；参照大纲让采风从「读过」变「用上」。

### 实测二期 #040 作者裁定：作家心流是第一性原理（2026-08-31，架构收口之锚）

- **作者原话要义**：这里的重点最底层逻辑和核心思想是——**专业的人类网文作家，在构建故事这个步骤的心流是什么**。

### 设计裁定 #059 写作模式定型：两意图模型+三技能契约+改稿两路（2026-09-01，#058 延续）
