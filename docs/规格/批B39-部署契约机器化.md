- 版本：v1.0（2026-08-25）
- 依据：架构建议 #4（B31 P1 延伸）——部署清单类事实（agent/hook 数、sentinel 字段、CLAUDE.md 标准节、章节范围格式）散落文档/代码/测试，双份维护反复漂移（B31/B32 计数过期、B37 章节范围双模板）
- 性质：契约扩展 + 守卫断言收口，零行为变更

## 一、现状事实

- current-contract.json 已有 agents_version/setup_skill_version/topic_decision_phase/required_outline_sections 等，无部署清单域
- deploy.py SENTINEL_FIELDS(6)/MANAGED_SECTIONS(5)、deploy-manual 数字、SKILL.md 计数、next_step.py 章节范围正则、build/write 模板格式——各自维护

## 二、设计

current-contract.json 新增 `deployment_manifest` 域（部署清单事实唯一真源）：
```json
"deployment_manifest": {
  "agents_count": 8, "hooks_count": 8, "rules_count": 4,
  "sentinel_fields": ["deployed_at", "agents_version", "setup_skill_version", "target_cli", "resolver_strategy", "references_dir"],
  "claude_md_sections": ["Skill 路由表", "文件结构", "协作规则", "作者控制点", "Compact 后恢复上下文"],
  "chapter_range_format": "第{N}-{M}章"
}
```

check-current-skill-contracts.py 新增 `deployment_manifest_findings()`：断言
1. deploy.py 源码 SENTINEL_FIELDS 元组与契约一致（逐字段）
2. deploy.py 源码 MANAGED_SECTIONS 元组与契约一致
3. deploy-manual.md 含「8 agent files exist」；SKILL.md 含「8 个 agents」（agents_count）
4. next_step.py 源码含「第」前缀与 `[-—~至]` 范围正则形态
5. workflow-build.md 与 artifact-protocols.md 的「章节范围」模板行均含「第」前缀（chapter_range_format 口径）

## 三、文件级改动清单

1. `scripts/current-contract.json`：+ deployment_manifest 域
2. `scripts/check-current-skill-contracts.py`：ContractManifest 加字段 + parse 校验 + deployment_manifest_findings() + main 接入
3. `scripts/test-current-skill-contracts.py`：fixture manifest 补 deployment_manifest + 违规场景断言（数字不符红/字段缺红）

## 四、禁止事项

- 不改 deploy.py/next_step.py 可执行逻辑（守卫断言迁就代码，代码迁就契约——契约是唯一真源，不符即红）
- 不改既有契约域

## 五、验收命令

1. `python scripts/check-current-skill-contracts.py` → 全 PASS
2. `python scripts/test-current-skill-contracts.py` → 绿
3. 违规验证：临时改契约数字 → 守卫红（复现后还原）
