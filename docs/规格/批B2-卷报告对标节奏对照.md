## 4. 新文件设计

**A. 坐标表固化格式**（workflow-build 回流节模板）：

```markdown
### 对标结构坐标
| 点位 | 对标章位 | 本卷计划章位 | 事件锚点（关键词） |
|---|---|---|---|
| 1/4 点 | 对标第{X}章 | 本卷第{Y}章 | {词1、词2} |
| 中点 | 对标第{X}章 | 本卷第{Y}章 | {词1、词2} |
| 3/4 点 | 对标第{X}章 | 本卷第{Y}章 | {词1、词2} |
```

**B. volume-report 第④节算法**（确定性、零 LLM）：

1. **卷纲定位**：优先 `--volume N`（新可选参数）→ `大纲/卷纲_第N卷.md`；缺省时 glob 卷纲并用既有章节范围正则探测包含 [A,B] 的卷；多卷命中/无法解析 → `skipped_ambiguous_outline`（报告注明，不失败）。
2. **前提**：卷纲无「### 对标结构坐标」节 → `skipped_no_coordinates`（老卷纲兼容路径，报告只多一行说明）；有表即对照（对标章位"—"时该列输出 —）。
3. **解析**：逐行正则匹配表行（点位/对标章位/计划章位/锚点词）；计划章位解析失败 → 该行 `unparseable`。
4. **落点检测（每行）**：锚点词集 → ①正文：`正文/第{A}-{B}章` 文件按章号升序，首个命中任一关键词的章 = `actual_chapter`；②辅助：timeline_events 的 `objective_fact`/`reader_knowledge` 命中 → 事件 id + first_recorded_chapter 列表。均未命中 → `not_found`；锚点空 → `unanchored`（只报计划章位）。附 grep 命中明细（文件:行）。
5. **偏差** = actual − 计划；输出对照表 + 偏差行 + 命中明细。**候选性质：不影响退出码、不写任何状态**。
6. MD 追加「## 对标节奏对照（候选呈报）」节；JSON 增 `benchmark_rhythm_check` 键（rows/skipped/degraded 结构）。

## 6. 守卫与 CI

既有守卫全覆盖；无 yml 变更；capability-wiring 不需改（volume-report 能力 producer 未变）。

## 7. 回滚点

单提交 revert；报告为按需产物，无迁移无状态。

## 8. 禁止事项

1. 禁止偏差影响退出码或写入任何文件状态（候选永不拦截）。
2. 禁止改动第①②③节任何输出（向后兼容：老项目报告只多一行 skipped 说明）。
3. 禁止语义匹配（只做关键词 grep；匹配质量靠构建时锚点填写纪律）。
4. 禁止重读 `对标/{书}/剧情/节奏.md`（对标章位已在坐标表转录；避免第二解析面——范围收敛决策，见 §9）。
5. 禁止动追踪 schema 与既有命令语义。

## 9. 范围收敛记录

原研讨提到三方对照（含重读对标节奏.md）；规格化时收敛为两方（卷纲坐标表 + 实际落点）——对标章位在构建回流时已转录进坐标表，重读节奏.md 只为校验转录、徒增解析面。节奏.md 模板加固（关键点章号固化）移出本批，未来若有工具直读需求再立项。
