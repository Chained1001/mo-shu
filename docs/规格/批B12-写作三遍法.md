## 一、核心变更

chapter-core.md 的 B 段（正文执行与字数验收）从**单遍写作**重构为**三遍法**——每遍换一顶帽子（创作帽→读者帽→技艺帽），每遍先读方法论书对应章节再操作。

### 1.1 现状缺口

| 三遍法应有 | mo-shu 现状 | 缺口 |
|---|---|---|
| Pass 1 快写 | ✅ B 段"跟着细纲写正文" | 已有，但没明示"禁止边写边改" |
| Pass 2 读者重读 | ❌ 完全缺失 | 写完直接进 C 段机检 |
| Pass 3 技艺打磨 | ⚠️ C 段部分覆盖（仅机器可检项） | 缺语义层打磨（情绪/感官/文风/句式） |

### 1.2 三遍定义

| 遍 | 名称 | 帽子 | 做什么 | 禁止 | 产出 |
|---|---|---|---|---|---|
| 1 | **快写** | 创作帽 | 跟着细纲把故事倒出来：对话/动作/内心独白/基本描述 | **边写边改**（每天只允许改前一章，Sanderson 原则）；**注水/无限堆爽点** | 完整故事骨架+鲜活对白 |
| 2 | **读者重读** | 读者帽 | 放下作者身份，以读者视角从头读到尾；四项检查（LOCK/冲突三层/弧线推进/角色辨识度）；修改：补感官细节/加强情绪拍/修弱过渡/Show don't Tell | **大改结构**（不动细纲架构）；**跳过检查项** | 读者体验完整的章节 |
| 3 | **技艺打磨** | 技艺帽 | 换工匠帽逐段打磨：文风偏差/句式节奏/章首尾钩子/对话动力/视角一致性；修剪：删冗词/砍重复/压缩过场 | **改故事内容**（只打磨表达，不动情节）；**过度打磨**（改味保护——不得整段重写） | 定稿正文 → 进 C 段 |

### 1.3 方法论书章节索引（每遍先读再操作）

| 遍 | 书 | 章节 | 读什么 | 怎么用 |
|---|---|---|---|---|
| 1 | 大师课一册 | 第 7 章（场景） | 场景四和弦：行动/反应/铺陈/深化 | 每场戏知道在弹哪个和弦——行动场景写目标+冲突，反应场景写情绪+反思 |
| 1 | 小说写作 | 第 6 章（塔和网） | 福斯特因果链："因为悲痛"而非"然后" | 每个场景转换问"为什么会这样？" |

## 二、chapter-core.md B 段重构设计

### 2.1 文件级改动清单

| 文件 | 改什么 | 注意点 |
|---|---|---|
| `skills/moshu-write/references/chapter-core.md` | B 段整体重构为三遍（每遍一个 `### 第 N 遍·XX` 子节，含帽子声明/方法论书指引/操作步骤/禁止事项）；字数验收移至第 3 遍末尾 | 保留 B 段的对外接口不变（A 段输入→三遍→C 段输出）；改的是内部分遍 |
| `skills/moshu-write/references/workflow-chapter.md` | 引用 B 段处更新措辞（"按三遍法执行"） | 一句级 |
| `skills/moshu-write/references/workflow-daily.md` | 日更流程中 B 段引用处更新 | 一句级 |
| `skills/moshu-write/SKILL.md` | description 或流程描述提及三遍法 | 版本 bump |

### 2.2 每遍的文档结构模板

```markdown
### 第 N 遍·XX（XX 帽）

> **帽子**：{创作帽/读者帽/技艺帽}——本遍只从这一个视角工作
> **方法论书**：{先读的书章节清单}（约 5 分钟，然后照着走）
> **输入**：{上一遍产出 / A 段上下文}
> **产出**：{本遍目标}
> **禁止**：{本遍铁律}

{操作步骤，3-6 步}
```

### 2.3 第一遍·快写（创作帽）操作步骤

```
0. 【上下文隔离铁律】从本遍开始，你只以以下文件为写作依据：
   - 大纲/细纲_第N章.md（本章蓝图——唯一执行依据）
   - 设定/（本章涉及的角色/地点/物件）
   - 文风库/文风.md（风格基线）
   - 追踪/上下文.md（续写状态卡）
   不参考、不回忆建细纲时的规划讨论——细纲是唯一的执行依据。
   （设计依据：v7"干净上下文"哲学——写稿时只看备料产物，不看规划过程）

1. 读方法论书：大师课第 7 章（场景四和弦）——知道每场戏弹哪个和弦
2. 读细纲（A 段已加载）——确认本章结构公式（含 BC-ID 引用）
3. 快写：
   a. 跟着细纲的情节序列走（密/疏标注对应展开/带过）
   b. 对话优先——先写对话骨架，再补动作/描述
   c. 内心独白允许（角色思考）
   d. 每个场景转换问"因为什么？"（因果链，不是"然后"）
4. 【禁止】边写边改——写完一段就往下走，不回头润色
5. 【允许】微型探索——不确定的写法先写一版（后续遍可改）
6. 字数不够 → 继续推进情节（不注水）；字数超了 → 先不停（第 3 遍精确控制）
```

### 2.4 第二遍·读者重读（读者帽）操作步骤

```
1. 读方法论书：大师课第 11 章（"重新体验"）+ 第 9 章（弧线节拍）
2. 放下作者身份——假装你是第一次读这章的读者
3. 四项检查（每项标记 ✅/⚠️/❌）：
   a. LOCK 四查（章节级）：主角有趣吗？目标清楚吗？冲突够强吗？结尾有冲击吗？
   b. 冲突三层：每场景至少一层冲突？只有外部没有内心=标记"扁平"
   c. 弧线推进：本章角色有变化吗（认知/情感/关系）？无变化=标记"停滞"
   d. 角色辨识度：遮住名字能认出谁在说话吗？全靠对话/行为/心理区分
4. 修改（针对 ⚠️/❌ 项）：
   a. 补感官细节——视觉/听觉/触觉/嗅觉（读者能"看到"场景吗？）
   b. 加强情绪拍——关键情绪节拍有没有"落到具体动作/画面"？
   c. 修弱过渡——场景切换是否生硬？加一句桥接
   d. Show don't Tell——"他很愤怒"→"他的手指关节发白"
5. 【禁止】大改结构——不动细纲架构，只改表达层
```

### 2.5 第三遍·技艺打磨（技艺帽）操作步骤

```
1. 读方法论书：大师课二册第 4/8/9 章（对话三查）+ 小说写作第 1-2/7 章
2. 五项打磨（逐段进行）：
   a. 文风偏差：与文风库基线对照——句长/标点/段落节奏偏离了吗？
   b. 句式节奏：密场景短句快切（beat-cards 参考）？疏场景长句舒缓？
   c. 章首钩子：开头 3 句能否抓住读者？（hooks-chapter 选合适类型）
   d. 章尾钩子：结尾是否留悬念/未答问题/情绪余韵？（对照细纲"结尾设定"）
   e. 对话动力：每段对话删掉后故事受损吗？不受损=删或压缩
3. 修剪：
   a. 删冗词（"非常""很""开始"等多余修饰）
   b. 砍重复意象（同一意象出现 ≥3 次且无递进=砍）
   c. 压缩过场（细纲标"疏"的段落，40 字内带过）
4. 字数验收：对照细纲字数目标——低于目标则增展开点，高于上限则压过场
5. 【禁止】改故事内容——只打磨表达，不动情节
6. 【禁止】过度打磨——改味保护原则：不得整段重写（"改最少效果最大"）
```

## 三、与日更流程的集成

日更批量（workflow-daily）中三遍法的位置：

```
日更 Step 2（写作）：
  对每一章：
    A 段（写前准备——加载上下文/细纲/设定）
      ↓
    B 段三遍法：
      第 1 遍 快写（约 50% 时间）
      第 2 遍 读者重读（约 30% 时间）
      第 3 遍 技艺打磨（约 20% 时间）
      ↓
    C 段（机检——确定性收尾）
      ↓
    D 段（追踪事务）
      ↓
  下一章（重复 A→B→C→D）
```

**批量优化**：日更连写多章时，可以**第 1 遍连续写 2-3 章的快写**，然后统一做每章的第 2/3 遍——这是 Sanderson "写完再回头" 原则在批量场景的适配。但每章的 C/D 段仍在每章写完后立即执行（保持追踪事务的及时性）。

> **批量场景与上下文隔离的关系**：隔离铁律隔离的是"建细纲的规划讨论"，**不隔离前章正文**——连续快写时后章需要知道前章写了什么（对话衔接/情绪延续），前章正文在上下文中是刻意保留的。

## 五、禁止事项

1. 禁止第 1 遍边写边改（Sanderson/King/Bell 三源铁律）。
2. 禁止第 2 遍大改结构（不动细纲架构——那是 build 侧的职责）。
3. 禁止第 3 遍改故事内容或整段重写（改味保护：改最少效果最大）。
4. 禁止跳过任何一遍（三遍是完整流程，不许"时间紧只做两遍"——除非作者显式要求降级）。
5. 禁止 C 段/D 段被移动或修改（三遍法只改 B 段内部）。
6. 禁止方法论书指引被删除（每遍先读再操作是核心设计）。
