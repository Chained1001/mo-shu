# 规格 · 批 B10：构建迭代法 v3.0（书驱构建·双路设计）

- 版本：v3.0（2026-08-23 终版：以雪花法 10 步为基底流程 + 网文适配层 + 对标参照层 + 方法论书章节作为操作说明书 + 卡片按需加载）
- **前置依赖**：B9 已合入；B11（台账 v2）配套。
- 核心变更 vs v2.0：不再由旗舰侧推导抽象模型——**流程骨架直接来自雪花法**，适配层来自五步法/八节点，对标层来自现有机制，每步挂方法论书的具体章节。

## 一、设计总纲

### 1.1 三层架构

```

│  基底流程（雪花法 10 步 → 压缩为 6 步网文适配版）        │
```

### 1.3 扩展规则（雪花法一手原则）

**每一步都消费上一步的产出再扩展**——不是重写：
- 步 1 的每卷一句话 → 步 2 扩为每卷一段话（五句=三幕+两次灾难）
- 步 2 的每段 → 步 3 拆为单元卡（每段拆成 2-5 个单元）
- 步 3 的单元卡 → 步 4 精修（加伏笔/反转/因果标注）
- **结构保持不变，密度加深**

### 1.4 双路设计

| 步 | 无对标路径 | 有对标路径 |
|---|---|---|
| 0 | 选题+完美评述+方法论声明 | 同左 + **对标发现** |
| 1 | 雪花法→八节点定结构→每卷一句话 | 同左 + **读概要参考卷功能** |
| 2 | 雪花法→弧线六阶段→角色一页 | 同左 + **读节奏校准灾难级别** |
| 3 | 五步法→题材公式→单元卡 | 同左 + **读对标单元参考功能/密度** |
| 4 | 伏笔/线索/因果+可证伪 | 同左 + **读情绪模块校准密度** |
| 5 | 八节点占比+LOCK+定稿 | **对标回流**+LOCK+定稿 |

**同流程+可选参照**——不是两套流程，是同一骨架的对标增强版。

## 三、完整交互脚本（每步问什么、怎么问）

### 步 0·信息采集——五问式开场

```
问 1（方向）：
"你想写什么类型的故事？有没有特别想对标的书？你的优势是什么（脑洞/文笔/节奏感/生活经验）？"
→ 有方向 → 继续问 2
→ 没方向 → "要不要先扫一下最近的榜单？或者说说你想让读者有什么感觉？"
→ 有对标意向 → 执行对标发现（扫拆文库推荐）→ 作者选定主对标

问 2（规模）：
"这本书大概什么体量？预计总字数/总章数/分几卷？"
→ 知道 → 记录
→ 不确定 → "先按 200 万字/5 卷规划，写完第一卷可以调"

问 3（结局）：
"有明确的结局吗？"
→ 完结 → 记录"终局底牌待步 1 设计"
→ 无限流 → 记录"无固定终局，升级台阶驱动"

问 4（精度）：
"构建精细度选哪档？"
  🏃 快速（2 停，适合试水/脑洞文）
  🚶 标准（3 停，大部分网文）
  🧗 完整（3 停，多线/强反转/群像）
→ 不确定 → "先标准档，写完第一卷觉得需要可以升级"

问 5（完美评述）：
"在你确定写什么之前，我做一份'完美评述'——想象一个完全读懂你这本书的评论家，
为它写一篇溢美的书评。你说说你希望这本书给读者什么感觉？"
→ [作者描述感受]
→ AI 生成理想书评草稿 → 作者改定 → 落盘设定/
→ "好，这是你的北极星——后面每一步都拿它当尺子。"
```
