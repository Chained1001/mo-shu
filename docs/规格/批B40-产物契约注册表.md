# 规格 · 批 B40：产物契约注册表

- 版本：v1.0（2026-08-25）
- 依据：架构建议 #1——跨 skill 字段级断裂（A2 单元 ID、B37 章节范围、B36 工单根字段、import 细纲字段）是最高频真实缺口，文件级守卫查不出；审计法 3b「字段级吻合」目前靠人查
- 性质：契约扩展 + 字段存在性抽检守卫，零行为变更

## 一、现状事实

current-contract.json 已有 primary_benchmark_artifacts（节奏/情绪模块路径）与 required_outline_sections（细纲 8 字段），但无跨 skill 产物的字段契约；字段级断裂（生产者文档字段与消费者读取字段不一致）只能靠审计发现。

## 二、设计

current-contract.json 新增 `artifact_contracts` 域（三个高频跨 skill 产物）：
- 剧情单元卡（build 产 → write 消费）：字段 单元 ID/章节范围/承诺/风险/对标剧情参照/章功能分配；锚点 workflow-build.md
- 审查工单 JSON（review 产 → write 消费）：字段 schema_version/chapter_range/review_token/findings；锚点 review-workflow.md
- 采风-CF 记录（research 产 → build 消费）：字段 CF/需求描述/状态；锚点 workflow-build.md + caifeng-methods.md

守卫 `artifact_contract_findings()`：每个契约的字段必须在锚点文档中出现（缺失 → `artifact-field-missing` FAIL）。字段名与文档实际文本已预验证（全部命中）。

## 三、文件级改动清单

1. `scripts/current-contract.json`：+ artifact_contracts 域
2. `scripts/check-current-skill-contracts.py`：EXPECTED_KEYS + ContractManifest 字段 + load_manifest 校验 + artifact_contract_findings() + main 接入
3. `scripts/test-current-skill-contracts.py`：补两断言（结构违规红 / 字段缺失红）

## 四、禁止事项

- 不改任何 skill 可执行逻辑与文档（守卫只断言）
- 新增产物契约须同时满足：字段名在锚点文档实际存在（否则守卫首跑红）

## 五、验收命令

1. `python scripts/check-current-skill-contracts.py` → 全 PASS
2. `python scripts/test-current-skill-contracts.py` → 绿
3. 违规验证：虚构产物契约 → artifact-field-missing 红（复现后还原）
