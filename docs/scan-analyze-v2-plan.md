## 一·五、设计溯源（为什么 scan-analyze 只支持起点——设计如此，非漏洞）

- 上游没有 scan-analyze（分析靠 AI 手写 grep），本脚本是 mo-shu v1.1.0 自研新增，不存在"与上游对齐"问题。
- 只做起点是理性范围选择：① 起点是主战场 + 字段最全；② 起点字段是规整 `**XX：**` 结构，其他平台字段内嵌 meta 段位；③ 头部注释显式声明"扩展另行推进"。
- 非漏洞判据：v1.1.1 已诚实化（适用范围声明 + 不可信警告），不会静默出错。
- 被浪费的机会成本：排名/书名/作者 4 平台都有（正则一行可提），`--dup` 跨平台能力被闲置。
- **v2 姿态**：保留起点完整解析逐字节不变 → 补通用提取 → 按平台适配。

## 二、4 平台输出格式对照（已核实，2026-08-18）

| 平台 | 文件头 | 条目行 | meta 行结构 | 独有字段 |

| 番茄 | `# 番茄 · 榜单 · 全 N 题材` | `### #N 书名` | `作者 · 题材 · 状态 · N 在读 · N字` | `**标签：**` `**最新更新：**` `**bookId：**` 简介 |
| 晋江 | `# 晋江 · 榜单名` | `### #N 书名` | `作者 · 收藏 N · 营养液 N · 积分 N · 字数 N · 状态` | 收藏/营养液/积分内嵌 meta；**题材无** |

统一中间结构：`{rank, title, author, genre, words, metric(平台主指标), extra{…}}`，缺失字段 `[待补]`。

## 三、v2 设计

### 结构（保持单文件，~250 行）

```
scan-analyze.js v2
├── 平台识别 detectPlatform(text)
│    └── 按文件头 `# 番茄 ·` / `# 晋江 ·` / `# 七猫 ·` / 其余按起点
├── 通用条目解析 parseBlocks(text)          # 全平台：排名/书名/作者/meta
├── per-platform 字段适配器
│    ├── qidian:  现有逻辑不变（**XX：** 字段 + 简介）——逐字节保留
│    ├── fanqie:  meta 尾段 `(\d+(?:\.\d+)?)字` → words；第 2 段 → genre；**标签：**
│    ├── jjwxc:   meta 段 `收藏 (\d+[.\d万]*)` / `字数 (\d+[.\d万]*)字` → metric/words；genre=[待补]
│    └── qimao:   meta 段 `N热度` → metric；`(\d+)字` → words；第 2-3 段 → genre
├── 统一输出（保持现有 --dist / --genre / --dup / --full 接口）
│    ├── --dup:   按 title 聚合（全平台生效，跨平台=交叉验证信号，标注平台）
│    ├── --dist:  按各平台尽力 genre；晋江全 [待补] 时警告"题材不可得"
│    └── 警告细化：逐文件报"哪些字段缺失"（不再一刀切"疑似非起点"）
```

### 向后兼容

- CLI 接口不变（`--dir/--genre/--full/--dup/--dist`），AI 文档无需改调用方式。
- 起点文件解析结果与 v1 **逐字节一致**（起点适配器 = 现有逻辑原样保留）。
- 头部注释更新：4 平台通用提取说明；晋江题材缺失、番茄无总推荐等平台固有边界如实标注。

## 四、实施步骤

1. **重构 parseFile** → 通用 `parseBlocks` + 平台识别（保留起点分支原逻辑）
2. **写 3 个平台适配器**（fanqie/jjwxc/qimao），规则见第二节表格
3. **fixture 样本**：`tests/fixtures/scan/` 下放 4 平台最小样例 md（各 3-5 条，含 [待补] 场景）——不依赖真实采集
4. **测试脚本**：`scripts/test-scan-analyze-v2.js`（node --test 风格）：每平台断言 排名/书名/作者/字段提取正确 + [待补] 缺失 + `--dup` 跨平台聚合
5. **文档同步**：scan-analyze.js 头部注释、moshu-scan SKILL.md（适用范围描述"仅起点"→"4 平台通用提取"）、scan-output-format 无改动（模板本来就有 4 平台）
6. 真实走查：有真实榜单文件时跑一次 `--dup --dist` 看输出质量
