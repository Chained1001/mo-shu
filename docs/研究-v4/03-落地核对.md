### 1.3 跨 skill 引用专项（static-check 规则）

- static-check.py:62-65：`FOUNDATION_SKILL_REFERENCES = frozenset({"moshu-cdp"})`——除 moshu-cdp 外禁止跨 skill 文件路径引用（代码事实）。

- **双用文件的引用形态**：setup agent-references 副本是**拷贝**（shared-assets target），不是引用；write references 之间的相对链接（`[outline-methods.md](outline-methods.md)`）是 skill 内引用。迁移 build 后 write 侧对 build 文件的引用只能走 shared-assets 副本（字节同步）——**共享方案是唯一合规路径**（静态规则不变的前提下）。
- **疑点 Q1**：workflow-setup 拆分形态（同文件 write 保留副本 / 拆 build-workflow 与细纲工作流两文件）——影响 chapter-core:149 引用与 doc-budget 登记，需旗舰裁决。
