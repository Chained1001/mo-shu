# 《小说的骨架：好提纲成就好故事》与现有方法论体系重叠度评估

- 评估对象：`otherMaterials/referFile/《小说的骨架：好提纲成就好故事》.md`（凯蒂·维兰德，2018，后浪；中文全译文，4140 行，正文 11 章 + 每章"章节清单" + 书后关键词索引，无 `#` 标题，章标记为"第N章"独立行）。
- 对照系（真源）：`skills/moshu-write/references/` 下 outline-methods / plot-frameworks / plot-core-methods / character-design-methods / idea-seed / reader-contract-and-progression / emotional-arc-design / opening-design，及 `skills/moshu-build/references/workflow-build.md`。
- 角色：研究员，只读 referFile + 写本报告；零 git 写、零改 referFile。书内证据用【行号区间】（章标记为"第N章"行），现有机制用【文件:节名:行号】。
- 记号：【事实】=可直接从书中/现有文件验证；**(推断)**=我基于证据的分析判断。

> 核心判断先行：这本书是**西方单本小说的提纲生产方法书**（提纲派但反教条），与 mo-shu 的**中文长篇网文多卷构建体系**在"大纲方法、结构、人物/背景、场景、修订"五个层面大量重叠；其独特增量集中在几个"自有工具"与"清单化检查"，以及一个本质差异——**提纲颗粒度**（本书 per-场景扩展版提纲 vs mo-shu"卷纲只写走向、细纲才展开"）与**结构范式**（三幕 vs 网文八节点/六幕）。转译成本整体"中"，个别"高"（三幕/扩展版提纲/软件工具）。

## 1. 书籍速览（11 章各一段）

【事实】以下每章核心主张与关键工具取自全书正文（行号见括注），清单/访谈为贯穿体例（每章"章节清单"=可勾选要点回顾，"作家访谈"=十位作家固定五问）。

- **第一章　我们应该写提纲吗？（第 115–393 行）**：破除"要不要写提纲"之争。立场：写/不写都对，取决于个性与生活方式；作者是坚定提纲派（《守望黎明》成功 vs 《梦境者》无提纲 50 页返工）。工具：错误认知④条（提纲有严格格式／束缚创造力／夺取探索乐趣／太耗时）、四步创作流程（构思右脑→提纲左脑→创作右脑→修改左脑）、七大好处（平衡连贯/避死胡同/铺线索/提节奏/视角/人物连贯/动力）。
- **第二章　写提纲之前（第 475–693 行）**：选方法与工具。工具：四种非标准提纲（思维导图／图像式提纲／地图／**完美评述**——动笔前以"理想评论家"口吻写一份具体溢美书评）、三种书写工具（手写七好处／**yWriter 软件**／日历排时间轴）。立场：唯一标准是"能否提供最大创作自由"。
- **第三章　雕琢好小说的前提（第 778–1017 行）**：把全书浓缩成**前提句**（一句话）作北极星。工具："如果……会怎样"**穷尽问句**（列读者期待＋让读者大吃一惊）、前提句六点好处、写提纲前问题清单、头脑风暴/梦想风暴（dreamstorming）五法——思维导图／如果问句／提示性写作／自由写作／让左脑休息。
- **第四章　小说示意图（Ⅰ）：连点成画（第 1091–1329 行）**：把已知场景当"点"连起来，先写已知、标漏洞、用提问补空白。工具：**场景清单三动作**（概述场景／列出场景／标出问题）、**荧光笔标记系统**（橙=需完善/蓝=可誊写/粉=新想法）、**连点成画**（从最棘手问题反推）、**自由写作**、**相信直觉**、**提问技巧**（陈述句→问句）。
- **第五章　小说示意图（Ⅱ）：核心元素（第 1419–1929 行，全书最长章）**：尽早确认并植入**动机→愿望→目标链**、**人物变化轨迹表**、**制造冲突=在目标间加障碍**、**内在+外在冲突**、**主题**（用人物凸显主题、**发现主题五问**、象征/意象重复）。
- **第六章　人物速写（Ⅰ）：探索幕后故事（第 1988–2257 行）**：幕后故事是冰山水下 8/7。工具：**激发事件四问框架**（什么是／什么不是／在何处／四特质）、**幕后故事四步**（总体概述／探索其他重要人物／教育职业旅途／大事件"点金石"）、**正确使用**（早埋线索晚揭示／越短越好／暗示替代直白）。
- **第七章　人物速写（Ⅱ）：人物采访（第 2320–2601 行）**：用采访把人逼成血肉。工具：**人物采访问题清单（100+ 问**，分名字/基本/人生观/外貌/性格/爱好/希望梦想等区块）、**自由采访**（不按清单纸上逼问）、**九型人格表格**（9 型×理想/恐惧/愿望/缺陷——用于锁定"致命弱点"，非套模板）。
- **第八章　发现小说背景（第 2670–2842 行）**：背景要"内化"为有机部分。工具：**背景四问**（是否有机／人物如何看待／是否牵动情绪／是否过度）、**精简背景四技巧**（慎重选主背景／写好主背景／**合众为一**合并次要背景／铺线索）、**世界建构问题清单**（自然风光/社会形态/自然法则/居民/历史，参考帕翠亚·瑞德）。
- **第九章　扩展版提纲：创作一部小说（第 2909–3363 行）**：按场景逐条写主要事件（无对白叙述），是布局真正起点。工具：**写前铺垫三问**（写什么类型／读者是谁／视角时态）、**三幕要点清单**（开头 8 条/中间 4 条/结尾 8 条）、**三大基本元素**（关系/动作/幽默）、**首尾呼应**、**多米诺效应**（每场景必影响后续，否则删）、**逆向提纲**（不知 A→B 时从终点倒推）。作者明言本书"不会细致讨论小说结构"（指向其另一本书《搭建你的小说》）。
- **第十章　精简版提纲：画好你的路线图（第 3454–3674 行）**：从扩展版提炼一份随时可查的路线图，并完成删并/切分。工具：**精简版提纲两档示例**（极简一句话档/详细档）、**进一步整理**（删并场景、合并次要人物）、**拆章**（戏剧性时刻切分）、**11 条章节结尾建议**（预示冲突/秘密/重要决定/震惊/激烈情绪/突转/新想法/未答问题/神秘对白/预言/转折点）、**节奏=章节长短**、**砍脂/场景切换隐形脱脂**。
- **第十一章　结语：用好你的提纲（第 3742–3784 行）**：提纲是**指南不是铁律**，每天动笔前看一眼；灵感+结构双轮。立场重申"弹性提纲"（想多灵活就多灵活）。

## 3. 增量清单（核心价值）

按价值优先列 8 条（各阶段/各层面），每条给【方法一句话】+【书内证据】+【落点建议】+【维度宪章三问】。（推断)处为我的建议性判断。

### 增量① 完美评述（第2章）
- **方法一句话**：动笔前以"理想评论家"口吻为这本书写一份具体、全面、溢美的书评，把"我要写一本好书"的模糊愿望具象成可衡量的成品目标。
- **书内证据**：（推断)第 2 章"完美评述"小节，第 518–594 行区间（四种非标准提纲之一，"缩小构想与成书差距"）；清单要求"写一份完美评述"（第 695 行）。
- **落点建议**：并入 `idea-seed.md`（在 Logline 之后、落盘前，作为成品一致性尺度）或 workflow-build.md Phase 1 方向提问后作为"成品设想"自检；(推断)优先并入 idea-seed.md，因为两者都是"开书前收敛器"。
- **维度宪章三问**：谁在什么阶段调用——开书 Phase 1 方向确认后、写前提句前（LLM 帮作者生成"理想书评"草稿）；解决什么问题——把模糊构想/作者"差不多"心态具象成成品目标，减少中途漂移；调用后什么可观察结果——项目根多一份"成品设想评价"，后续每个设定选择可与之核对，防止"卷纲只写走向"但方向漂移。

### 增量② 如果问句穷尽法（第3章）
- **方法一句话**：从"如果……会怎样"穷尽列出故事可能性，并行列出"读者期待什么"与"什么让他们大吃一惊"两套清单。
- **书内证据**：（推断)第 3 章"如果问句 + 读者期待/大吃一惊清单"，第 796–874 行；清单"写'如果'问句"（第 1017 行）。
- **落点建议**：并入 `idea-seed.md` 生成规则或 Phase 1 方向提问；(推断)作为方向提问前的"可能性发散"，补充 idea-seed 的"只收敛不铺陈"。
- **维度宪章三问**：谁在什么阶段调用——开书 Phase 1 方向探索时；解决什么问题——把"只有一个想法"发散成候选可能与读者期待，避免"想到第一个可行就开写"；调用后结果——多一份"可能性清单"，供方向提问/选题收敛选择。

### 增量③ 人物变化轨迹表（第5章）
- **方法一句话**：比较人物起点与终点在性格、行为、价值观、信念上的转变，配五要素（起点状态/起点缺陷/前段缺陷例证/成长工具/高潮揭示+行动证明）。
- **书内证据**：（推断)第 5 章"人物变化轨迹表"，第 1542–1571 行。
- **落点建议**：并入 `character-design-methods.md` 九维人设「人物成长弧线（三阶段）」（:328），作为"弧线的可写检查表"。
- **维度宪章三问**：谁在什么阶段调用——Phase 3 卷级大纲/卷纲定人物弧线时；解决什么问题——把"人物成长"从一句"主角成长了"变成可核对（起点→缺陷→例证→工具→证明）；调用后结果——人物弧线有一张可对照的转表，防"人物没成长/结尾人设崩塌"。

### 增量④ 发现主题五问 + 主题=人物结尾所得认知（第5章）
- **方法一句话**：主题用"人物结尾学到了什么"来凸显；用五问（内在冲突/观念如何变/首尾证明/象征强化/潜文本印证）来发现主题。

### 增量⑤ 激发事件四问框架（第6章）
- **方法一句话**：用"什么是激发事件 / 什么不是 / 在何处（1/4 处或之后）/ 四特质"来锚定开篇的推动核心。
