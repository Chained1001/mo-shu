1. **系统与权威规范十判据全对齐**（每条 file:line 实证）——mo-shu 的既有架构（打磨环=evaluator-optimizer、追踪事务=stateless reducer、确认点=checkpoints）与 2025-2026 主流 agent 工程共识一致，方向无需修正；
