### 改动 2：chapter-core.md B 段增强（~25 行增量）

**2a. spawn prompt 新增材料**（在现有材料清单追加）：

```
  - 本章场景类型：{细纲「章节定位」值}——写正文时按此调整笔触（高压=短句快切少描写，低压=长句舒缓多感官）
  - 重点情节点功能标签：{本章密点的功能标签列表，如「爽点·打脸·反转」}——密点展开时参考对应写法（爽点→铺垫-释放节奏，打脸→对比-揭露-反应三拍，反转→误导-揭示-重构）

  - 场景文风锚点：{A 段 (d) 按场景选路的锚点片段}——优先用于 few-shot
```

**2b. 三遍法各遍加场景感知行**（在各遍步骤中插入）：

第 1 遍（创作帽）步骤 3「快写」后追加：
```
  按本章场景类型调整笔触：高压章短句快切少环境描写（信息密度高），低压章长句舒缓多感官细节（情绪沉浸），关系章对话优先动作辅助，信息章整理条理不堆砌。
```

第 2 遍（读者帽）四查前追加：
```
  按场景类型选重点查：高压章先查节奏（b/c）再查角色（a/d），关系章先查角色辨识度（d）和冲突（b），低压章先查流畅性（查全段是否让人想跳过）。
```

第 3 遍（技艺帽）五磨前追加：
```
  按场景类型选磨序：高压章先磨节奏（b）+钩子（c/e）再磨对话（e），关系章先磨对话（e）+情绪（d），低压章先磨文风（a）+描写质感。
```

### 改动 3：三遍法苏格拉底化（~30 行改写）

**3a. 第 2 遍四查加强迫表态问句**（在现有四查 a-d 的每条后追加苏式问句）：

```
  a. LOCK 四查 → 苏式加强：「主角有趣吗？——如果不有趣，是因为{____}（无欲望/无困境/无反差）？答不出说明主角设定不锐。」
  b. 冲突三层 → 苏式加强：「每场景至少一层冲突？——找出全书最平的一个场景，它存在的理由是{____}？删掉后读者损失了{____}？两者都答不出=该场景不该存在。」
  c. 弧线推进 → 苏式加强：「本章角色有变化吗？——变化的证据是{____}（一句话/一个选择/一次情绪波动）？没有任何证据=标记停滞。」
  d. 角色辨识度 → 苏式加强：「遮住名字能认出谁在说话吗？——挑一段双人对话逐行标注是谁说的；标不出=对话无个性，需重写。」
```

**3b. 第 3 遍五磨加强迫表态问句**（同法追加）：

```
  a. 文风偏差 → 「本章偏离文风基线最多的三句是哪些？把它们逐句改到基线带内——改完读一遍，还像同一个人写的吗？」
  b. 句式节奏 → 「本章最平的一段是哪里？把它变锐的最小改动是什么——删一句/加一个具体细节/换一个动词/埋一个反讽？」
  c. 章首钩子 → 「开头三句能让读者不划走吗？如果自己都觉得平，读者为什么会继续？给出一个不可拒绝的理由或重写。」
  d. 章尾钩子 → 「读者合上手机的理由是什么？——如果答不出'下一章会发生什么'，钩子没建立。」
  e. 对话动力 → 「每段对话删掉后故事受损吗？——找一段删掉无损的对话，删或压缩到一句。对话要么推动情节、要么揭示人物，两者都不做=装饰品。」
```
