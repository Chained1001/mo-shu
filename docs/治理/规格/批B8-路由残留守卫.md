## 4. 新文件设计

**check-route-write.py**（算法级）：
1. 扫描 `skills/**/*.md` 的**表格行**（`^\|` 开头），匹配第二列为 `moshu-write`（或 `` `moshu-write` ``/`/moshu-write`）的行。
2. 提取第一列语境词，**两级判定**：
   - **BLOCKING**（语境含构建域词：开书/开写/开新/建设定/改设定/写大纲/搭大纲/写卷纲/定世界观）→ 违规，报 `文件:行号:原行`，退出 1；
   - **WHITELIST**（写作域词：续写/继续写/继续创作/写长篇/写正文/回炉/重写/日更/补纲/修改/改稿/去味/润色/写作）→ 通过；白名单 dict 每词带一行理由注释（仿 check-story-numbers ALLOWED 纪律）；
   - **未知语境** → candidate：打印 `[candidate] 文件:行号:原行`，**退出 0**（未知≠违规——候选永不拦截宪法）。
3. 首跑枚举全部命中，逐条归类：合法→白名单收编；当前仓无 blocking 预期；未知遗留候选须呈报旗舰。
4. 输出汇总 `route-write: ok (N rows checked, M candidates)`；退出码语义：blocking>0 → 1，否则 0。

**test-route-write.py**：fixture 仓库四用例——①白名单行（继续写作）→ 过；②blocking 行（准备开书）→ 退出 1 且报文含文件名；③未知语境行（"随便干点什么"）→ candidate 打印但退出 0；④无表格行文件 → 过。
