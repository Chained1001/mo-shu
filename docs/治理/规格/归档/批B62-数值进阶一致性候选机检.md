## 三、文件级改动清单

### 子步 62a：数值正本声明 + 长度候选（零 schema）

**1a. check-prose-candidates.js 加长度候选**：
- 从 `--prose` 文件名提取章号 → 定位 `大纲/细纲_第{XXX}章*.md`（项目根按 prose 路径上溯一级书根；找不到 → 输出 `length_check: skipped_no_outline` 后跳过，合法旧书模式）；
- 细纲在但无「字数目标」行 → 候选「细纲无字数目标，长度未检」（可行动：补字段）；
- 有目标 → 成稿非空白字符数比率 <0.7 或 >1.3 → 候选「成稿长度 X 字 vs 目标 Y（比率 Z，越界 [0.7,1.3]）」；范围内 → 输出 `length_check: ok（X/Y）` 不出候选；
- 阈值常量命名 `LENGTH_FLOOR_RATIO=0.7 / LENGTH_CEILING_RATIO=1.3`（注释标 mo-shu 自定）+ CLI `--length-floor/--length-ceiling` 可覆盖；
- blocking_count 结构不动（仍恒 0）。

**1b. 正本声明两句**：chapter-core A3 末加「**数值正本优先级（B62）**：数值类事实冲突时仲裁序 = 追踪 state > 细纲 > 正文回忆——不信自己刚写的数字」；review-workflow 审查基准包节加同义一句（审查数值矛盾按此序裁决）。

**1c. 三类→四类**：chapter-core:185 候选清单「高频意象/句式偏离/信息差兑现三类」补「成稿长度」为四类；workflow-daily :83 链命令不变。

### 子步 62b：progression 域 + 单调性候选（schema 7→8）

**2a. tracking_commit.py（×4）——state 扩展（仿 address_book 第三例）**：
- 新顶级可选域 `progression`：条目键 `{角色}#{指标}`，值 `{character, metric, value(number), unit(≤12B 可选), direction("up"|"down"), first_recorded_chapter, updated_chapter}`；
- 输入 `progression_updates: [{action: register|update|retire, character, metric, value?, direction?, unit?, reason?}]`——register 带全量、update 带 value（reason 可选）、retire 只带 character+metric；
- TRACKING_SCHEMA_VERSION 7→**8**，migrate 链补 v7→v8（顶层补 `progression: {}`，一次备份，老键零丢失）；INPUT_SCHEMA_VERSION 保持 2。
- **单调性候选（提交时比对，stdout 呈报）**：update 命中已有键时——direction=up 且 new<old，或 direction=down 且 new>old：无 `reason` → commit 输出「⚠️ 进度回退候选：{角色}·{指标} {old}→{new}（{direction} 指标逆向，未带归因）——候选不拦截，剧情安排请在 update 带 reason」；带 reason → 输出「已归因回退：{角色}·{指标} {old}→{new}（{reason}）」。**退出码不变、state 照常更新、不渲染进上下文卡**。

**2b. 派生视图 `追踪/进度.md`**：全量表（角色｜指标｜当前值｜单位｜方向｜登记章｜更新章）——A 段按需读，不进卡。

**2c. chapter-core D 段登记指引**（+1 句，可选语义）：「数值登记（可选，B62）：境界/欠款/排名/资产等想盯的指标随事务登记 progression（登记时声明方向 up/down）——回退会出候选提醒，剧情性回退带 reason 归因」。

**2d. 涟漪面七类**（§二.3 清单逐条）：hook `!==7`→`!==8`+消息；契约断言文本→8；capability 标记→8；12 处 fixture 7→8；⑦ 用例 v5 不动；pipeline 零改；守卫 JSON 复扫。

**2e. 回归 +4 用例**：progression register→升（无候选）→降无 reason（候选行+state 更新+退出码 0）→降带 reason（已归因行）→retire；migrate v7→v8 零丢失。

## 五、禁止事项

1. 三组件全候选语义——blocking_count/退出码/拦截行为零变化。
2. **不解析正文自由文本数值**（登记制=确定性边界）；不做历史追加账本（当前值+提交时比对；历史在 git 与卷复盘）。
3. direction 登记后不可改（语义稳定）；schema 只加可选域，migrate 带备份。
4. 涟漪面漏检即返工（宪法 §3.4，第三次连续应用）。
5. 阈值/比率常量标注 mo-shu 自定+CLI 可覆盖+验收可测。
