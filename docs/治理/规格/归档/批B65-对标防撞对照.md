# 规格 · 批 B65：对标防撞对照（三维重合检查 + 登记免责）

- 版本：v1.0（2026-08-28，旗舰起草；来源：[06-强化方案草案](../../研究/开源强化/06-强化方案草案.md) B65 + 作者质询引出的**登记免责**设计点（2026-08-28 对话：防撞与采风不矛盾的前提=已声明学习免责，测的只是未登记渗透）。候选语义——永不拦截）
- 性质：build 侧语义检查步（AI 层，非确定性脚本——三层分工：语义归 AI）+ 协议下沉 cold-path。单批单提交，无 schema/无 agent 变更（主会话执行，天然 fallback）。

## 一、设计依据

| 改进 | 外部来源 | mo-shu 现状（实证） |
|---|---|---|
| 三维重合对照 | Claude-Book story-ideator/bible-merger 反抄袭矩阵（07） | 「学结构不学血肉」只有过程纪律（采风转译三问），无成品检验——写到兴头的无意识渗透无人量 |
| 多源共性降噪 | Claude-Book 合并收紧（07：多本全出现才升格规则） | 无区分——单源重合（渗透）与多源共性（套路）混为一谈会把矩阵变成永远红灯 |
| **登记免责** | 作者质询 2026-08-28（防撞 vs 采风矛盾的消解） | build 明示学主对标（对标结构坐标 B2 固化模板/剧情单元卡「对标剧情参照」）——无免责规则则合法学习全部误报 |

**防的失败模式**：神似越界成融梗——网文圈审判不需要抄原文，结构指纹撞了就算。这是序列里唯一防**平台/法律风险**（而非质量失败）的批次。

## 三、文件级改动清单

**1. workflow-build.md Stage 5 区**（卷纲成型后、定稿前；预估 +100 字，调高 18700→18800）：

> **防撞对照（B65）**：Stage 5 卷纲成型后按 [cold-path.md](cold-path.md)「防撞对照协议」执行三维重合对照（人物功能位 / 桥段节拍 / 设定机制）——卷纲对标结构坐标与剧情单元卡已登记的参照项**登记免责**（明示学习不计渗透）；单源两维以上高重合 → 候选呈报，多参照源同现的共性降为背景噪音；只呈报不拦截，重合裁决归作者。

**2. cold-path.md 加「防撞对照协议」节**（~300 字，冷路径无预算约束）：
- **触发**：开书 Stage 5 卷纲成型后；修订流改动设定/单元卡后复跑（改动面对照）。
- **数据源**：主对标拆文库角色/剧情模块 + 其他参照（拆文库多本、采风产物 设定/采风-*.md）；无对标书 → 声明跳过（合法无对标模式，明示不静默）。
- **对照表模板**：`| 维度 | 本书元素 | 源作品元素 | 重合判定（高/中/低/免责） | 说明 |`——登记项照列但标「免责」（透明可审计，不藏着）。
- **判定规则**：单源（同一参照书）≥2 维度高重合 → 候选；仅 1 维高重合 → 记表不呈报（单维是学习）；≥2 参照源同现同类重合 → 共性，降噪音注记。
- **呈报**：停靠屏附屏（候选区）/修订流报告节；措辞用「重合度」不用「抄袭」（候选语义，判定归作者）。
- **修订流复用**：revision-workflow ③b 后加一句「设定/单元修订后按 cold-path 防撞对照协议对改动面复跑（~+40 字，界内）」。

## 五、禁止事项

1. **不做确定性脚本**（语义对照归 AI，三层分工）；不建新 agent/新文件（cold-path 已在）。
2. 候选永不拦截；措辞禁「抄袭」定罪（重合度呈报，裁决归作者）。
3. **登记免责≠免列**——登记项仍进对照表标「免责」（透明可审计），防「登记」变成万能挡箭牌。
4. 无对标书跳过须明示声明，不静默。

## 八、风险与回滚

风险 1：重合判定主观性（高/中/低无硬标准）——对照表强制「源作品元素」具体引证（不是感觉，是可指认的对应）；实测门校准。
风险 2：误报噪音——单维不呈报+多源降噪已压；仍吵则实测后调「高重合」定义。
回滚：三处文档 revert 即恢复（语义步无数据残留）。
