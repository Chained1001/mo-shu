## 一、四项萃取

### 萃取 1：金手指设计学 → `skills/moshu-outline/references/golden-finger-design.md`（~2500 字）

**源**：大师写作课相关章 + 实测外评 #016 金手指三定则 + 大奉式实例解剖（见 #016 与 #012 的分析）。

**四节**：
1. **三定则**（核心框架）——能界（能/不能边界，保推理空间——如「七息主观视角」设计参考）/代价算法（何时反/反到什么程度/算法可验证——防「作者需要时才反」）/成长同步（能看见的越多承接越重，终局绑死——卷 5 烧尽命数式）
2. **四性**——剧情绑定性（与世界观顶层绑死，非无脑系统）/成长性（随剧情解封）/限制性（无俗套面板）/代价性（有得必有失）
3. **大奉式实例解剖**——许七安金手指的层次拆解（现代人知识辅助位 vs 国运/神殊主金手指）+ 三层分离原则（辅助位不遮主位）
4. **设计问句**（苏格拉底化）——三问+四性各配触发问句（判据零发明，每条标书源或实测出处）

**消费接线**：workflow-outline Stage 1 核心设定表→金手指/核心能力字段设计时**必读本文件**；写明加载句。

### 萃取 2：读者心理学 → `skills/moshu-write/references/reader-psychology.md`（~2500 字）

**源**：大师写作课读者章 + 骨架书相关章 + 实测 #012-2 诊断。

**四节**：
1. **开篇心理**——危机代入（为什么悬疑/危机开篇有效——从第一页就与主角绑定）/信息差勾连（读者比主角多知/少知产生的追读力）
2. **爽点心理动力学**——负债-偿付模型（铺垫=读者情绪负债，高潮=偿付；爽点是缺口被填补）/爽点递升四维（影响力/层级/收获/认知——至少一维递升否则重复）
3. **代入机制**——低贱视角逼入（越底层越有代入空间——大奉/本测试书共用）/代理权（主角的判断不可替代才值得代入）
4. **期待管理**——期待债（承诺-兑现-新承诺的循环）/低压容忍度（连续 N 章不爽的边界）

**消费接线**：理想书评模板（ideal-review-template）→ 情绪目标设计时；chapter-core B 段→三遍法第 2 遍读者帽进入法。

### 萃取 3：提纲学与动机链 → `skills/moshu-outline/references/outline-causality.md`（~2000 字）

**源**：骨架书前提句章 + 雪花法 Ch9 道德前提 + Ch6 人物动机 + 大师课 :6451 动机定义。

**三节**：
1. **前提句=北极星**——一句话迷你提纲（骨架书 :898-900）；「写提纲前须明确人物/冲突/情节」三要素
2. **动机→目标→障碍→冲突链**（骨架书 :1470-1473 公式）——动机≠目标（大师课 :6451：目标=赢比赛，动机=父亲认可）；动机个人化（雪花法第六章：「所有人都恨纳粹」不够——要「为什么是他」）
3. **道德前提**（雪花法 Ch9）——起点信念（主角一开始信什么错的）→世界教训→终点信念（顿悟）——三层底线逻辑

**消费接线**：skeleton-template 第 8 节核心角色五件套→动机字段设计时；第 3 节卷间驱动链构建时。

### 萃取 4：人物构建学 → `skills/moshu-outline/references/character-construction.md`（~3000 字）

**源**：雪花法 Ch12 人物宝典 + Ch8 人物秘事 + 演员自我修养 + character-basics 既有整合 + 实测 #021 五问诊断。

**五节**：
1. **人物宝典元素清单**（雪花法 Ch12 框架）——基本信息/外貌/性格标签/背景故事/动机（五件套之一）/目标/障碍/价值观冲突/弧线六阶段/对话 DNA/关系网/弱点/出场设计——**每个元素一行+触发问句**（治「待 volume 定」散落）
2. **配角群规模规划（roster 分层）**——核心团 5-8 / 跨卷反派 5-8（须具名）/朝堂势力人物 8-15 / 单元轮换配角 20-40——按体量分档参考值（300 万字长篇对照）+ **出场编排表**（谁在哪卷哪段入场）
3. **魅力原型学**——咒术/血界类型库扩挖：帅型强者（五条悟式）/搞笑抽象型（扎普式）/underdog 观测者（雷欧式）/成人导师（七海式）/职场妈妈（KK 式）/腹黑军师/老手尊严型——每型给定义+功能位+适用场景
4. **演员规定情境法**——情绪不由命令导出由规定情境导出（已在 emotional-methods 有雏形，此处升格为人物构建节）；任务动词化（目标动词化命名）
5. **升级绑弧光强化**——既有弧线六阶段+升阶三问的深化补充（每阶段对表升级台阶的具体操作）

**消费接线**：workflow-outline Stage 3 人物构建→**开始前必读本文件**（替代或整合 character-basics 的既有加载——两者合一，以更全的为准）；skeleton-template 第 2 节群像列→出场编排表参照。

## 二、共同纪律（四项萃取均须遵守）

1. **苏格拉底化萃取**：每条方法论=问句+操作+反例+来源（B5/B17 先例），**判据零发明**——无书源或实测出处的条目不落文
2. **消费接线一体**：每个新文件的头部必须有「消费点」声明——哪些流程步在什么时机加载本文件；同时流程文件里必须写上对应的加载句——**先写接线再写内容**（防「库存有接线无」复发）
3. **来源分层标注**：书源标（书名+章节）/实测标（实测 #NNN）/外评标（外评发现 #N）——研究纪律 §7
4. **与既有方法论不重复**：character-basics 已有的（主角卡/配角卡/质量检查清单）须整合而非并存——**合并为 character-construction.md 单文件**（character-basics.md 如内容全被覆盖则删除并迁路径，否则保留并在新文件头声明互补边界）
