## 一、改动清单

### P1 I/O 契约块（技能交接面，人读层）+边界声明句式统一

三个 SKILL.md 的既有「交接声明」节升级为**输入←/输出→两行式**（内容以 current-contract.json 登记与产物归属表为据，零发明），并**统一边界声明句式**（「XX 归 /moshu-xx」定式，自检发现现散于 description/头注/正文三种位置）：

- `skills/moshu-outline/SKILL.md`（余 65）：输出→（设定/*、大纲/大纲.md、⚠️ 台账移交）给 /moshu-volume；
- `skills/moshu-volume/SKILL.md`（余 65）：输入←（outline 产设定+大纲.md）｜输出→（卷纲/场景表/台账构建态、tracking init）给 /moshu-write；
- `skills/moshu-write/SKILL.md`（余 29，**红线**）：输入←（卷纲+设定+场景表）——净增必须 ≤29，**配 P7 加粗瘦身释放预算**（去 40+ 个冗余 `**`，重点太多=没有重点）。

### P2 收尾四节对照检查（只补缺不新增节）

按「输出产物/数据去向（正式 vs 追踪内部）/上下游配合/断点恢复」四要素核对 workflow-outline、volume-workflow、workflow-daily 尾部——**信息已在则只调位置，缺失才补句**；预算近零文件（volume-workflow 余 9/workflow-daily 余 20）只减不增，补句必须配对冲。

### P3 开发仓库 CLAUDE.md 指针文件（两宿主会话纪律）

根级新建 `CLAUDE.md`（一行内容：`AGENTS.md`+一句说明「本仓库唯一宪法在 AGENTS.md，Claude Code 会话请读它」）——ZCode 原生读 AGENTS.md，Claude Code 读 CLAUDE.md 被指回，**开发会话纪律双宿主统一**（sumeru 同款技巧反向应用；写作项目侧不涉，deploy 方案不变）。

### P4 ASCII 流程图符号系统（冷路径限定）

`skills/moshu-volume/references/cold-path.md`「开新卷」节：加一张纵向流程图，采用四元素符号系统——`[阶段] → 输入:/输出: 具体文件`、`✅ 必须完成`、`⚠️ 遵循约束`、`[检查点]`（sumeru worldbuilder 协调流程的符号法，文字 ASCII 非 mermaid）。cold-path 不登记预算；图控制在 ~25 行内。

### P5 check-prose-candidates 报告分级（stdout，零工件）

`skills/moshu-write/scripts/check-prose-candidates.js`（及 shared-assets 同源副本——**改源后 sync**）输出增强为三层：汇总行（总章/越界数）→ 分级行（✅ 界内/⚠️ 警告区[0.7-1.3 界内但贴边]/🔴 越界候选）→ 明细行（现有内容保留）。**退出码语义/阈值/候选永不拦截全部不动；不落盘任何文件**。配对：test-writing-pipeline e2e 若断言输出文本则同步（grep 核实）。

### P6 研究落档（随批 docs 件）

`docs/研究/开源强化/00-总纲.md` 学习台账追加 sumeru 行：直接同类/自动管线不学（自动连写污染传播=不学清单既有项）/并行写章与串行分歧记录/工艺 5 候选去向（本批）/触发词裁定——**「触发面收敛：子技能 slash 直呼为主，自然语言路由归 moshu 路由层，不学长尾触发词堆砌（作者 2026-08-30 实测使用裁定）」**。证据路径（sumeru-master 各文件）随行标注。

### P7 自检修正项（v1.1 增补——同一把尺子量自己的产出）

1. **标题层级跳级 ×2**：moshu-cdp/SKILL.md:109、deslop-workflow.md:186——修至逐级递进；
2. **write SKILL 加粗瘦身**：108 个 `**` 削至 ~60（保留真重点：红线/路径/数字/闸门；削语气性强调），释放预算 ~30 供 P1 使用；
3. 代码块标注**明确不做**（v1.1 结论入台账）：无标注围栏均为中文话术类无语言可标，硬标 text=churn 无渲染收益——此条作为自检结论记录，防止未来重提。

## 二、验收

1. 三 SKILL 的 I/O 两行式在位且与 current-contract 登记一致（抽 outline→volume 交接逐字段对）；write SKILL 实测 ≤4400；
2. 三 workflow 尾部四要素 grep 齐（补句处附对冲数字进日志）；
3. 根级 CLAUDE.md 存在且恰为指针内容；static-check/story-numbers 不受影响（复跑绿）；
4. cold-path 流程图四元素齐（grep `✅`/`⚠️`/`[检查点]` 命中）；
5. check-prose-candidates 分级输出实测（对 fixture 跑一次贴 stdout 进日志），退出码 0/1 语义回归（test-writing-pipeline 绿）；sync 后 check-shared-files 绿；
6. 学习台账 sumeru 行+触发词裁定在位；守卫矩阵全绿（最终态复跑+Result 行整段引用含退出码）。
7. P7（v1.1）：全仓标题跳级复扫归零（施工前 lint 脚本复用）；write SKILL 加粗计数 ≤65 且预算界内；三 SKILL 边界声明 grep 统一句式命中 ≥1；「标注不做」结论入台账（防重提）。

2. 不用 mermaid（B54 文字化先例——token 成本）；流程图仅限冷路径文件，热路径禁加图；

4. I/O 块零发明（只抄 current-contract 已登记事实，第二真源即违规）；
5. agents_version 44 不动（零模板改动，第七查 git diff 对照）；
6. 预算近零文件（volume-workflow/workflow-daily/outline-workflow）本批只减不增。
