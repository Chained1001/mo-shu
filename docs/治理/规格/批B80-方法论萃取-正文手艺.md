## 二、文件级改动清单

### 子步 76a：Burroway 正文技艺萃取

**新建 `skills/moshu-write/references/literary-techniques.md`**（~2000 字）：

五节苏格拉底化萃取（每节=问句+操作+反例+来源行号）：
1. **过滤词直呈**——触发问句「这段有限知视角的感知/回忆，我写的是『她注意到X』还是直接写 X？」；操作=删除「注意到/看见/回想起/意识到/这才发现」直接呈现所见物；注意=角色自觉的反省时刻可保留。（来源：Burroway Ch.2 :1500-1552）
2. **系动词激活**——触发=「X 很 Y」式状态句或「显得/看起来/感到」；操作=让头发飘动/让人笑跳哭抱，或保留系动词表静止态度；注意=被动语态三合法情形（动作主体未知/不重要/表无助感）别误删。（:1558-1648）
3. **比喻禁忌**——问句「这个比喻是陈词滥调/牵强/混合/过度解释/专名无注吗？」五类各给一句判据+修法；总原则「少即是多，拿不准就不用」。（:6253-6465）
4. **POV 距离推拉**——拉远=抽象名词+简述+典型+客观（读者评判视角）；拉近=具体细节+场景+思想（角色沉浸视角）；问句「这个场景此刻需要读者离角色多近？」（:5749-5776）
5. **叙事时间五技**——简述（黏合剂，覆盖长时间）/详述（砖石，展开关键时刻）/白空间（空行切换时空/视角/基调）/倒叙三规则（实物锚进出/禁直白过渡句/不嵌套）/慢动作（危机时高度聚焦随机小细节，禁感叹式内心喊话）。（:3952-4275）

**`skills/moshu-write/references/writing-craft.md` 增强两节**：
- 「展示的操作原理」——情感定位术（写「思乡在她胃里」直到落到具体位置+具体物件）+ 细节两轴判据（具体×有意义，通缉画像=只有具体没有意义）+ 主动动词杠杆（说「她被吓到」=告诉；写「攥住扶手指关节白」=必须找到形象）。（Burroway Ch.2 :1209-1552 浓缩）
- 「修改方法论」——疑虑→搁置→重听批评（听诊断不听建议：「读者说困惑的地方要留意，读者的解决方案大部分忽略」）→一遍一个问题→自我逃避检测（「你不愿深入写的地方，是对小说好还是你贪图舒适？」）。（Ch.9 :6827-7119 浓缩）

**`skills/moshu-write/references/workflow-revision.md` 增强**：
- 「重听批评」节——修订流处置工单时：听审查者的诊断（哪里读不下去/哪里不信）忽略其解决方案（「一旦薄弱环节被指出，作者几乎总能想出比读者建议好的解决办法」:6929-6935）；一遍集中修一个维度。

### 子步 76b：雪花法场景-续景操作规则

**`skills/moshu-write/references/outline-structure-theory.md` Swain 注记扩档**（:308 从 ~120 字扩为 ~300 字，两副本同步）：

现有名词（场景[目标/冲突/挫折]→续景[反应/困境/决定]）后追加五条操作规则：
1. **续景强度门槛**——「并不是所有情绪反应都足以构成完整的被动场景」（:3259）——轻微情绪（觉得奇怪/有点紧张）不够格开续景，跳过直接进下一场景
2. **主动远多于被动**——大多数专业作家主动场景远多于被动场景；续景可跳过，主动场景不可（:3259）
3. **困境=选项逐一击毙**——续景中段防注水的硬骨架：列出角色可选项（通常 3-4 个），每个配一个具体障碍击毙，最后一个未失败选项=决定（:3201-3217）
4. **决定=下一场景的目标**——决定标志续景结束，同时成为下一幕主动场景的目标（锁链式衔接，:3221-3223）
5. **挫折可藏于胜利**——中途的「胜利」可能只是冲突的一层，场景必须收在处境实质变糟处（:3181-3187 判例）

**`skills/moshu-write/references/outline-workflow.md` 场景表步增强**：
- 场景行列追加两个可选列：`视点角色`（一行多场景且 POV 轮换时必填）+ 一句话事件概括（记忆锚粒度：这句话能让你想起整个场景吗？:2813-2821）
- 准入补第二只眼：McKee「无转变删」旁加雪花冲突准入（「无冲突的场景加冲突或删；烘托气氛/解释背景/阐明动机不算存在理由」:3529）
- 细纲批末交叉核对加一条：「本批实际章数 vs 场景表预估区间+主动:被动场景比例（主动应占多数）」
