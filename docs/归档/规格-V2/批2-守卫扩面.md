## 4. 新文件设计

**check-story-numbers.py**（算法级）：
1. 枚举 `skills/*/SKILL.md`（glob）得 N（=skill 数）。
2. 扫描文件集：README.md、README_EN.md、CONTRIBUTING.md、scripts/README.md、docs/architecture.md。
3. 中文模式 `(\d+)\s*个\s*[Ss]kill`；英文模式 `(\d+)\s+skills?\b`（忽略大小写）。
4. 每处命中数字 ≠ N → 收集违规（文件:行号:原文）。
5. 全部一致退出 0 并打印 `story numbers: ok (N skills)`；有违规打印清单退出 1。
6. **白名单机制**：文件顶部常量 `ALLOWED = {}`（暂空），供"历史对照性提及"豁免——每条豁免须注释理由。
7. 零第三方依赖，仅标准库（pathlib/re/sys）。

**test-story-numbers.py**（正反向）：
- 正向：临时目录构造假仓库结构（2 个 skill + 含"2 个 skill"文本的假 README）→ 断言退出 0。通过 `--root` 参数让 check 脚本接受扫描根（脚本需支持 `--root` 覆盖默认仓库根，便于测试）。
- 反向：同样结构但 README 写"3 个 skill" → 断言退出 1 且报文含文件名。
- 反向 2：英文模式 "5 skills" → 退出 1。
- fixture 全部在临时目录（tempfile），测试自清理，不留 `.tmp`。
