# 规格 · 批 B75：narrative-writer 模板两级装配（稳定规则收进模板，spawn prompt 只传本章增量）

- 版本：v1.0（2026-08-28，旗舰起草；来源：B72 审计 §7.4 LLM 专家视角「只改一处」——80K 规则包围 3-6K 创作，规则与正文争夺 attention——作者裁定立项）
- **目的**：解决「正文 agent spawn 携带 ~13K 模板 + 日更路径 ~36K 流程文本 = ~80K 规则包围 3-6K 创作」——把「怎么写」的稳定规则收进 agent 模板（一次部署），spawn prompt 只传「本章写什么」的增量（估从 36K 减到 8-12K），释放 attention 给创作本身。
- 性质：agent 模板增强（**agents_version 40→41 bump**）+ chapter-core spawn 段瘦身 + workflow-daily 接线。分两子步两提交：**75a 模板增强**（搬规则进模板，spawn 不变——向后兼容）、**75b spawn 瘦身**（删 spawn 里的重复规则，只传增量——启用两级）。

## 一、设计依据

| 项 | 现状（实证） | 目标 |
|---|---|---|
| agent 模板 | narrative-writer.md 13300 字符——含写手角色/7 Gate/对话技巧/检查清单——已经是「稳定内核」 | 模板增加「流程规则承接」节——把 chapter-core B 段的稳定写作指令（三遍法结构/细纲优先边界/禁止提前释放/格式硬约束/场景路由映射/一进一出判据）内嵌为模板自有规则 |
| spawn prompt | chapter-core :115 传 15+ 项材料——其中约 60% 是「怎么写」的稳定规则（每章重复传），仅 40% 是「本章写什么」的增量 | spawn 只传增量（细纲/出场角色/语声锚/称谓/场景类型/文风锚点/genre_prose_card/上一章结尾段/字数目标/情节点预算），规则依赖模板 |
| 预期收益 | 日更路径 spawn payload ~36K → ~8-12K（估减 65-75%），规则不再逐章重传——**attention 留给创作** | — |

## 二、文件级改动清单

### 子步 75a：模板增强（agent 模板+规则承接——向后兼容，spawn 不变）

**1. narrative-writer.md 增加「流程规则承接」节（~800 字）**：
- 三遍法结构概述（第一遍快写/第二遍四查/第三遍五磨——每遍的帽子与重点，不重复 chapter-core 全文只列关键判据）；
- 细纲优先边界（内容层）：细纲是执行权威——情节点顺序/密疏预算/禁止提前释放/复沓锚句必须遵守；
- 禁止提前释放纪律：细纲「本章禁止提前释放」行+伏笔剧透锁标记——收到 🔒 标记的条目不得在正文揭示；
- 格式硬约束：字数目标/情节点预算 Σ/章尾钩子承诺兑现；
- 场景路由映射（B56 摘要）：高压→短句快切/低压→长句多感官/关系→对话锚点；
- 一进一出判据（B68）：本章解决一个小问题/欠一个新问题；
- 语声对照（B59）：出场角色语声锚须对照——「这句台词换人说成立吗？称谓与登记一致吗？」；
- **注意**：这些是「承接已加载的 chapter-core 规则」的摘要引用（写明「完整规则见已部署的 chapter-core.md」），不是复制全文——模板承接的功能是让 agent **不依赖 spawn prompt 重传规则也能写出合规正文**。

**2. agents_version 40→41** bump 全套（模板变更+UPGRADING v41 条目+指纹重登记）。

### 子步 75b：spawn 瘦身（chapter-core spawn 段改写——启用两级）

**3. chapter-core.md :115 spawn 段改写**：
- 删除所有稳定规则重复传（三遍法结构/细纲优先边界描述/禁止提前释放纪律描述/格式约束描述/场景路由映射/一进一出判据——这些已入模板）；
- 保留并精炼为**增量清单**（~12 项 → 精简表述）：
  1. 项目目录+章节号+细纲文件路径+上一章结尾段+输出路径（5 项基础）
  2. `selected_emotion_module`+`rhythm_reference`+来源路径
  3. `genre_prose_card`（≤300 字精华）
  4. 出场角色名单+语声锚文件路径+称谓行（B59）
  5. 场景类型（B56 一词）+重点密点功能标签
  6. 场景文风锚点片段（few-shot 优先用）
  7. 字数目标+情节点预算合计
  8. 本章禁止提前释放条目编号（如有）
  9. 本章承诺（next_chapter_commitments 相关项）
- 尾部声明：「流程规则（三遍法/细纲优先/格式约束/场景路由/语声对照/一进一出判据）由 agent 模板承接（B75a），不在 prompt 重复传递——本 prompt 只传本章增量数据」。

**4. chapter-core 净零目标**：删除的规则文本 ≥ 新增的精炼清单文本——实测 ≤ 当前 21274+（B73 后实测以 grep 为准）。

**5. workflow-daily.md 日更路径中 spawn 相关句同步**（如有重复规则传述，一并精简）。

## 四、禁止事项

**不改 agent 的行为语义**——75a 只加规则承接（agent 本来就应遵守这些规则，模板只是显式化）；75b 只删 spawn 重复（规则仍在，只是来源从 prompt 变成模板）；**不改其他 agent 模板**（本批只动 narrative-writer——其他 agent spawn payload 较小，后续按需扩展）；三遍法/苏格拉底问句/方法论指引在 chapter-core 中**不删**（它们是主会话的规则——本批只动「传给 agent 的 spawn prompt」中的重复）。

## 五、预算耦合

chapter-core 改写目标净零或净减（删除规则文本 ≥ 新增增量清单文本）；模板 narrative-writer.md +~800（不在 doc-budget——部署物非热路径）。
