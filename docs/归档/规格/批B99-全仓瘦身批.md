> **目的**：执行审计四期 C1 方向（瘦身池按新基线重排后的 C/F/G 三项）——收窄注意力面（文件数/索引行/sync 负担），**方法论内容零删除**（搬家不瘦身肉）。勘察实证：write 54 顶层 references 中 38 个为 shared-assets 节点——**合并可行域由「伪共享组清单」决定**，故本批首步为分析步、执行范围由清单数据定。

> **审计出处**：审计-四期 v1（零阻断；C1 瘦身池重排/F 方向/G 方向）；B87 瘦身批为先例（施工会话 6.5 倍减负）。

## 施工首步（第〇步）：共享组三清单（分析步，产出进施工日志）

用 python 读 `scripts/shared-assets.json` 产出：
- **清单①伪共享组**：targets 除 source 所在技能外**无任何跨技能副本**的组（组存在但无 sync 语义）→ 这些组的文件可**消组后自由合并**（零跨技能涟漪）；
- **清单②真共享文件集**：有跨技能副本的组涉及文件 → 本批**不动其组结构**（内容并入共享大文件属类型一安全路径，见 F2）；
- **清单③同源可并组**：source 相同/内容同源但拆成多个细粒度组的（G 候选）。

三清单 + 判定过程记施工日志；**清单①是 F 增量配对的授权范围**。

## 文件级改动清单

### C. 规格归档（12 份移动）

**C1.** docs/治理/规格/ 顶层 12 份已闭环规格（批B87 至 批B98）移入 `docs/治理/规格/归档/`；顶层仅留 README.md；**README 补一行索引声明**：「已闭环规格在 归档/（施工日志历史条目中的顶层路径以归档/ 为准）」——施工日志/审核记录的旧文本提及不回改（append-only）。

### F. 方法论合并（固定对+清单①增量对，合计净减 ≤8 文件）

**F1. 固定安全对（三组，不依赖清单①）**：
- **hooks-paragraph → hooks-chapter**（类型一：非共享小文件并入共享大文件——hooks-chapter 共享组 source 路径不变，内容增长经 sync 推副本）：微张力节整节迁入，保留节名锚点（「微张力·段落级悬念」）；hooks-chapter 内加一行分域导航（章首/章尾/段落级/悬念——suspense 独立文件不动）。消费者改指：SKILL 索引行合并、chapter-core 第 3 遍按需加载句、workflow-daily D2、B92 挂载若有涉及则白名单同步。
- **scene-cards + craft-cards → cards.md**（非共享×非共享=新非共享文件，~14.5K）：双卡合一，内部两域节保留（「场景工艺卡 SC-001~006」「落笔技法卡 14 张」）；全部消费方改指（writing-craft 决策路由两行并一行、chapter-core A3(h) 表中 craft-cards 引用、SKILL 索引）。
- **literary-techniques → writing-craft**（类型一：并入共享总入口）：五技节（过滤词/系动词/比喻/POV 距离/叙事时间）整节迁入 writing-craft 作「落笔五技」节；writing-craft 文件头职责声明补一行；消费方（第 3 遍 SOP/决策路由/B80 系引用）改指。

**F2. 清单①增量对**：施工首步产出的伪共享组文件中，按同域小并大原则配对执行（上限合计与固定对共净减 ≤8 文件；无合适配对则少并——**宁缺毋滥，规格不设下限**）。

**F3. 引用改造纪律**：每个被删文件名全仓 grep（盲区 #15 防假绿四条——含 .github/ISSUE_TEMPLATE/ 与连字符形态）零命中；节锚点保留（按节精读纪律依赖节名）；SKILL.md 索引行/横切主题表/writing-craft 决策路由/chapter-core/workflow 三件同步；静态检查 Warn 0。

### G. 共享资产收敛（清单③，上限 5 组）

**G1.** 对清单③确认的同源细粒度组执行合并（组 targets 取并集、组名统一）——**仅限「内容完全同源、拆组无语义」的组**（判定：组间 source 相同或 source 文件内容逐字一致）；改 shared-assets.json 后跑 sync + check-shared-files 全绿。
**G2.** 伪共享组（清单①）中因 F 合并而消失的文件，同步消组。

### D. 预算与收尾

**D1.** doc-budget：涉改文件（若在册）实测回填；新文件 cards.md 按需登记（冷路径）。**D2.** 施工日志 B99 条目（三清单+配对表+消组表+偏差）；**D3.** agent-references 副本因 source 内容变化→sync 后**指纹确认性重登记**（B78 先例，无 bump）。

## 禁止事项

1. **方法论内容零删除**——只搬家/合文件，节与内容逐字保留（瘦身瘦身壳不瘦肉，B87 原则）。
2. **真共享组结构不动**（清单②——组结构变更仅限清单①消组与清单③并组）；题材卡 32 张零触碰。
3. 挂载守卫 AUTHORITY_FILES 涉及文件：合并前核对，涉则白名单同批同步，**不得先删文件留死白名单**。
4. 热路径文件（chapter-core/workflow 系）只改引用行不加内容。
5. 规格归档不回改施工日志/审核记录历史文本。
6. 禁止 git add -A；每步 grep 带 exit 哨兵。
