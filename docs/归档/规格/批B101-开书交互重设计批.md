## 设计基准（作者裁定链，施工与验收都以此对照）

**三问链**：为什么问→落盘哪个文件哪个字段→谁消费。**三原则**：问句对素材分型不对模板填空；答无必有降级路（每级降级改变下游 query 构造）；表驱动双向追溯。**八类病**：问句不字段驱动/重活错位/交互后台交错/缺过目网/重活无声明/散点交互/术语视角错位/时机重叠。

**目标流程终稿**：
```
Stage 1 立意（纯交互，零后台零等待）：
  屏1 念头框 → 屏2 回读+缺啥问啥 → 屏3 口味与种子[含对标发现] → 屏4 档位
  → 屏5 核心设定 v1 过目落盘（标尺=初版按信号推演，明标「待 Stage 2 采风校准」）
Stage 2 备料+骨架：
  采风确认屏（query 预览四路/开始/跳过）→ 采风合并跑 → 要点表过目 → 融合五步
  → 标尺校准 v1→v2 + 档案实证化 → 骨架构建 → 机检 → 骨架轻过目
Stage 3 人物+终审：人物构建（可选评审[声明]）→ 终审（[声明]+报告）→ 开书确认（产物地图）
```
