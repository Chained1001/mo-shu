## 4. 关键设计细节

- 两模态互斥：写作任务取写作模式段，审查任务取审查模式段（对照 communication.py 互斥选择，禁止"两段叠加"）。
- 落盘回执判定（对照 director_graph）：只输出草稿未调 Write/Edit 落盘 = 未完成，打回。
- 归一化层放薄层：LLM JSON 解析全部走一个公共函数（可下沉为共享 lib，批 7 前保持 per-skill 副本 + shared-assets 同步）。
