# 作家心流模型（dev 侧设计对照一页纸）

> **定位**：产品第一性原理=对专业网文作家构建心流的建模（实测 #040 作者裁定 2026-08-31）——「人类此刻脑内在干什么、我们的机制是不是它的等价物」。与宪法「功能模仿非形式模仿」互为表里：那条问「人类步骤在 AI 身上服务什么功能」，这条问「机制=心流哪一环的等价物」。本文件是 dev 侧设计对照用，不进部署面。
>
> **使用**：设计/审查任何新机制时对照下表——机制须能落到某环的等价物，否则显式豁免声明。挂载：开发标准 §1.5「作家心流主设计律」；AGENTS.md §9 功能模仿原则同源。

## 心流十环（旗舰起草 v1，#040）

| # | 环名 | 人类作家在干什么 | 产品等价物或缺口 |
|---|---|---|---|
| ① | 脑内读者 | 每个决策瞬间过「他读到这儿什么反应」 | reader-psychology / 基本设定·品类参考 / evaluator 评委（构建时刻仍缺——⑦的补丁） |
| ② | 肌肉记忆 | 几百本书=手感，不是查询 | 方法论库=外化肌肉记忆；点名注入=AI 等价物（宪法既有） |
| ③ | 兴奋点倒推 | 先有起鸡皮疙瘩的画面/高光，再倒推怎么铺 | 灵感种子 / 终局底牌先行（Stage 2 未显式强调——候选） |
| ④ | 见好就拆 | 本能问「这为什么好」，拆完收进工具箱用时已变形 | 归因三问（B88 部署：采风手法入设计过三问） |
| ⑤ | 缝合自带变形 | 个人口味/经历/恶趣味自动渗入，成品带指纹 | 增量自证（B88 部署：改了什么/加了什么/重组了什么） |
| ⑥ | 坑见多了会绕 | 追更经验变负面清单 | 缺点规避清单 / 禁词表 / banned-words |
| ⑦ | 自嗨测试 | 写到燃点自己会激动=质量真实信号 | write 侧读者帽部分等价；outline 构建过程缺「假想读者在场」——**已由 B88 期待/释放排布表+峰值时刻×3 修补（构建时抓，不等评审）** |
| ⑧ | 品味取舍 | 取舍凭品味、推演靠「然后呢」脑内沙盘 | 预填确认 / 作者裁决位（停靠与定稿闸门） |
| ⑨ | 市场体感 | 对市场水温有体感 | 扫榜 / 采风泛化（选题决策与结构采风） |
| ⑩ | 卡住知去哪 | 卡住时知道去哪找 | 按需加载方法论 / 采风补强 / plot-troubleshooting |

## 主设计律

**每个产品机制须能回答「它等价于作家心流哪一环」；心流十环在产品里应有等价物或显式豁免声明**——新机制设计的必答题（出处：实测 #040 作者裁定 2026-08-31）。答不出的机制=「机制与心流脱节」，先修设计再落地。

## 心流透镜用法（新机制快审三问）

1. 这个机制对应心流第几环？（无对应 → 是不是在解决一个作家根本没有的"问题"？）
2. 人类作家靠什么天然完成这件事？我们的等价物够不够？（不够 → 缺口，先补等价物再上机制）
3. 豁免声明写得清吗？（不做的环+理由——不学清单同款纪律）

## 心流十阶段（序列维，#057 外部合成，B91）

> 与十环互补：十环=横切心智要素，十阶段=生命周期序列——两维合成总图。来源：专业写作书籍六源（故事/救猫咪/冲突与悬念/心流/深度工作/故事天才）+网文方法论外部合成。

| 阶段 | 在想什么（一句代表） | 产品对应或缺口 |
|---|---|---|
| 0 灵感捕获 | 这个瞬间为什么戳我 | 灵感池（B91）+灵感种子 |
| 1 验证 | 这故事有市场吗 | moshu-scan 选题决策 |
| 2 网文化改造 | 怎么让老梗有新钩子 | 采风+速写确认+归因三问 |
| 3 世界观 | 规则如何制造冲突 | 世界观骨架+金手指三定则 |
| 4 人物 | 谁值得读者代入 | 人物宝典+五件套 |
| 5 分卷大纲 | 每卷的赌注是什么 | skeleton 十列+卷间驱动链 |
| 6 黄金三章章纲 | 前三章怎么让读者留下 | BC-007 节拍精化（B91） |
| 7 第一章 | 第一页抓住人吗 | 第一章专项（B91 多版本开头+前 300 字） |
| 8 连载 | 今天这章给读者什么 | 三遍法+微张力（B91）+日更批 |
| 9 卷复盘 | 这卷兑现了什么 | volume-review+卷复盘 |

**核心认知四条（与产品哲学同构）**：灵感是火种不是燃料／爽点可计算／心流是制造出来的／读者是共同创作者。

**建纲心流四阶段注记（C20③，外部经验收敛）**：宏观俯视→降维代入→拉扯权衡→松弛留白——与十环/十阶段并列的工序态描述。**定位声明（功能模仿纪律）**：心流状态是人类认知现象，本注记仅供设计侧翻译（人类做法→AI 机制的原料），禁止进任何运行时流程/加载清单——AI 不模拟心流，只实现心流所服务的功能。
