## 常见陷阱排查清单（研究期间逐项自查）

1. v6/v7 版本混淆：同名机制可能一版已废弃，查清版本再写设计
2. 自造数字：源码中无关数字（如字符截断数）不得当设计参数
3. 文档宣称≠代码事实：README 实测数据无代码出处降级为"文档宣称"
4. "未接线"vs"已删除"：翻注释/引用确认
5. 清单类断言（skill 数/文件数）必须实测核对
6. 引文先 grep 原文再引用
7. 候选类机检永不拦截
8. 自动裁决必须补作者确认点
9. 禁大爆炸 schema 迁移
10. 文档体积超区间=没写干净，砍而非扩
11. 悬空引用：删改文档后全仓 grep
12. 批次前置依赖双向核对
13. 术语漂移：同一机制全文一名

## 研究纪律（硬约束）

1. 参考项目绝对只读；归档目录（docs/归档/，含研究-v2/、实施总纲.md、规格/ 等）不读不引用不修改。
2. 每条论断标证据：源码相对路径+行号；区分「代码事实」/「（推断）」/「存疑」。
3. 以代码为准，README 只是入口；实测数字必须可复现或标存疑。
4. 机制标注所属版本与是否废弃。
